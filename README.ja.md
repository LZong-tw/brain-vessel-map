# 脳血管インタラクティブマップ · Brain Vessel Interactive Map

[![CI](https://github.com/LZong-tw/brain-vessel-map/actions/workflows/ci.yml/badge.svg)](https://github.com/LZong-tw/brain-vessel-map/actions/workflows/ci.yml)
[![Deploy](https://github.com/LZong-tw/brain-vessel-map/actions/workflows/deploy.yml/badge.svg)](https://github.com/LZong-tw/brain-vessel-map/actions/workflows/deploy.yml)
[![Code: MIT](https://img.shields.io/badge/code-MIT-yellow.svg)](LICENSE)
[![Data: CC BY-SA 4.0](https://img.shields.io/badge/data-CC%20BY--SA%204.0-lightgrey.svg)](public/data/LICENSE.txt)

実際の MNI テンプレート脳に、大脳・小脳・脳幹の動脈を表示します。血管を閉塞させる（または塞栓を放出する）と、**数分から数か月**にわたる**他の**脳領域への影響を追えます。半影から梗塞への移行、浮腫と占拠効果、脳ヘルニア、水頭症、遠隔変性などを通じて、各時点でどの領域・**機能**が失われ、救済可能で、回復しているか、最終的に何が残るかを表示します。

**公開版：** <https://lzong-tw.github.io/brain-vessel-map/>（先に GitHub Pages を有効にする必要があります。下記の配備を参照）

![3D 表示：左 M1 閉塞を 4.5 h で再開通。左に症例パネル、右に Outcome タブ](docs/screenshot-3d-en.jpg)

> ⚠️ **教育目的のみ。診断には使用できません。** 個人の脳ではなく「標準脳」と簡略規則を使用します。
> 脳卒中が疑われる場合は直ちに救急サービスへ連絡してください（顔の下垂、上肢の筋力低下、言語障害。発症時刻を記録してください）。
>
> 台湾向けの繁体字中国語原文では、脳卒中が疑われる場合は **119** に連絡するよう記されています。

<a id="how-to-use-it"></a>
## 使い方

1. **開始点を選ぶ**：*Templates* で教材症例（左 M1 塞栓、閉じ込め症候群など）を読み込むか、*Vessels* で任意の動脈の「+ Block」を押します。テンプレートの *Add* と血管の「+ Block」は現在の症例に**追加**するため、複数動脈を組み合わせられます（中部脳底動脈 + 右 PICA など）。
2. **症例を設定する**：*Case* には *Before onset*（側副血行、血圧、Willis 動脈輪変異）、*Occlusion events*（各血管の閉塞度と時刻。先に TIA、3 日後に完全閉塞など）、*Treatment*（再開通の時刻・方法・程度、減圧手術）のカードがあります。閉じたカードにも 1 行の要約があり、時間軸上には症例全体の要約があります。
3. **時間軸を移動する**：発症から 6 か月まで。*Now* はその時点の組織、症状、NIHSS、イベント、*Outcome* は最終経過（治療設定時は同じ閉塞を放置した場合との比較）、*Details* は選択血管・領域を示します。*Now* はモデルが再開通を提示する期間（閉塞開始から 1 日以内で、まだ再開通していない間）のみ半影を「まだ救済可能」とし、その後は「まだ失われる可能性」とします。量は現在の血流でなお壊死に向かう半影のみで、閉塞が続いても側副血行で生存する部分は別記します。部分的にしか血流が戻らない再開通（eTICI 3 未満、無再流、下流の血栓片）後は、血流が戻らない場所やその後壊死した場所で損傷が進むと説明し、半影の壊死が止まったとはしません。脳幹などの小梗塞は自身の体積の 10 分の 1（または 0.5 mL）増大すると増大中と判定します。
4. **共有する**：症例全体は URL の `#` 以降にあります。URL をコピーしてください。

| **Case → Now → Outcome** | *Case* は症例設定全体、*Templates* は教材の読み込み・追加。右側の *Now* は表示時点、*Outcome* は最終梗塞、3・6 か月の NIHSS、残存障害と代償程度、晩期合併症を示します。 |
| **時間軸** | 発症 → 15, 30 min → 1, 2, 3, 4.5, 6, 12 h → 1, 2, 3, 5 日 → 1, 2 週 → 1, 3, 6 か月。*Now* と *Details* は組織状態、半影喪失までの時間、障害／危険／回復した機能、全経過のヒートマップに追従します。セルを押すと、その時点の症状、原因領域、変化を表示します。 |
| **段階的経過** | 各血管の開始・自然再開通時刻や「後に完全閉塞」を設定できます。TIA、後に閉塞する狭窄（前駆 TIA → 数日後の脳底動脈閉塞など）、任意時点の治療を扱います。 |
| **再開通の詳細** | 方法（血栓回収／静注血栓溶解／併用）、再灌流等級（eTICI 0–3）、再閉塞、遠位枝または新領域（同側 ACA）への血栓片塞栓、無再流（証拠は限定的）。選択した結果を再現し、隣に部位別の公表値を出典付きで表示します（再開通、症候性出血、中・遠位血管、大コア血栓回収、tenecteplase、4.5 h 後の画像選択血栓溶解、再閉塞、遠位・新領域塞栓、無再流）。部位別の治療時間枠にも注意を表示します。選択時刻は血流再開で、血栓溶解薬投与から 1–3 h 後となるため、単独血栓溶解を遅いとするのは投与が 4.5 h 後であった可能性が高い血流再開約 6.5 h 以降です。脳底動脈の 4.5 h 後の血栓溶解は専門家合意のみが根拠で、血栓回収試験のない部位や否定的な中血管試験も明示します。治療時間枠は前方大血管（大コア試験を含む）、脳底動脈（試験死亡率を含む）、単独頸部 ICA、V4、中・遠位血管、ラクナで異なります。「救済」は未治療なら壊死し、治療により生存する組織だけで、未治療腫脹のヘルニアが梗塞させる領域も含みます。 |
| **回復** | 初期障害は梗塞より広く、浮腫と遠隔抑制が生存組織を沈黙させます。その後、残存経路が機能を一部代償します。片側病変や両側・並列供給の機能で多く、脳神経核などの最終共通経路ではありません。主経路と代替経路が集まる両側橋腹側や大脳脚の大部分が途絶すると非常に少なく、該当経路を明記します。再開通後の小さな両側梗塞はこのボトルネックではありません。失語・半側空間無視の代償は同側 MCA 皮質残存量によります。言語皮質のほぼ全体が梗塞すると 3 か月でも重度または全失語が残ります。理解は Wernicke 領域残存量にも依存し、約 5 分の 3 超が梗塞すると 3・6 か月でも中等度〜重度の Wernicke 失語が残ります。脳幹の密集した経路・核の障害は梗塞・回復中の割合で薄れ、閾値で一斉に出没しません。右傍正中視床梗塞の認知障害は多くが回復する一方、左または両側では残りやすいなど、側性も関係します。模式的集団平均であり予後ではありません。 |
| **浮腫と腫脹** | 細胞障害性浮腫（DWI、数分）→ イオン性浮腫（CT 低吸収、数時間）→ 血管原性浮腫（3–5 日に最大）→ 消退 → 萎縮（数か月）。各領域の腫脹で 3D 脳が変形します（1× / 3× / 5× に誇張可能）。「浮腫／画像」色モードでは ADC 正常化後も DWI は数週高信号で、グリオーシス瘢痕の T2/FLAIR は恒久的に高信号です。正中偏位と脳室圧迫・拡大が時間変化し、意識は正中偏位、両側腫脹時はその合算に追従します。 |
| **連鎖反応（他領域への影響）** | 悪性 MCA 浮腫 → 大脳鎌下ヘルニア（ACA 圧迫）と鉤ヘルニア（中脳、PCA。梗塞した大脳脚を通る動眼神経束の麻痺は残存）。他半球の状態にかかわらず、その半球自身の腫脹が正中を昏睡範囲まで偏位させると発生します。両側が同程度に腫脹すると下行性の中心性経テントヘルニアとなり、単独でヘルニアを起こす各半球の二次性梗塞を保持します（合算だけで昏睡範囲となる場合はなし）。減圧なしでは「死亡の可能性が高い」。占拠性小脳梗塞は段階化（20 mL から監視、38 mL から悪性腫脹が起こりやすい）→ 脳幹圧迫と閉塞性水頭症、意識は腫脹に追従し、手術なしで昏睡に至ると「生命を脅かす」。出血性変化リスク、交叉性小脳機能抑制、錐体路の Wallerian 変性、肥大性オリーブ核変性と口蓋振戦の可能性、視床萎縮、広範両側脳幹被蓋梗塞と昏睡後の中枢性高体温、外側延髄梗塞後 10 日の呼吸不全リスク（片側でも十分）、内耳単独梗塞を TIA ではなく脳卒中警告とする説明を含みます。誤嚥性肺炎は嚥下障害または意識低下がある間に、その時点の原因を表題に表示し、大梗塞には該当症状が出るまで嚥下評価を促します。脳卒中後の心臓問題は全梗塞後に表示し、NIHSS 16 または昏迷・昏睡から重症（体積でなく臨床重症度）とします。再開通で改善後は発症時重症とし、島皮質関与を注記します。深部静脈血栓は不動（下肢挙上不能、昏迷・昏睡、意識障害、無動無言）の 2〜30 日に表示します。重複閉塞では各梗塞の発症から警告や中枢熱を計時します。早期・晩期発作（晩期数値付き）、症状を伴う中枢性疼痛・痙縮の可能性、脳幹梗塞後 REM 睡眠行動障害の可能性、うつなども含みます。 |

<a id="how-the-simulation-works"></a>
## シミュレーションの仕組み

1. **形状**：`tools/build_assets.py` が TemplateFlow から MNI152NLin2009cAsym の分割・確率マップを取得し、marching cubes でメッシュ化します。各表面点に機能領域と動脈灌流域（*bed*）を付けます。灌流域は Liu et al. の動脈アトラスに由来し、重なりが境界領域です。
2. **血流**：各血管は Poiseuille 抵抗で、各 bed は 1 本以上の供給動脈を共有します。側副血行は等級（良好／中等度／不良）に応じて通流し、灌流圧低下時は細動脈が拡張します（自動調節、最大 1.8×）。脳幹の非描画軟膜側副血行は正常を超える血圧で収縮します。鎖骨下動脈の非描画胸壁・頸部側副血行は、近位閉塞時に逆流椎骨動脈と共に上肢を供給します。遺残三叉神経動脈など一部の人にしかない血管は変異選択時のみ存在し、変異で除去される血管は描画しません。半球上の軟膜動脈（A2、M2、P2 と皮質枝）と吻合は左右の長さ・基準流量の平均を使い、どちら側でも同じ閉塞の流量を同じにします（制限を参照）。線形系で全位置の圧と流量を解きます。
3. **段階的経過**：閉塞は異なる時刻に開始し、自然再開通・進行でき、治療は再閉塞や遠位血栓片を生じます。閉塞状態が一定の各期間で血流を 1 回解き、組織はその履歴に従います。時刻 0 は最初のイベントです。連鎖と回復の基準は最大の梗塞を生む閉塞（各病変の腫脹は独自の時計；梗塞なしでは最後に虚血を生む閉塞で、以前の発作は別の発作として説明）です。領域ごとの晩期症状、代償、昏睡ラベル変更はその領域の虚血開始から数え、ヘルニア二次性梗塞は原因腫脹病変の開始から数えます。同側半球が基準であり、悪性右 M1 梗塞によるヘルニア性梗塞は 1 か月後の左 M1 が基準イベントとなっても時計を再開せず、下肢筋力低下の代償を保持します。各時点はその時点の症例で、後発閉塞はまだ知られておらず、開始前の腫脹・意識・イベント・*Now* の予測を変えません（将来閉塞する狭窄はその時まで持続）。*Outcome* とその最終梗塞案内は全予定を示します。

   後発閉塞後も各病変は独自の浮腫イベント（悪性浮腫／占拠効果、ヘルニアとその梗塞、交叉性小脳機能抑制、小脳腫脹）を保持します。大きな閉塞が始まっても先行梗塞の腫脹・ヘルニア性梗塞を消さず、ヘルニアで壊死した組織は後発閉塞も同じ場所を梗塞させる場合に生き返りません。既に始まった浮腫・ヘルニア・致死性注記や、治療／再開通イベント（時間枠、再開通と後続、自然再開通、Willis 動脈輪作動、線条体内包梗塞の皮質症状）を後発閉塞前から削除・改題・終了しません。後発病変で中等度占拠効果が悪性経過になる場合、その病変の最初の日から変更します。

   各半球と小脳の分類は自身の病変（開始が 1 日以内の beds；小脳は前後どちらでも腫脹の重なる全小脳梗塞）によります。後頭蓋窩経過は体積だけで決め、既に始まった梗塞の合計が該当体積に達した時から進めるため、数日違う 2 小脳梗塞でも順序によらず同じ腫脹となり、後発前の説明は保持します。各病変は共に腫脹する病変の体積で腫れ、後発病変は自身が腫れる分のみ加え、開始時に先行腫脹が跳びません。単一悪性梗塞の体積基準に対して両半球を合算するのは開始が 1 日以内の場合のみですが、重なる腫脹は常に合算します。他のイベント（超急性機序、画像、出血性変化、発作、晩期変性）は最大梗塞を生む病変の時計に従う重複脳卒中の簡略化です。「発症後」はその基準発症から、腫脹文は自身の病変から数え、異なれば明記します（右 M1 閉塞後 279 h に軽減するヘルニアは、1 か月後の左 M1 が基準でもそう記述）。

   梗塞を残さない脳虚血も障害が続く間は TIA とまだ区別できない急性脳卒中として、消失を待たず治療時間枠を示します。抗血小板薬は画像で出血を除外してからです。TIA の説明（「症状消失は安全を意味しない」と抗血小板薬案内；血栓溶解後は 24 h 画像以降）は症状一覧から障害が消えた時に開始します（Powers 2019; Easton 2009）。上位頸髄（前脊髄動脈域）の虚血には独自の脊髄梗塞・脊髄 MRI・経過の説明があり、脳虚血があれば並記します。上肢や顔だけにはこの説明を出しません。
4. **組織の運命**：相対流量 < 30 % は虚血コア、30–55 % は半影、55–85 % は軽い乏血です。壊死速度は血流不足の深さと時間によります。終末動脈で完全無血流となる深部穿通枝領域の灰白質（線条体・視床など）は約 6 分から損傷し、15 分以内に大部分を失います。白質（内包・放線冠）は長く保ち、約 2½ 時間は喪失せず、4 h に約半分、6 h に大部分を失います。各再灌流時刻の血栓回収で内包が温存される頻度に合わせた設定です。

   ラクナ（穿通枝束の 1 枝）は所在組織の時計を、束全体と同様に用い、束がその場所で供給する以上の構造を失わせません。内包枝の 1 時間閉塞はレンズ核線条体動脈群全体の 1 時間閉塞以上の内包を壊死させず、どちらも壊死なしで、その後数時間かけて機能が戻ります。従って M1 を 1–2 h で開けば線条体梗塞は残るが上肢は通常温存され、6 h ではまれです。最終領域一覧と詳細はラクナ自身の体積・割合（約 0.8 mL、放線冠の 6 %、後脚の 38 %）を、上の最終梗塞と整合して表示します。機能喪失（大部分）は領域機能障害に表示し、なぜ小病変が大障害を生むかを詳細で説明します。尾状核頭、下部橋、外側延髄など自身の構造症状を使う部位は束全体以上の機能を失わせません。Heubner 枝だけが本幹では残らない構音障害を残したり、下部傍正中橋枝が全群より重い片麻痺を残したりしません。純粋運動・失調性片麻痺など専用症候群の部位は経路機能の大部分を保持します。

   側副血行が届く皮質・白質・小脳は最初の 20 分に損傷しません。その後無血流では 2½ h に約半分、コア閾値直下では 6 h に約半分、半影ではさらに遅く損傷します（低流量ほど速い）。再開通なしでは最大 85 % が側副血行で生存し、約 12 h で機能を回復します。開始 2 日後はなお壊死中でなければ半影と数えません。その時までに死亡または生存へ移り、低酸素だが生存する組織の PET 標識も最初の 2 日に減少・縮小しています（Read 2000; Markus 2004）。従って 2 日目以降の半影は今後なお失う分で、残りは生存するが沈黙し回復中の組織です。*Now* と詳細は再開通救済組織と同様にそう記述し、壊死組織とは呼びません。

   不良側副血行の M1 閉塞は 1 h で約 60 mL、初期は 35–55 mL/h 増大し、約 12 h で灌流域を埋めます（実測大血管閉塞の最速増大は約 74 mL/h）。中等度では 20–30 mL/h。未治療ではコア閾値未満は全て壊死するため最終梗塞は従来と同じで、経過だけが遅く、早期再開通は不良側副血行でも救済します。救済組織は即時ではなく数時間〜数日で回復します。虚血 1 時間後なら約 4 分の 1 が直後、半分は約 2 h 内、虚血 6 h 後なら約 1 日内、残りは数週で戻ります（数分の TIA は直ちに消失）。網膜は完全閉塞約 12 分後に損傷開始（ヒト推定；サル実験はもっと長い）で、数分の黒内障には梗塞が残りません。脳幹半影はゆっくり損傷しますが未治療生存は少なく、ATTENTION・BAOCHE に合わせた設定です。単一穿通枝閉塞はモデルが観測する血流を変えず、閉塞直後から組織機能が止まります。壊死開始前（数分、内包・放線冠は約 2½ 時間）に開けば梗塞を残しません（内包 TIA）。単一枝でも全束でも終末穿通動脈先の白質には側副血行が届かず、*Now* は無血流でも白質壊死に数時間かかるため生存すると説明します。最終梗塞は最後の血管変更から 6 か月後に評価します。
5. **治療**：選択時点の完全閉塞を開通させます。eTICI が再開通経過に従う灌流域割合を決め、残りは未治療経過です。無再流・再閉塞・遠位塞栓がそれぞれ経過を変更します。「救済」= 未治療なら梗塞し治療で生存する組織で、未治療腫脹のヘルニア性梗塞領域も含む（未治療最終梗塞 − 治療最終梗塞）。開通後は治療時間枠を終了し、梗塞を残す自然再開通も同様です。再閉塞後は発症から数えた最初の 1 日の残りに再表示します。eTICI 0 は「試みたが開通せず」。開ける閉塞がない治療（モデルでは再開通しないラクナへの静注、完全閉塞のない時刻）は投与時刻のみで、eTICI、比較、救済量を表示しません。

   eTICI は最終造影の全遠位灌流域再灌流を等級化します（3 = 100 %, 2c = 90–99 %, 2b67 = 67–89 %, 2b50 = 50–66 %: Liebeskind 2019）。下流枝の血栓片はその枝の正常流量割合だけ表示等級を下げます（M1 回収中の下部分枝塞栓では選択 3 が 2b50）。選択等級は残りの領域の等級で、新領域塞栓は別記して選択値を保ちます。梗塞を残す自然再開通にはイベントと *Now* の専用文があり、同じ症例の閉塞持続との差を示します（53 研究のメタ解析で約 4 分の 1: Rha & Saver 2007）。壊死前なら TIA とします。自然再開通も治療と同じ判定で、腫脹のヘルニアが侵す生存組織は閉塞持続例と同じものを用いるため、同時刻の完全血栓回収と同じ最終状態で、閉塞持続より大きくなりません。

   後発閉塞の時間枠は治療判断時に自身が壊死させたコアを用い、先行梗塞は使いません。少なくとも 1 日前に始まった先行梗塞（モデル選択）から 3 か月以内は静注血栓溶解が標準でないと説明します。指針は推奨せず、主に専門家合意による相対禁忌で、登録研究の症候性出血増加は先行脳卒中後 14 日以内のみでした（Shah 2020; Scala 2026）。イベントは治療有無の 3 か月 NIHSS を示し、2 点以上の障害、しばしば致死的な経過（ヘルニア、脳幹圧迫、昏睡を伴う未開通脳底動脈）、または 50 mL 以上の梗塞を回避すれば利益とします。閉じ込めの防止は数 mL の橋救済でも重要です。一方、未治療致死経過の NIHSS は生存者の得点であり、同体積の右病変は左より低得点、最終体積自身も機能転帰を予測します。同得点を「X ではなく約 X」と差として書かず、尺度に反映されにくいことと救済脳量を説明します。致死経過の欄はイベントと *Outcome* に「生存した場合」を付けます。

   0.5 mL 未満かつ未治療梗塞の 10 分の 1 未満の微量救済では、等級境界の NIHSS 差を利益とせず明記し、不完全閉じ込めイベントにも橋を一部救済したとは書きません。再開通なしでも同時期（1 日以内）に動きが戻る場合も同様です。良好側副血行の中部脳底動脈を 2 日で開いた例は、どちらも 9 日に動きが戻ります。0.05〜0.5 mL は小数 1 桁で示し「~0 mL」としません。微量判定は救済量で行い、別領域の遠位塞栓損傷を差し引きません。小脳幹梗塞は必ずしも微量でなく、不良側副血行の下部脳底動脈を 6 h で開き 1.5 mL 中 0.4 mL を救う場合は利益を保持します。
6. **浮腫**：各 bed はコア・半影・再灌流から細胞障害性、イオン性、血管原性浮腫と後の萎縮を蓄積します。腫脹量を正中偏位（減圧開頭後は主に外向き）へ変換し、近似帯で意識を低下させます（Ropper：約 4 mm から傾眠、6 mm から昏迷、8 mm から昏睡）。両側腫脹は横でなく下へ押し、正中偏位が小さいため、意識には単一半球と同様に合算量を使います。各半球のヘルニアと時刻は自身単独で生じる偏位に従い、昏睡範囲にある間は 3 日目から生じます。反対側の小さい腫脹が押し返してもヘルニアや二次性梗塞を消しません。他半球が自身の浮腫イベントを持つには小さすぎる場合も、合算が昏睡範囲にある間は、この側からの力によるヘルニアと昏睡を維持します。

   ヘルニア開始時に自身から反対側へ 4 mm 以上偏位すれば鉤・大脳鎌下ヘルニア、それ以外は両側下行性の中心性ヘルニア（大脳鎌下なし、片側動眼神経麻痺なし）です。単独でヘルニアを起こす半球は自身の二次性梗塞を保持します。テント縁の PCA 領域は片側／両側腫瘤後の記載（Keane 1980）、鎌に接する ACA 領域はモデル選択（両側腫脹では帯状回は鎌下へ滑らない）です。単独では起こらず合算のみ昏睡範囲なら、側や範囲を特定できないため二次性梗塞なし（モデル選択）。両側 MCA の少なくとも 3 分の 2 が機能を失うと腫脹によらず最初の 2 週は少なくとも傾眠です。

   体積基準で両側を悪性浮腫・ヘルニアとして扱うのは両側に腫脹に十分な MCA 梗塞がある場合のみです（証拠は MCA 領域）。両側 ACA／PCA、または MCA と対側 ACA は各側中等度占拠効果で、意識には合算します。合算時のみ危険な側はその旨を示し、小さい自身の体積の隣に「> 145 mL は高リスク」としません。体積にかかわらず 8 mm の昏睡範囲（片側または合算）なら悪性浮腫で、滞在中は 3 日目からヘルニアです。個々は悪性体積未満の両側頸動脈域（MCA と ACA）梗塞も合算で昏睡・下行ヘルニア・致死リスクとなり、1 週昏睡後に覚醒する経過とはしません。単独約 245 mL、偏位 9 mm の半球も同様です。モデルの腫脹性昏睡は常にこの経過ですが、昏迷（6–8 mm）は違います。両半球または両側 MCA（皮質–視床連絡白質の多くを含む）の 3 分の 2 以上が最終梗塞（ヘルニア二次性を含む）となれば、ヘルニアの有無にかかわらず、生存者は新しい病変から 2 週後に意識障害（植物状態／最小意識状態、NIHSS 1a = 3）となり、清明へ覚醒しません（Adams 2000; Multi-Society Task Force 1994）。*Outcome* には単側の生存数値でなく両側専用の注記を出します。
7. **連鎖**：文献から簡略化した閾値（> 145 mL の梗塞が 14 h 内 → 悪性浮腫；小脳 ≥ 20 mL → 腫脹監視、≥ 38 mL → 悪性腫脹の可能性）を、閉塞して**いない**領域への影響に投影します。Willis 動脈輪の作動は閉塞・狭窄の先へ血流を運ぶ場合のみです。平常供給動脈が全て閉塞・狭窄またはそのような接合部から供給される接合部に、ACom、PCom、眼動脈の流量が 5 mL/min 超増加することを用います（モデル選択）。頸動脈、A1、P1、脳底動脈、頸動脈 T から ACA への迂回は可能で、輪の先の MCA、A2、P2 閉塞は迂回しません。実際に運ぶ経路だけを名指し（両交通動脈欠損なら眼動脈のみ）、なお梗塞が生じれば不十分と領域梗塞を説明します。閉塞中も機能が維持される時のみ緑色の「梗塞予防に十分」です。数分の頸動脈 T・脳底動脈閉塞は短時間のため梗塞しなくても障害があるため、再開通までは機能維持なしとします。交通動脈逆流だけでは判定できません。対称ネットワークの安静 ACom 方向は任意で、片側 M1・M2・A2 閉塞だけで「逆転」し、他側ではしなかったためです。線条体内包梗塞の皮質症状（Donnan 1991）は皮質に閉塞が及ばないレンズ核線条体単独なら発症時、皮質壊死前に M1 を開く場合は皮質機能が戻る再開通時に始まります。壊死する深部構造を名指しし、早期再開通で温存される内包は含めません。
8. **症状・症候群・回復**：各領域は喪失症状（同側／対側）を持ち、合併して名称付き症候群規則と照合します。徴候による名称（無視、Wallenberg、純粋感覚ラクナ、閉じ込め、網膜虚血、内耳脳卒中など）は徴候が一覧にある間のみ表示します。失語・意識低下で単眼視力低下が検査不能なら、網膜虚血ラベルは非表示で、徴候と理由を別記し、評価可能になれば戻します。血管パターンによる名称（灌流域、境界領域梗塞）は組織損傷中に保持し、その側の症状が表示中にも評価不能にも残らなければ「臨床的に無症候」とします。ACA は内側前頭／帯状皮質ともう 1 ACA 領域の梗塞を指し、側副血行で中心傍小葉と下肢を救う場合も含みます。

   境界領域ラベルには同側の血行動態背景、MAP 70 mmHg 未満、または頸動脈／M1 の高度（≥ 70 %）狭窄・閉塞が必要です（Bogousslavsky & Regli 1986; Wong 2002）。遠位枝の塞栓単独は境界領域 beds に位置しても分枝域梗塞です。閾値はモデル選択です。MCA 上部・下部分枝のラベルは症状の閾値（25 %）を用い、その症状の持続中に保持します。左では他分枝の失語（下部ラベルと運動性、上部と感覚性／伝導性）や全失語・混合性超皮質性失語には併記しません。下部分枝は記述徴候が表示中または評価不能の場合のみ（左の感覚性／伝導性失語、右の左無視／視空間障害、どちら側でも視野欠損）。良好側副血行で右 M1 を 4.5 h で開き、3 か月で無視が代償される例は線条体内包ラベルを保ち、下部分枝は保ちません。徴候消失後に無症候ラベルとして残すこともしません。

   完全 MCA は区間でなく領域全体の病像です（通常 M1、側副血行不十分の頸動脈閉塞も原因）。顔／上肢／下肢、顔と上肢、または全半身の筋力・感覚喪失が表示中・評価不能、あるいは内包梗塞がある場合のみ表示します。M1 回収時に下部へ血栓片が飛ぶと、線条体、島を含むその枝の皮質、領域の 4 皮質区域が梗塞し、Wernicke 失語と半盲があっても筋力低下なしなら下部分枝と呼びます。血行動態性境界病像は境界領域ラベルを優先します。半球損傷の少なくとも 35 % が境界領域、または MCA の 4 皮質区域に広がる損傷が周囲 ACA・PCA の固有 beds を相対的に温存する場合（損傷密度が境界領域の半分以下）、MCA と境界内の損傷の 35 % を用います。第 2 指標は Willis 動脈輪が鏡像でないためです。低血圧下の高度頸動脈狭窄では右 ACA 固有領域の低灌流が左より多く（16 mL 対 5 mL）、全半球割合だけでは同じ MCA 境界病像が左で境界、右で完全 MCA となっていました。前脊髄動脈症候群は上位頸髄梗塞を指します。

   損傷領域の言語成分は流暢性・理解・復唱から一度に 1 失語型（全、Broca、Wernicke、伝導、超皮質、混合性超皮質）へ合併します。代償による変化は軽い型に限り、流暢性が非流暢性へ戻ることはありません（Copenhagen aphasia study）。軽くなった全失語は Broca、理解の方が重ければ Wernicke とします。救済組織の回復中は残存成分で決め、発語失行・壊死由来成分は非流暢型を保ちます。2–5 日の一時的浮腫は成分を深めても全失語へ戻しません。視野欠損部の解放性幻覚など少数例の現象は「可能性」として記述し予測しません。盲視野に色覚喪失を挙げません。黄斑回避は半盲の説明で障害ではなく、浮腫が後頭極も沈黙させて失われても改善とは呼びません。*Outcome* では半盲の隣に記し残存障害に数えません。

   覚醒・協力を要するもの（行動、遂行、記憶、自発性、気分、歩行、色覚、読字、書字、計算、失認・失行、病態無認知、指鼻試験、巧緻運動、本人しか訴えられないめまい・複視・疼痛）は昏迷・昏睡・意識障害中に表示しません。重力に抗して上肢が動かない側の運動失調、動作時振戦、巧緻運動障害も非表示（失調は下肢が全く動かない場合も）。NIHSS は麻痺肢の失調を数えず、動かない肢で示せないためです。他人の手（自発的把握・探索、左手が右手に対抗）、脳梁離断性左手失行・失書も同じです。後者 2 徴候は右手との比較（右手が行う命令動作・書字を左ができない）なので、右上肢も重力に抗して動かなければ表示しません。歩行・体幹失調は歩行・立位・座位で見る（Carmona 2016）ため両下肢が抗重力不能なら非表示です。立てず、両側体幹筋力低下で支持なし座位も不能なためです。片側だけなら座位評価を保ちます。

   視覚による顔・物体認識、読字、道順、視覚下到達、視空間課題は視覚が必要で、皮質盲または中心視温存なしの両半視野喪失では表示せず Balint とも呼びません。無動無言の覚醒患者は動作・回答・報告（行為、他人の手、到達、認識、読み書き、記憶、失語型）を要する評価ができず、観察のみ可能です。言語理解のない中等度／重度全・Wernicke・混合性超皮質性失語では、読字、書字、計算、指の名称、言語記憶、病態認識、本人のめまい・複視・味覚・位置覚・疼痛は失語と区別不能なので別記します。言語なしに検者動作を模倣する両手失行は表示（De Renzi 1980）しますが、命令・書字の左右比較を要する脳梁左手失行・失書はしません（Watson & Heilman 1983）。左手が右手に対抗するのは観察徴候なので残します。

   言語（失語、構音／嗄声、項目 9・10）と無視（11）は尺度が昏迷でも評価するので表示し、無反応者として採点する昏睡でのみ除外します。意識障害でも言語は非表示で無言として採点します。障害は消えたのではなく、*Now* の要約・一覧、ヒートマップの点線セル・詳細、領域詳細、*Outcome* の障害数を含む出力で、理由（意識、盲、無動無言、理解不能、肢麻痺）と「現在評価不能」を別記します。改善／消失とはせず、評価可能になれば戻し、NIHSS もこのためには下げません。

   NIHSS は尺度固有規則に従います。軽い筋力低下＝ドリフト 1 点。失調は肢数で、片側軽度は 1、片側中等度／高度は上肢・下肢で 2。理解不能・麻痺では失調なし。昏迷・無構音も質問（1b）に算入し、質問を理解しない昏迷（1b = 2）は 2 命令中最大 1（1c は少なくとも 1）。重度失語／発語少量（9 = 2）は最大 1 質問回答（1b は少なくとも 1）。脳幹由来の両側感覚喪失は 2。無言の全失語（9 = 3）は命令不能（1c = 2）、構音も無言（10 = 2）。意識障害もベッドサイドでは無言・命令不能として採点します。眼球で回答できれば閉じ込めで清明と採点しますが、モデルは再現できません。無動無言は覚醒・無言（9 = 3, 10 = 2）、命令不能（1c = 2）、失語以外で回答不能（1b = 1）です。

   両前頭眼野喪失は反対向きの共同偏視 2 つでなく両側随意注視麻痺。上位頸髄の両側障害と延髄の同じ片側障害は側ごとに 1 回表示します。同側広範障害の、より重くない一部は広範障害に統合します（四分盲は半盲の一部、完全上肢麻痺に軽い肩筋力低下を重ねず、全感覚半身喪失は温痛覚・位置覚・顔・上肢・下肢を含み、末梢性全顔面麻痺は下顔面低下を含む）。部分が全体より重ければ、より悪い場所として別記（顔・上肢感覚が残りの半身より悪いなど）。初期の浮腫・遠隔抑制は一過性障害を加え、既存障害を維持・増悪できますが、再開通で消失したものを戻しません（救済された脳底動脈閉塞が 3 日目に閉じ込めにはならない）。後は機能の代替経路に応じて代償します。*Now* が「改善しない」とするのは代替のない機能の全障害が壊死由来の時のみで、周囲浮腫が深める間、隣の腫脹が経路を圧迫する間、生存だが沈黙する間、直前に改善した時には言いません。

   失語・右半球性無視は主に同半球の残存皮質、より少なく反対同名領域が代償します。同側 MCA 皮質の 10 分の 6 超が梗塞すると代償割合が低下し、ほぼ全体なら約 10 分の 1 になります。全 MCA 梗塞生存者は 3 か月にも全失語・重度 Broca／Wernicke または重度無視を残し、M2 病変・早期再開通は従来通り回復します（大部分はよく回復するが、MCA 全域や広範側頭頭頂損傷では中等度／重度残存が多い：Wilson 2023）。理解は総梗塞量によらず Wernicke 残存で代償し、半分超で低下、約 5 分の 3 から 3・6 か月に中等度／重度（NIHSS 9 = 2、質問 2 つとも回答不能）、半分以下なら軽度へ回復します（Naeser 1987；残存 Wernicke は通常縁上回・角回も関与：Kertesz 1993）。改善する全失語はこの損傷なら重度 Wernicke へ。共同偏視は病変量によらず反対眼野が数日で代償します（Steiner & Melamed 1984）。

   脳幹は経路と核が密集するため小梗塞も線維の一部を途絶します。症状閾値以下でも 15 % まで損傷割合で段階化し、より小さい割合は隣接動脈に供給される領域端（Wallenberg の内側延髄、Percheron の中脳など）を表します。回復徴候は一斉に消えず薄れ、閾値直下の梗塞も比例した障害を残します。両側徴候（無構音、両側嚥下、呼吸）はなお両側の閾値が必要で、下では各側の構音障害・筋力低下です。閾値未満は自身の症状だけを段階化し、その側の経路喪失とはしません。P2 による大脳脚の 5 分の 1 や椎骨閉塞による内側延髄端は対半球筋力低下の回復を遅らせず、両側小梗塞も片側同様に代償されます。内包の一過性抑制による視床梗塞の筋力低下も経路喪失ではありません。外側延髄の同側顔面低下は交叉後延髄へ下行する一部の対半球線維のみ（個人差：Urban 2001）で、多くは橋で交叉します。中枢性顔面麻痺は全例軽く退院まで消失（Kanbayashi 2021）でした。従って経路喪失とせず、どちら側の運動皮質梗塞と重なっても顔面症状は独立に回復し、右 M2 と共存しても延髄性は 3 か月で消失します。両側化は両半球自身の経路が切れた場合のみです。

   脳幹自身が閾値未満なら一過性腫脹抑制が 2 日目の新片麻痺や、独自の高い閾値を超える一時的 Horner・傾眠を生みません。側副血行維持半影のなお壊死する分は機能障害に数えます。初期完全麻痺で、内包後脚・大脳脚・橋底部など皮質脊髄線維集束の半分以上が梗塞すると代償が少なく、上肢はドリフトでなく中等度（NIHSS 3）が残り、下肢はより回復します（単独上肢運動回復はこの群 1/28、純皮質群 3/4：Shelton & Reding 2001）。小ラクナは一部線維を温存し通常割合を保ちます。両大脳脚／橋腹側のボトルネックは両側喪失量ほど代償が減り、症状閾値で追加の急変をさせず、古典的閉じ込めの 40 % で最大効果、*Now*・領域・*Outcome* に名称を出すのは両側約 3 分の 1 からです。併用再開通後の両脚 4 分の 1 梗塞（0.8 mL）は軽い筋力低下へ回復し、閉じ込めではありません（両側橋は片側より転帰不良：Kumral 2002；ただし広範両側 DWI 病変でも再開通後不良とは限らない：Haussen 2016）。

   動眼神経麻痺の眼に自身の Horner を重ねません。瞳孔括約・散大筋とも脱神経なら中間位・無反応で、動眼神経麻痺と Horner 併存は瞳孔温存のように見えます（Serdaru 1983）。同病変の半身発汗低下は保持します。Horner と発汗低下には P2 の供給分より広い外側中脳損傷を要します。PCA 閉塞は通常視野・半身感覚・神経心理障害で、Horner は前外側中脳を梗塞させる近位例（Bassetti 1995）、後方循環登録では近位延髄域と関連しました（Searls 2012）。

## 明示する制限

- **血流は 0-D 集中定数モデル**です。拍動、粘度変化、実際の 3D 流体力学はありません。mL/min の数値は桁と方向についてのみ意味があります。
- **閾値・時定数は文献から簡略化し手動校正**して、側副血行不良 → 大梗塞、早い再開通 → 多い救済、後方脳卒中の低 NIHSS などの傾向を示すもので、個人の体積を予測しません。損傷速度は大血管閉塞コアの実測増大（中央値約 3–5 mL/h、速い群は 10 mL/h から、最速約 74 mL/h）に合わせていますが、中等度・良好の初期増大（約 20–30 と 10–20 mL/h）は中央値を上回ります。無血流とする終末穿通枝域と前側頭皮質が早期壊死するためです。両交通動脈から遮断された不良側副血行の半球はほぼ無血流で最初の 1 時間に約 100 mL を失い、実測範囲を超えます。サル閾値（10–12 mL/100 g/min 未満で 2–3 h 内に梗塞）はモデルが従うヒトデータより速いものです。深部白質は再灌流時刻ごとの内包梗塞患者割合を内包喪失割合として読み替えています（典型例 1 人で、分布ではない）。ラクナは所在組織の経過です。2 日で半影を危険組織に数えなくするのは PET の低酸素生存組織減少に基づく選択で、実測期限ではありません。小脳と穿通枝供給のない延髄は一般の側副血行到達組織経過を使い専用校正がないため、同流量では専用校正を保持した橋より長く生存します。
- **浮腫の量・時間は教材用近似**です。全 bed が同曲線ですが個人差は大きく、3D 変形は表面法線方向のみ（組織力学なし）で、誇張は見えるようにするためです。Ropper の帯は片側腫瘤の横偏位と意識の関係です。両側を片側のように合算し、両 MCA の 3 分の 2 が機能を失う間は少なくとも傾眠、両半球／両 MCA の 3 分の 2 が梗塞すると 2 週以降の生存者を意識障害とする 3 点は、体積別両側梗塞意識の症例系列がないためモデル選択です。
- 皮質穿通枝・小脳幹枝など小血管は**模式的**で、統計アトラスに合わせたのは主幹のみ。表面動脈と側副血行は皮質に沈まないよう溝を閉じた表面の上に描画します。画像だけを変え、血流モデルは元の血管長を使います。
- **脳メッシュに小さな隙間があります**。半球間と脳幹–小脳間の数 mm の隙間から、角度によって第三・第四脳室の短い部分（最大約 4 mm）が見えます。テント位置の半球–小脳間には意図的に約 3 mm の隙間を残し SCA 枝を通します。そのため接合部の後頭・側頭葉下面は約 2 mm（最大約 6 mm）薄く描きますが、領域体積と血流は不変です。実脳同様に小脳上面の大部分は後頭葉で覆われるため SCA 全体を見るには *View* で半球を隠すか皮質を透過させます。
- 症状・症候群・NIHSS は**損傷領域から推定**し実際の表現は多様です。出血性脳卒中、静脈洞血栓、血管炎などは**シミュレーションしません**。
- **血圧効果はモデル仮定**です。高圧ほど側副血流が増え梗塞が縮小（既定 93 mmHg 付近で非常に敏感）し、高圧自身の害はありません。実際の急性期では高・低圧とも不良転帰と関連し、薬物昇圧の支持は小試験のみです。MAP 120 mmHg からこの証拠と血栓溶解前の血圧上限を注記します。
- **後方循環の時間枠は校正**です。脳幹軟膜側副血行と遅い半影を ATTENTION、BAOCHE の傾向に合わせ、経路・値は実測でなく仮定です。単一脳底区間の校正で、下部と他区間が共に閉塞する長い血栓（AICA 起始も覆う）は中等度／不良側副血行で傍正中橋がコア未満となり、30 分再開通でも小脳を救う一方橋をほぼ救えず、同じ閉じ込め／意識障害を残します。ESO/ESMINT は BASILAR 登録で血栓負荷を含む BATMAN の全階層に回収の良好転帰関連を報告し、側副血行得点によらず再灌流を勧めます。長い血栓は不利であって無益ではなく、ここはモデル制限です。P2 は終末分岐まで覆う閉塞とし、1 皮質枝の側副血行が他枝を逆充填しないため未治療で通常の半盲を生じます。虫部の左右 PICA 吻合は弱くして、既定側副血行の内側 PICA 枝閉塞が前庭神経炎に似た単独めまいを生じるようにし、AICA・SCA との半球吻合はやや強くし、全 PICA も側副血行・早期再開通に依存します。外側延髄と同側の筋力低下（Opalski 型）は交叉後錐体路の最下部延髄領域がないため再現しません。
- **鎖骨下の非描画胸壁・頸部側副血行も校正**です。鎖骨下盗血でも安静脳底流が順行し、基準ではほぼ流れないよう設定しています。総頸動脈／腕頭動脈閉塞にも同じ接続が供給します（甲状頸動脈幹／上甲状腺動脈 → 外頸動脈 → 頸動脈分岐は総頸動脈閉塞後の造影で観察；腕頭閉塞では大動脈から内胸動脈経由で逆流鎖骨下へも）。そのため接続なしよりよく代償されますが強度は未測定です。
- **非運動症状の証拠強度は不均一**です。発汗、味覚、病的泣きの局在は主に症例系列・小研究で、重症度は模式的。REM 睡眠行動障害の証拠は相反するため橋／延髄梗塞後の晩期可能性のみで局在症状ではありません。視床下部がなく体温設定、概日、食欲、ホルモンは再現しません。中枢熱は症状でなく（虚血後初期熱は主に感染、文献の中枢高体温は主に出血）、昏睡を伴う両側上部橋／傍正中中脳–視床被蓋の広範梗塞後にリスク警告のみ。*Outcome* の集団頻度は症例予測ではありません。
- **ラクナは少数の典型部位**です。全て約 0.8 mL で主に軽〜中等度の典型症候群となり、内包最下部の小梗塞による重い片麻痺や大きさの差は未実装です。脳卒中後運動障害は主に集団頻度で、特定小領域の 2 晩期型のみ可能性症状にします：傍正中中脳後 Holmes 振戦と後脈絡叢動脈後の不規則・ジストニア性・不安定な手。
- **脊髄は上端のみ**です。両椎骨動脈から起こる前脊髄動脈の C1–C3 を持ち、下方から合流する根髄動脈（MRA で 50 人中 24 人：Sheehy 2005）はないため、両椎骨が脊髄枝遠位で閉じると C1–C3 全梗塞となり頻度を過大評価し得ます。脳の回復曲線を使う脊髄筋力・感覚はほぼ戻りませんが、実際は数か月〜年で改善する例があります（Robertson 2012）。
- **回復・代償は模式的**です。機能・片側／両側損傷の集団平均で、訓練強度、年齢、併存症はなく個人回復を推定しません。CST 集束途絶時の回復低下、MCA 喪失による失語・無視の低下範囲／割合、Wernicke の半分〜5 分の 3 の範囲、脳幹下限 15 %、ボトルネックの症状閾値〜両側 40 %、外側中脳交感線維 35 %、利益とする救済 50 mL は推定です。長虚血後回復に別上限は設けません。広範初期虚血なしの脳底溶解で半数が 48 h まで時刻と独立に良好転帰（Strbian 2013）なので、晩期も残す梗塞で判定します。再開通後は 1 形の曲線を虚血時間で伸縮し全救済機能が最終回復しますが、実際は低灌流深度に応じニューロン喪失や他の遅延（stunned brain）があり得ます。領域性昏睡・傾眠は虚血開始固定 2 週で持続過眠、広範両側被蓋なら意識障害／閉じ込めへ改名しますが、実際の覚醒は数日〜週です。脳幹意識イベントは原因病変時計でラベルに追従し、脳底昏睡は壊死前救済被蓋が再機能するか改名まで、以後古典／不完全閉じ込め・意識障害が引き継ぎます。
- **再開通詳細は模式的**です。部分再灌流は灌流域割合の血流復帰で微小血管モデルなし。持続再閉塞は遅く未治療最終梗塞へ到達。無再流証拠は限定的、公表値は参照のみで動作を決めません。alteplase／tenecteplase は結果を変えず、選択時刻は投与でなく血流再開です。ラクナ単一枝は治療で開かず、遠位塞栓の eTICI は造影でなく枝の正常流量割合から得ます。
- **モデルは死亡を表現しません**。減圧なしのヘルニアは通常致死的で「死亡の可能性が高い」とします。両半球／両 MCA 破壊には片側の生存数値を使わず、生存者は意識障害と注記し、両側下行ヘルニアに片側生存者の転帰を使いません。手術なし小脳腫脹昏睡は無治療昏睡対照がなく信頼できる死亡値がないため「生命を脅かす」。未開通脳底閉塞自身（脳幹／視床）の昏睡は閉塞時から「しばしば致死的」（試験内科群 90 日死亡 55% と 42%）。重なる半球腫脹昏睡はヘルニア独自リスク。閉じ込め・両側内側延髄梗塞は通常致死的とはせず、約 60%・24% の大きな死亡率を *Outcome* に注記します。その後と 3・6 か月 NIHSS は生存を仮定します。
- **Outcome は同じモデルを 2 回実行**します。未治療は再開通なしの同閉塞で実患者対照ではなく、致死経過 NIHSS 欄に生存条件を記します。3・6 か月は初イベントからの最後の 2 時点ですが、最終梗塞は最終血管変更後 6 か月です。後発変更は評価を 6 か月停止後へ移し、正確な差を明示します。「6 か月で未安定」は途中で梗塞・表示障害の重症度／群が変わる場合のみ。代償割合が月に約 1 点増えても群変更時のみ数え、晩期イベントと最終領域は再評価しません。「顕著／一部代償／大部分代償」の 25 %・60 % は可読性基準。最終体積は頸髄を含みその量を明示し、ニューロン推定は脳のみ。領域一覧は自身の 5 % 以上梗塞または最終梗塞の 10 分の 1 を保持する領域で、両閾値も可読性の選択です。
- **軟膜吻合の強さは手動**です。等級と接続する両動脈の流量で容量が増えます。凸面 ACA–MCA は供給流量 1 mL/min 当たり各 MCA 枝にほぼ同容量（以前は運動帯が約 1.7 倍で、中等度中心前枝閉塞に無症状）。PCA–MCA は後頭頂・側頭後頭へ多く、中等度単独閉塞は無症状。前・後側頭は吻合なしで等級によらず全障害です。
- **大脳軟膜動脈は左右鏡像ですが全てではありません**。脳・灌流アトラスは非対称で、以前は追跡長・供給組織をそのまま用い、良好側副血行の右鳥距閉塞は残存視野障害なし、左は半盲でした（左側頭後頭 115 mm、右 98 mm、左は 4 分の 1 多い組織で側副流不足）。現在 A2・M2・P2 と皮質枝／軟膜吻合は左右長・基準流量の平均を使い、灌流圧は約 1.5 mmHg 内で同じですが、組織・梗塞体積はアトラスのまま。Willis、穿通枝、椎骨脳底・小脳は後方校正のため元の長さで、供給区分も左右差（右上頭頂小葉はより ACA）があります。閾値付近の ACA 後皮質感覚や良好鳥距後中心暗点は片側だけ、または片側で遅く消える場合があります。
- **一側閉塞が対側側副血行を供給する場合があります**。単一抵抗網なので特に A2・P1・P2、また小脳・MCA 枝閉塞が残る輪・脳底先端圧を上げ、対側軟膜血流を増やし主に対側 MCA 梗塞を縮小します。大梗塞の約 5 分の 1 まで（良好右下部 58 mL → 左 P2 併存 46 mL、右上部 68 → 左 A2 で 59、右 M1 163 → どちらでも 155）、小病変ではさらに大きい割合（中等度角回 7 → 対側 P2 で約 4.5 mL）。良好／中等度の両半球単閉塞 512 組の約 5 分の 1（不良ではなし）、12 組は合計が大きい単独より小さくなりました（右 P1 と左下部分枝：単独 59 mL、合計 51 mL）。実際の大動脈圧損失は小さく輪は全身圧に近いため効果は無視できるはずです。除去には血流モデル変更（他枝の増圧を側副から除くか動脈自動調節）が必要で、全対象合併例の体積・腫脹・ヘルニアを動かすため制限として残しています。
- **障害は整数段階**です。肢完全麻痺／少し動く、NIHSS 5 の 4／3 など、境界の微量組織が等級を変えます。不良側副血行の中部脳底は 12 h に橋腹側が梗塞し、その時の回収は 0.2 mL 救済（下部橋底が未治療 63 %、治療 59 %）で 3 か月の四肢が完全不動から少し動く（NIHSS 24 対 20）。閾値は除けないため文で量を示し差を再開通の利益に数えませんが、*Outcome* には両得点が出ます。
- **実症例を後から判断するために使わないでください**（「血栓回収なら変わったか」など）。平均値の標準脳なので答えは仮定のみを反映します。
- 医学内容は開発者が教科書・論文から編集し、**正式な臨床専門家レビューは未実施**です。誤りは issue で知らせてください。

<a id="development"></a>
## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # エンジン、コンポーネント（jsdom）、文書、出力不変条件：全規則の発火、治療で梗塞が増大しないこと、症状のちらつきがないこと、文書とデータの数値一致など
npm run lint && npm run typecheck
npm run build      # 相対パスの dist/ を生成し、任意のサブディレクトリに配備可能
```

テストはエンジン、コンポーネント（jsdom）、文書、出力不変条件を対象とし、規則発火、治療による梗塞非増大、症状の非ちらつき、文書とデータの数値一致などを確認します。ビルドは相対パスの `dist/` を生成し任意のサブディレクトリへ配備できます。

<a id="regenerating-the-anatomy-assets"></a>
### 解剖アセットの再生成

`public/data/brain.{json,bin}` と `src/anatomy/generated/*.json` は追跡済みで、通常開発では再生成しません。血管・領域の `src/anatomy/` を変更後：

```bash
python3 -m pip install -r tools/requirements.txt
npm run assets:build    # = vite-node tools/export-anatomy.ts && python3 tools/build_assets.py
```

初回は公開アトラス約 80 MB を git 除外の `tools/.cache/` に取得し、約 1 分かかります。

<a id="deploying-to-github-pages"></a>
## GitHub Pages への配備

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定（初回のみ）。
2. `main` にマージ、または Actions の *Deploy to GitHub Pages* を手動実行。
3. `.github/workflows/deploy.yml` がテスト・ビルドし `dist/` を `https://<user>.github.io/<repo>/` に公開。

Vite の `base` は `'./'` で全アセットは相対パスなので、改名・独自ドメインでも変更不要です。状態は `#` 以降にありサーバールーティング不要です。

<a id="project-layout"></a>
## 構成

```
src/
  anatomy/     血管、領域、症状、症候群、変異、教材、時間軸、再開通の証拠、出典（sources.ts）
    generated/ tools/build_assets.py が生成（灌流単位体積、位置調整済み血管経路、作図血管経路）
  engine/      solver → hemodynamics → schedule / treatment → tissue → edema / cascade → recovery → clinical → simulate；塞栓
  scene/       react-three-fiber の 3D 場面
  components/  パネル（症例、教材、血管、現在、転帰、詳細）、時間軸、Willis 動脈輪・脳幹の図
  ui/          UI の純粋関数（症例要約、転帰、治療選択、書式）、各関数に単体テスト
  state/       zustand ストア、URL 同期
  i18n/        画面文字列（繁体字中国語／簡体字中国語／英語／ドイツ語／日本語）、機能ごとに分割
tools/         アセット処理（Python）と解剖データ出力
public/data/   脳メッシュ（バイナリ）
docs/          画面画像
```

`anatomy/` は血管・領域・症状・症候群・変異・教材・時間軸・再開通証拠・出典、`generated/` は体積と血管経路、`scene/` は 3D、`components/` はパネル・時間軸・図、`ui/` は個別テストされた UI 純粋関数、`state/` はストアと URL 同期、`i18n/` は機能別翻訳です。`tools/` は Python アセット処理と解剖出力、`public/data/` は二進メッシュ、`docs/` は画面画像です。
