The arteries of the cerebrum, cerebellum and brainstem on a real MNI template brain. Block one or more vessels (or
release an embolus) and follow what happens to **other** brain regions **from minutes to months**: penumbra turning
into infarct, oedema and mass effect, herniation, hydrocephalus, remote degeneration… — which regions and which
**functions** are failing, still salvageable or recovering at each moment, and what is left at the end of the course.

**Live:** <https://lzong-tw.github.io/brain-vessel-map/> (GitHub Pages has to be enabled first, see *Deploying* below)

![3D view: left M1 occlusion reopened at 4.5 h; the Case panel on the left, the Outcome tab on the right](docs/screenshot-3d-en.jpg)

## How to use it

1. **Pick a starting point**: load a teaching case from *Templates* (e.g. left M1 embolism, locked-in syndrome), or press "+ Block" on any artery in *Vessels*. A template's *Add* button and a vessel's "+ Block" **add to** the current case, so several arteries can be combined (e.g. mid-basilar + right PICA).
2. **Shape the case**: the *Case* tab has three cards — *Before onset* (collaterals, blood pressure, circle-of-Willis variants), *Occlusion events* (the degree and timing of each vessel, e.g. a TIA first and complete occlusion three days later) and *Treatment* (when, how and how well the artery is reopened; decompressive surgery). A closed card still shows a one-line summary, and a line above the timeline summarises the whole case.
3. **Move along the timeline** from onset to 6 months. *Now* shows the tissue, symptoms, NIHSS and events at that moment; *Outcome* shows how the course ends (and, with a treatment set, compares it with the same occlusion left closed); *Details* shows the selected vessel or region. *Now* says that the penumbra "can still be saved" only while the model still offers a reopening (within a day of the occlusion's start, before any reopening) and that it "may still be lost" after that; the amount it quotes is the part of the penumbra that the flow it has now still kills, and the rest, which survives on its collaterals even if the artery stays closed, is named apart; after a reopening that brings blood back to only part of the territory (an eTICI grade below 3, no-reflow, a clot fragment downstream) it says that tissue is still dying where blood has not come back, or has died since, not that the penumbra stopped dying; a small infarct, such as one in the brainstem, counts as growing once it grows by a tenth of its size (or by 0.5 mL).
4. **Share**: the whole case lives after the `#` in the address — copy the URL.

The brainstem is made of compact tracts and nuclei: its deficits fade with how much is infarcted or still recovering, rather than all appearing or vanishing together at a threshold. ## How the simulation works

1. **Geometry**: `tools/build_assets.py` downloads MNI152NLin2009cAsym segmentations and probability maps from TemplateFlow and meshes them with marching cubes; every surface point is labelled with a functional region and an arterial territory (a *bed*). Territories come from the Liu et al. arterial atlas; where they overlap is the watershed.
2. **Blood flow**: every vessel is a Poiseuille resistance; each bed is shared by one or more supplying arteries; collaterals conduct according to their grade (good / moderate / poor); arterioles dilate as perfusion pressure falls (autoregulation, up to 1.8×). The brainstem also has undrawn leptomeningeal collaterals, which constrict when blood pressure is above normal; the subclavian arteries have undrawn chest-wall and neck collaterals, which feed the arm together with the reversed vertebral artery when the subclavian is blocked proximally. A vessel only some people have (a persistent trigeminal artery) exists only when its variant is chosen, and vessels a variant removes are not drawn. The pial arteries over the hemispheres (A2, M2 and P2 with their cortical branches) and the anastomoses between them take the mean of the two sides' lengths and baseline flows, so that the same artery blocked on either side gets the same flow (see the limitations). A linear system gives the pressure and flow everywhere.
3. **Staged course**: occlusions can start at different times, reopen by themselves or progress, and treatment can reocclude or send fragments downstream; the flow is solved once for every stretch in which the occlusions stay the same, and the tissue follows that flow history. Time 0 is the first event; the cascade and recovery run from the occlusion that causes most of the infarct (each lesion's swelling on its own clock, below; without an infarct, from the latest one that makes tissue ischaemic, each earlier attack told as an attack of its own), while each region's late symptoms, compensation and the relabelling of its coma count from when that region itself became ischaemic, and those of a herniation's secondary infarct from when the swelling lesion that herniated began (the hemisphere on its own side: a malignant right M1 infarct's herniation infarcts do not start over when a left M1 occlusion a month later becomes the index event, and their leg weakness keeps its compensation). What a time shows is the case as it stands then: an occlusion that begins later is not known yet and changes nothing before it begins — not the swelling, the level of consciousness, the events or the forecast of the course on *Now* (a stenosis that will occlude simply lasts until then); the *Outcome* tab, and the final-infarct line that leads to it, show the whole schedule. Once the later occlusion has begun, each lesion still swells and herniates on its own clock, with its own oedema events (the malignant oedema or mass effect, the herniation and the infarcts it causes, crossed cerebellar diaschisis, a cerebellar swelling), so an earlier infarct does not lose its swelling or its herniation infarct when a larger occlusion begins, tissue a herniation has killed stays dead when a later occlusion would have infarcted it too, and what has begun of the swelling course (the oedema, the herniation, the fatal-herniation note) is not removed, retitled or ended before the later occlusion began, nor are the events of a treatment or a reopening that have begun (the treatment windows, the recanalisation and what followed it, an artery reopening by itself, the circle of Willis switched on, the cortical signs of a striatocapsular infarct): a swelling told otherwise because of the later lesion (a moderate mass effect becoming a malignant course) is told so from the later lesion's first day. Each hemisphere's swelling, and the cerebellar one, is classified by its own lesion (the beds whose lesion began within a day of it; for the cerebellum every cerebellar infarct whose swelling overlaps it, earlier or later, as the posterior fossa's course is told by the infarct's size alone: its course runs from when the infarcts begun by then reach its size, so two cerebellar infarcts a few days apart swell the same way whichever began first, and a course told before the later one began stays as told), each lesion swells by the size of the lesions swelling with it, a later one counting only as it swells itself (so an earlier swelling does not jump when a later occlusion begins), and two hemispheres are held together against the sizes of one malignant infarct only when their lesions began within a day of each other (their swelling still counts together while it overlaps); the other events (the hyperacute mechanisms, imaging, haemorrhagic transformation, seizures, late degeneration) run on the clock of the one that causes most of the infarct, a simplification of stacked strokes. A text giving a time "after onset" counts from that index onset; a swelling's texts count from its own lesion and say so when that is another (a right hemisphere's herniation that eases 279 h after its M1 closed is told so, also when a left M1 a month later is the index event). Ischaemia of the brain that leaves no infarct is told, while its deficit lasts, as the acute stroke nobody can yet tell from a TIA: the treatment windows of its occlusions, without waiting to see whether it clears, and antiplatelet drugs only once imaging has excluded a bleed; the TIA story ("symptoms gone does not mean safe" and the antiplatelet advice, after thrombolysis only from a scan at 24 h) starts when the symptom list shows no deficit any more (Powers 2019; Easton 2009). Ischaemia of the upper cervical cord (the anterior spinal artery's territory) has a story of its own (the spinal cord infarct, MRI of the spine, the course after it), beside the brain's when the brain is ischaemic too; an arm or the face alone gets no story.
4. **Tissue fate**: relative flow < 30 % is ischaemic core, 30–55 % is penumbra, 55–85 % is mild oligaemia. How fast tissue dies depends on how little flow it gets and for how long. Where an end artery leaves no flow at all (the grey matter of the deep perforator territories, such as the striatum and thalamus), loss starts after about 6 minutes and most of it is gone within a quarter of an hour. The white matter those perforators feed (the internal capsule and corona radiata) holds out longer: nothing is lost for about 2½ hours, then about half by 4 h and most by 6 h, fitted to how often thrombectomy spared the internal capsule at each time to reperfusion. A lacune (one branch of a perforator bundle) is lost on the course of the tissue it lies in, behind one branch as behind the whole bundle, and takes no more of a structure than its bundle feeds there: a capsular branch closed for an hour leaves no more of the capsule than the whole lenticulostriate group closed for an hour, that is none, and its function comes back over the following hours as the capsule's does behind the whole group. So an M1 occlusion reopened within 1–2 h still leaves the striatal infarct but usually spares the arm; reopened at 6 h it rarely does. The final region list and the region details show a lacune at its own volume and share of the structure (about 0.8 mL: 6 % of the corona radiata, 38 % of the posterior limb), in agreement with the final infarct above them; what it costs of the structure's function (most of it) shows as the region's dysfunction, and the region details say why so small an infarct costs so much. Where its site uses the structure's own deficits (the caudate head, the lower pons, the lateral medulla), a lacune costs no more of that function than its whole bundle does: a Heubner branch no longer leaves a lasting dysarthria that the whole Heubner artery does not, and an inferior paramedian pontine branch no denser a hemiparesis than its whole group (a site with a syndrome of its own, such as a pure motor or an ataxic hemiparesis lacune, keeps most of the function of its tract). Tissue that collaterals still reach (cortex, white matter, cerebellum) loses nothing in the first 20 minutes; then without any flow about half is lost by 2½ h, just below the core threshold about half by 6 h, and the penumbra more slowly still (the lower its flow, the faster; without reopening at most 85 % of it survives on collaterals and regains its function over about 12 h). Two days after its ischaemia began, tissue no longer counts as penumbra unless it is still dying: by then the penumbra has either died or survives (in PET with a marker of hypoxic but viable tissue, such tissue became rarer and smaller over the first two days: Read 2000; Markus 2004), so from day 2 the penumbra shown is about what the course still loses, and the rest is surviving tissue that is still silent, regaining its function as before (*Now* and the region details name it so, as they name the tissue a reopening rescued, not as dead tissue). Behind an M1 occlusion with poor collaterals the infarct is about 60 mL at 1 h and grows by 35–55 mL/h over the first hours, filling the territory by about 12 h (the fastest growth measured in large-vessel occlusion is about 74 mL/h); with moderate collaterals it grows by 20–30 mL/h. Untreated, everything below the core threshold still dies, so the final infarcts are as before; only the time course is slower, and an early reopening now saves tissue even with poor collaterals. Tissue rescued by a reopening regains its function over hours to days, not at once: about a quarter at once after an hour of ischaemia, half within about 2 h after an hour and within about a day after 6 h, the rest over weeks (a TIA of minutes clears at once). The retina starts to die only after about 12 minutes of complete occlusion (a human estimate; monkey experiments give much longer), so amaurosis fugax lasting minutes leaves no infarct. The brainstem penumbra dies more slowly and survives less often without treatment — a calibration to the basilar thrombectomy trials (ATTENTION, BAOCHE). A single-perforator (lacunar) occlusion changes no flow the model sees; its tissue stops working from the moment the branch closes, and a branch that reopens before its tissue starts to die (within minutes, or within about 2½ hours in the capsule and corona radiata) leaves no infarct (a capsular TIA). No collateral reaches the white matter behind a perforating end artery, a single branch or the whole bundle: *Now* says that it is still alive because white matter takes hours to die with no flow at all, not that collaterals hold it. The final infarct is evaluated 6 months after the last change to the vessels.
5. **Treatment**: reopens the complete occlusions present at the chosen time. The reperfusion grade (eTICI) sets the share of the territory that follows the reopened course; the rest follows the untreated one. No-reflow, reocclusion and distal emboli each modify that course. "Saved" = tissue that would have infarcted untreated and survives treated, including the territories a herniation of the untreated swelling would have infarcted (the untreated final infarct less the treated one). Once a treatment has reopened the artery, the *treatment windows* end (so they do when the artery reopens by itself and leaves an infarct), and they come back for the rest of the first day once a treated artery has closed again (a reocclusion), still counted from the onset; an eTICI 0 attempt is summarised as "attempted, not reopened", and a treatment that finds nothing it can reopen (IV thrombolysis for a lacunar occlusion, which the model does not reopen, or a time when nothing complete is occluded) is named as given then, with no eTICI grade, no treated-versus-untreated comparison and nothing "saved". eTICI grades the reperfusion of the whole downstream territory on the final angiogram (3 = 100 %, 2c = 90–99 %, 2b67 = 67–89 %, 2b50 = 50–66 %: Liebeskind 2019), so a downstream branch that a clot fragment blocks lowers the grade shown by the share of the territory's normal blood flow it supplies (an inferior-division embolus during an M1 thrombectomy turns a chosen 3 into 2b50): the grade chosen is that of the rest of the territory, and an embolus to a new territory is reported apart and leaves it as chosen. An artery that reopens by itself and leaves an infarct gets an event and a *Now* sentence of its own, with what it saved against the same case had it stayed closed (spontaneous recanalisation in about a quarter of occlusions in a meta-analysis of 53 studies: Rha & Saver 2007); one that reopens before anything dies is told as a TIA. It is judged as a treated reopening is: what a herniation of the swelling finds alive is that of the same case had the artery stayed closed, so it ends as a complete thrombectomy at the same hour does and never larger than the closed artery. The treatment windows of a later occlusion quote as the core what its own lesion has killed when treatment is decided, not an earlier infarct; and within 3 months of an earlier infarct (begun at least a day before; a model choice) they say that IV thrombolysis is not standard: guidelines advise against it, a relative contraindication resting largely on expert consensus, with more symptomatic haemorrhage in a registry only within 14 days of the earlier stroke (Shah 2020; Scala 2026). The recanalisation event gives the NIHSS at 3 months with and without the treatment, and shows the treatment as a benefit when it avoids a deficit (at least 2 points), a course that is often fatal (a herniation, a brainstem compression, an unreopened basilar occlusion with coma) or at least 50 mL of infarct: preventing a locked-in syndrome saves only a few mL of pons; conversely, the model's NIHSS of an untreated fatal course is that of a survivor, the NIHSS scores a right-hemisphere infarct lower than a left one of the same size, and the final infarct volume predicts the functional outcome on its own. The same NIHSS on both sides is never written as a difference ("about X instead of X"): the event says that the scale shows little of it and how much brain the treatment spared, and the column of a course that is usually fatal says "if the patient survives", in the event and on the *Outcome* tab. A reopening that saves a sliver of tissue, under 0.5 mL and under a tenth of the infarct the course would leave without it, is not credited with a difference in the NIHSS that the sliver tips at the edge of a grade (see the limitations): the event says so and is not shown as a benefit for it, and the incomplete locked-in event does not say that the reopening saved part of the pons; nor does it when the limbs would have moved again by then (within a day) without the reopening, as after a mid-basilar occlusion with good collaterals reopened at 2 days, whose limbs move again at 9 days with or without it; a saving from 0.05 to 0.5 mL is quoted to a tenth of a millilitre, not as "~0 mL"; whether a saving is a sliver is judged on what the reopening spared, not net of what a clot fragment it sent infarcted elsewhere. A small brainstem infarct is not a sliver: reopening a lower-basilar occlusion at 6 h with poor collaterals saves 0.4 mL of 1.5 mL and keeps its credit.
6. **Oedema**: each bed accumulates cytotoxic, ionic and vasogenic oedema and later atrophy from its core, penumbra and reperfusion; the swelling volume becomes a midline shift (mostly outward after decompressive craniectomy), and consciousness falls with the shift by approximate bands (Ropper: drowsy from about 4 mm, stupor from 6 mm, coma from 8 mm). When both hemispheres swell they push the brain down rather than across and the midline moves less: the model then counts their swelling together, as if it were one hemisphere's, for the level of consciousness. Whether a hemisphere herniates, and when, follows its own swelling (the midline shift it would give alone): it herniates from day 3 while that swelling stays in the coma range, so a smaller swelling of the other hemisphere, which pushes back, never takes a herniation and its secondary infarcts away; when the other hemisphere's swelling is too small to have an oedema event of its own, the swelling of both together pushing from this side also herniates it while it stays in the coma range, as it keeps the coma. It herniates to its own side (uncal and subfalcine) when the midline is pushed across from it by 4 mm or more as the herniation begins; otherwise the two are pushed down together (central herniation: no subfalcine herniation, no one-sided third-nerve palsy), and each hemisphere that would herniate on its own keeps the secondary infarcts its own swelling causes — its posterior cerebral territory against the tentorial edge, as after tentorial herniation from masses on one or both sides (Keane 1980), and its anterior cerebral territory against the falx (a model choice: with both swelling no cingulate gyrus slides under the falx); when neither would herniate alone but their swelling together reaches the coma range, the central herniation adds no secondary infarct (which side or how much cannot be told; a model choice). With at least two-thirds of both MCA territories out of action the patient is at least drowsy in the first two weeks, whatever the swelling. By their size, two hemispheres take the malignant-oedema and herniation course together only when both have an MCA infarct large enough to swell (the evidence for a malignant course is for MCA-territory infarcts): two ACA or PCA infarcts (or an MCA infarct on one side and an ACA infarct on the other) give a moderate mass effect on each side, whose swelling still counts together for the level of consciousness; a side at risk only together with the other says that both are counted together, never "> 145 mL carries high risk" beside a smaller volume of its own. Whatever the sizes, a swelling that reaches the coma range (8 mm, one hemisphere's or both together) is a malignant oedema and herniates from day 3 while it stays there: both carotid territories (MCA and ACA) infarcted, each under the malignant sizes, swell together into a coma and herniate downward, with the fatal risk, rather than lying in a coma for a week and waking; so does a single hemisphere of about 245 mL whose own midline shift reaches 9 mm. In the model a coma from swelling always comes with this course; a stupor (6–8 mm) does not. When two-thirds or more of both hemispheres end up infarcted (with the secondary infarcts of a herniation), or two-thirds or more of both MCA territories (which carry much of the white matter that connects the cortex with the thalamus), with a herniation or without one, a survivor is listed in a disorder of consciousness (a vegetative or minimally conscious state, NIHSS 1a = 3) from two weeks after the newer of the two lesions, not woken into an alert patient (Adams 2000; Multi-Society Task Force 1994), and the *Outcome* tab gives both hemispheres their own note instead of the survival figures of one.
7. **Cascade**: simplified thresholds from the literature (e.g. > 145 mL infarct within 14 h → malignant oedema; cerebellar infarct ≥ 20 mL → watch for swelling, ≥ 38 mL → malignant swelling likely) project consequences onto regions that were **not** occluded. The circle of Willis is said to be switched on only when it carries blood into the territory beyond an occlusion or a narrowing: a junction whose feeding arteries at rest are all blocked, narrowed or fed from such a junction, into which the flow of the anterior or a posterior communicating artery, or of the ophthalmic artery, rises by more than 5 mL/min (a model choice). So it bridges a blocked carotid, A1, P1 or basilar artery, and a carotid T clot to the ACA, but never an occluded MCA, A2 or P2, which lie beyond the circle; the event names only the routes that carry blood (the ophthalmic artery alone when both communicating arteries are absent), and says that they fall short, with the infarct of that territory, when one still develops. It is told as enough to prevent an infarct (green) only when that territory also keeps working while the artery is closed: a carotid T or a basilar artery closed for a few minutes, where nothing infarcts because the attack is short, is told as not keeping its territory working while it is closed (the deficits come from there), until the artery reopens. (A reversed communicating artery told nothing on its own: the direction of the anterior one at rest is arbitrary in a symmetric network, so it "reversed" with M1, M2 and A2 occlusions on one side and never on the other.) The cortical signs of a striatocapsular infarct (Donnan 1991) begin at onset when the occlusion never reached the cortex (the lenticulostriate arteries alone), and at the reopening when an M1 occlusion reopened before the cortex died, as the cortex regains its function; they name the deep structures that die (not the internal capsule that an early reopening spares).
8. **Symptoms, syndromes and recovery**: every region lists the symptoms of its loss (ipsi- or contralateral); these are combined and matched against named-syndrome rules. A syndrome named for its signs (neglect, Wallenberg, pure sensory lacunar syndrome, locked-in, retinal ischaemia, inner-ear stroke…) is listed only while those signs are in the symptom list (the retinal-ischaemia label not while aphasia or a lowered consciousness leaves the monocular vision loss unexaminable: that sign is named apart then, with why, and the label comes back with it); one named for its vascular pattern (a territory, a watershed infarct) stays while the tissue is damaged and is marked "clinically silent" once no symptom from that side is left, listed or not examinable. The ACA label names an infarct of the medial frontal or cingulate cortex together with another region of the ACA territory, also when collaterals save the paracentral lobule and with it the leg. The watershed labels need a haemodynamic setting on their side, as their text says: a mean arterial pressure below 70 mmHg, or a tight (≥ 70 %) stenosis or an occlusion of the carotid or of the M1 segment (Bogousslavsky & Regli 1986; Wong 2002); a single distal branch blocked by an embolus is a branch-territory infarct even where its territory lies in border-zone beds. These thresholds are the model's choice. The superior- and inferior-division labels of the MCA use the symptoms' own threshold (25 %), so they last as long as the deficits they name; on the left neither is shown beside an aphasia of the other division (an expressive one beside the inferior label, a receptive or conduction one beside the superior) or beside a global or mixed transcortical aphasia; and the inferior-division label is shown only beside one of the signs it names, listed or not examinable (on the left a receptive or conduction aphasia, on the right left neglect or a visuospatial deficit, on either side a field defect): a right M1 reopened at 4.5 h with good collaterals, whose neglect is compensated by 3 months, keeps its striatocapsular label but no longer this one (nor is this label kept as clinically silent once its signs have gone). The complete-MCA label names the picture of the whole territory, not a segment (an M1 occlusion is the usual cause, a carotid occlusion whose collaterals fail another), and is shown only beside the weakness or sensory loss it names (of the face, arm or leg, or of the face and arm or the whole side, listed or not examinable) or with the internal capsule infarcted: an M1 thrombectomy whose clot fragment blocks the inferior division leaves the striatum and that branch's cortex with the insula infarcted, four of the territory's cortical areas, beside a Wernicke aphasia and a hemianopia and no weakness at all, and is named by the inferior-division label; a border-zone picture in a haemodynamic setting is named by the watershed label instead: at least 35 % of the hemisphere's damage in the border zones or, when the damage reaches across the MCA territory (four of its cortical areas) and spares the cores of the territories around it (the ACA's and the PCA's own beds affected at most half as densely as the border zones, as a watershed infarct spares the cores of the territories that meet there), 35 % of the damage within the MCA territory and its borders. The second measure is there because the circle of Willis is not mirrored: behind a tight carotid stenosis at a low blood pressure it leaves more of the right ACA territory itself underperfused (16 mL of it against 5 mL on the left), and the share of the whole hemisphere alone named the same picture of the MCA territory watershed on the left and a complete MCA syndrome on the right. The anterior spinal artery syndrome names an infarct of the upper cervical cord. The language components of the damaged regions are combined into one aphasia type at a time (global, Broca, Wernicke, conduction, transcortical, mixed transcortical), from fluency, comprehension and repetition, and the type can change as components are compensated, but only towards a milder type, and a fluent aphasia does not become non-fluent again (Copenhagen aphasia study): a global aphasia that has become mild is listed as a Broca type, or as a Wernicke type when comprehension is more impaired than speech; while tissue rescued by a reopening regains its function, what lasts decides (an apraxia of speech, or a deficit from dead tissue, keeps the type non-fluent), and the passing oedema of days 2–5 deepens the components without making a global aphasia again. Uncommon phenomena that only a minority of patients has, such as release hallucinations in a blind field, are named "Possible:" and described as possible, not predicted; colour loss is not listed in a part of the visual field that is blind; macular sparing, the central vision a hemianopia keeps, describes the hemianopia rather than being a deficit, so losing it (when the swelling silences the occipital pole too) is not called an improvement, and *Outcome* names it beside the hemianopia without counting it among the lasting deficits; and what only an awake, cooperating patient can show, report or be examined for (behaviour, executive function, memory, initiative, mood, gait, colour vision, reading, writing, calculation, the agnosias and apraxias, unawareness of the deficit, the finger–nose test and fine hand movements, and what only the patient can report, such as vertigo, double vision and pain) is not listed while the patient is stuporous, comatose or in a disorder of consciousness. Nor are limb ataxia, a tremor of the moving arm or fine finger movements (a clumsy hand) listed on a side whose arm cannot move against gravity (or, for the ataxia, whose leg cannot move at all): the NIHSS scores no ataxia in a paralysed limb, and they cannot be shown by a limb that does not move; nor, for the same reason, an alien hand (grasping and groping of its own, or the left hand working against the right) or the apraxia and agraphia of the left hand from a callosal disconnection, in a hand whose arm cannot move against gravity; and these two signs of a callosal disconnection, told against the right hand (the left hand works against the right, and fails movements on command and writing that the right hand performs), are not listed while the right arm cannot move against gravity either. Gait and truncal ataxia, seen walking, standing and sitting upright (Carmona 2016), are not listed while neither leg can move against gravity: the patient can neither stand nor, the trunk weak from both sides, sit unsupported; with one weak leg the trunk can still be tested sitting, and it stays listed. Recognising faces and objects by sight, reading, finding the way, reaching under sight and visuospatial tasks need sight, and are not listed while the patient is blind (cortical blindness, or both half-fields lost without spared central vision; nor is a Balint syndrome named then). An awake patient in akinetic mutism, who hardly moves or speaks and does not act on request, cannot be examined for anything that needs them to act, answer or report (praxis, the alien hand, reaching, recognition, reading and writing, memory, the type of aphasia), only for what is seen. A patient who does not understand speech (a moderate or severe global, Wernicke or mixed transcortical aphasia) cannot be tested for what is tested through language — reading, writing, calculation, naming the fingers, verbal memory, awareness of the deficit, and what only the patient can report, such as vertigo, double vision, taste, position sense and pain — which cannot be told apart from the aphasia, so it is named apart; the apraxia of both hands, tested by imitating the examiner's gestures without language, stays listed (De Renzi 1980), but not the apraxia and agraphia of the left hand from a callosal disconnection, which is told by the left hand failing commands and writing that the right hand performs (Watson & Heilman 1983); the left hand working against the right is seen, not asked for, and stays listed. Speech (an aphasia, a slurred or hoarse voice: items 9 and 10) and neglect (item 11), which the scale still scores in a stuporous patient, stay listed then and are left out only in coma, where those items are scored for an unresponsive patient; speech is not listed in a disorder of consciousness either, which is scored as mute. These deficits have not gone: *Now* (the summary line and the symptom list), the function heat-map (dotted cells and the cell details), the region details and the *Outcome* tab (its deficit count included) name them apart as not examinable now, with the reason (the level of consciousness, blindness, akinetic mutism, not understanding speech, a paralysed limb), not as improved or resolved; they are listed again once they can be examined, and the NIHSS does not drop for them. The NIHSS estimate follows the scale's own scoring rules (mild weakness = drift, 1 point; limb ataxia counts limbs, a mild one of a body side as one and a moderate or marked one as its arm and leg, 2; no ataxia score when the patient cannot understand or is paralysed; stupor and anarthria also count on the questions item (1b), and a stuporous patient, who does not comprehend the questions (1b = 2), performs at most one of the two commands (1c at least 1); a severe aphasia or little speech (item 9 = 2) answers at most one question (1b at least 1); bilateral sensory loss from a brainstem lesion scores 2; a mute global aphasia (item 9 = 3) follows no command (1c = 2) and scores as mute on dysarthria (10 = 2); a disorder of consciousness is scored as such a mute patient who follows no command, which is what the bedside examination finds — if answers by eye movement are found, the person is locked-in and would be scored as alert, which the model cannot simulate; an akinetic mutism is scored as an awake patient who is mute (9 = 3, 10 = 2), performs no command (1c = 2) and cannot answer for a reason other than aphasia (1b = 1)). Both frontal eye fields lost do not give two opposite gaze deviations but a voluntary gaze paresis to both sides; a deficit of both body sides from the upper cervical cord and the same deficit of one side from the medulla are listed once per side; and a part of a broader deficit of the same side that is no more severe than it is listed as that deficit, as a quadrantanopia is part of a hemianopia (a plegic arm has no milder weakness of the shoulder of its own; a hemisensory loss of all modalities takes in the pain and temperature, position-sense, face, arm and leg losses of that side; a whole-face peripheral palsy takes in the weakness of the lower face), while a part more severe than the whole is listed beside it as what is worse there (a face and arm that have lost more sensation than the rest of the side). Early on, oedema and remote depression add temporary dysfunction (it can keep and deepen a deficit, but after an artery has reopened it does not bring back one that cleared when blood returned: a rescued basilar occlusion does not turn into a locked-in syndrome on day 3); later, each function is compensated according to how much backup it has. *Now* calls a deficit of a function without backup one that will not improve only once all of it comes from dead tissue: not while the oedema around the infarct still deepens it, a swollen neighbour compresses its pathway or the tissue is alive but still silent, and not at a stop where it has just improved. An aphasia and a (right-hemisphere) neglect are taken over mainly by the spared cortex of the same hemisphere, less well by the homologues of the other: once more than six tenths of that hemisphere's MCA cortex is infarcted the share taken over falls, to about a tenth when nearly all of it is, so a survivor of a whole-territory MCA infarct still has a global or a severe Broca or Wernicke aphasia, or a severe neglect, at 3 months; a branch (M2) infarct and an early reopening recover as before (most patients with aphasia recover well, persistent moderate or severe deficits being common only with extensive damage throughout the MCA distribution or extensive temporoparietal damage: Wilson 2023). Comprehension is taken over through what is left of Wernicke's area itself, whatever the size of the whole infarct: once more than half of it is infarcted the share taken over falls, and from about three-fifths a Wernicke aphasia stays moderate to severe (NIHSS 9 = 2, neither question answered) at 3 and 6 months, while with half of it or less it recovers to a mild one (Naeser 1987; a persisting Wernicke's aphasia usually also involved the supramarginal and angular gyri: Kertesz 1993); a global aphasia that improves after such an infarct becomes a severe Wernicke type. A gaze deviation does not depend on the size of the lesion: the other frontal eye field takes it over within days (Steiner & Melamed 1984). The brainstem is made of compact tracts and nuclei, so a small infarct cuts a share of the fibres: below the symptom threshold its deficits are still graded by the share lost, down to 15 % (smaller shares stand in the model for the edge of a region fed by a neighbouring artery, such as the medial medulla in a Wallenberg syndrome or the midbrain in a Percheron infarct), so the signs of a recovering brainstem fade rather than vanish together, and an infarct just under the threshold leaves a deficit in proportion; the signs of both sides together (anarthria, the bilateral dysphagia, breathing) still need both sides at the threshold, and below it what is left is the picture of each side (a dysarthria, a weakness of each side). Below the threshold a brainstem region grades only its own deficits: it does not count as a loss of that side's pathway, so the fifth of a cerebral peduncle that a P2 occlusion infarcts, or the edge of the medial medulla that a vertebral occlusion reaches, does not slow the recovery of a weakness from the other hemisphere, and small infarcts of both sides below the threshold are taken over as one-sided ones. Nor is the passing weakness of a thalamic infarct (from the capsule beside it) a lost pathway, and a lateral medullary infarct, whose facial weakness is on its own side, cuts only some of the other hemisphere's fibres to that face, those that loop down into the medulla after crossing (in some people: Urban 2001), while most cross in the pons; its central facial paresis was mild in all who had it and gone by discharge (Kanbayashi 2021). So it is no lost pathway at all: beside a motor-cortex infarct of either side, the face weakness from the cortex and the medullary one each recover as they would alone (the medullary one is gone by 3 months beside a right M2 infarct as without it), and it is two-sided only when both hemispheres' own tracts are cut. While a brainstem region's own tissue is below the threshold, the passing depression of the swelling does not push it over and give a new hemiparesis on day 2 (nor over a deficit's own, higher threshold: no Horner syndrome or drowsiness for a few days only); the part of collateral-held penumbra that will still die counts as dysfunctional. An arm or leg weakness that was plegic at first and comes from where the corticospinal fibres converge (the posterior limb of the internal capsule, the cerebral peduncle, the basis pontis), with half or more of that region infarcted, is taken over much less: the arm stays moderately weak (NIHSS 3) rather than recovering to a drift, the leg recovers better (only 1 of 28 such patients regained isolated arm movement against 3 of 4 with purely cortical strokes: Shelton & Reding 2001); a small lacune there spares part of the tract and keeps the usual share. Where both sides are cut at a bottleneck (the cerebral peduncles or the ventral pons), the more of both sides is lost the less is taken over: nothing more is taken away at the symptom threshold, the full effect comes at the share of both ventral pontine halves at which the model names the classical locked-in syndrome (40 %), and the bottleneck is named (on the *Now*, region and *Outcome* tabs) only from about a third of both sides. A quarter of both peduncles infarcted after a bridged reopening (0.8 mL) is a two-sided lesion that recovers to a mild weakness, not a locked-in syndrome (bilateral pontine infarcts leave a worse outcome than one-sided ones: Kumral 2002; yet even extensive bilateral pontine lesions on DWI do not always mean a poor outcome after a reopening: Haussen 2016). The eye of a third-nerve palsy shows no Horner syndrome of its own: with both the constrictor and the dilator of the pupil denervated, the pupil is mid-position and unreactive, and an oculomotor palsy with a Horner syndrome can look pupil-sparing (Serdaru 1983); the half-body sweating loss of the same lesion stays. A Horner syndrome and that sweating loss need more of the lateral midbrain than the P2 segment's share: a PCA occlusion usually gives a field defect, a hemisensory loss and neuropsychological deficits, a Horner syndrome only in a case of proximal occlusion that infarcted the anterolateral midbrain (Bassetti 1995), and in a posterior-circulation registry a Horner syndrome went with the proximal (medullary) territory (Searls 2012).

## Honest limitations

- **The blood flow is a 0-D lumped model**: no pulsatility, no viscosity changes, no real 3D fluid dynamics. The numbers (mL/min) are meaningful only in order of magnitude and direction.
- **Thresholds and time constants are simplified from the literature and hand-calibrated** to show the right *trends* (worse collaterals → larger infarcts, earlier reopening → more saved, low NIHSS in posterior strokes…), not to predict anyone's infarct volume. The speed of tissue loss is calibrated to the measured growth of the ischaemic core in large-vessel occlusion (median about 3–5 mL/h, fast progressors from 10 mL/h, the fastest about 74 mL/h); with moderate and good collaterals the model's early growth (about 20–30 and 10–20 mL/h) stays above the median, because the end-artery perforator territories and the anterior temporal cortex, which the model leaves without flow, die early. A hemisphere cut off from both communicating arteries with poor collaterals gets almost no flow at all and loses about 100 mL in the first hour, beyond the measured range. The monkey thresholds (flow below 10–12 mL/100 g/min infarcts within 2–3 h) are faster than the human data the model follows. The course of the deep white matter is fitted to the share of patients whose internal capsule was infarcted at each time to reperfusion, read as the share of the capsule that is lost (the model has one typical patient, not a distribution); a lacune follows the course of the tissue it lies in. That penumbra stops counting as at risk two days after its ischaemia began is a model choice resting on how hypoxic but viable tissue became rarer in PET over that time, not a measured limit. The cerebellum and the parts of the medulla that no perforator feeds follow the general course of tissue that collaterals reach, with no calibration of their own, so at equal flow they now outlast the pons, whose basilar calibration was kept as it was fitted.
- **Oedema magnitude and timing are teaching approximations**: every bed uses the same curves while real people differ widely; the 3D deformation only pushes along surface normals (no tissue mechanics), and the exaggeration exists only to make it visible. Ropper's bands relate consciousness to the lateral shift of a one-sided mass; when both hemispheres swell the model counts their swelling together as if it were one hemisphere's, lists at least drowsiness while two-thirds of both MCA territories are out of action, and lists a survivor in a disorder of consciousness from two weeks on once two-thirds of both hemispheres, or of both MCA territories, are infarcted: all three are model choices, as no series gives the level of consciousness of bilateral hemispheric infarcts by size.
- Small vessels (cortical perforators, small brainstem branches) are **schematic**; only the main trunks are fitted to the statistical atlas. Surface arteries and collaterals are drawn above the surface with its sulci closed, so they don't keep sinking under the cortex; this changes only the picture — the flow model still uses the original vessel lengths.
- **The brain meshes have a few small gaps**: gaps of a few millimetres along the midline between the hemispheres and between the brainstem and cerebellum let short stretches of the third and fourth ventricles show from some angles (at most about 4 mm). A gap of about 3 mm is left on purpose between the hemispheres and the cerebellum (where the tentorium lies), and the branches of the superior cerebellar artery (SCA) run in it; to make room, the drawn lower surface of the occipital and temporal lobes is about 2 mm thinner at the junction (at most about 6 mm) — region volumes and the flow model are unaffected. As in a real brain, the top of the cerebellum is mostly covered by the occipital lobe: to see a whole SCA, hide that hemisphere or lower the cortex opacity under *View*.
- Symptoms, syndromes and the NIHSS are **inferred from the damaged regions**; real presentations vary widely. Haemorrhagic stroke, venous sinus thrombosis, vasculitis and the like are **not** simulated.
- **The effect of blood pressure is a model assumption**: in the model a higher pressure pushes more blood through the collaterals and shrinks the infarct (very sensitive around the default 93 mmHg), and high pressure does no harm of its own; in acute stroke both high and low pressure are associated with worse outcome, and raising pressure with drugs is supported only by small trials. From a mean pressure of 120 mmHg the course notes this evidence and the blood-pressure limit before thrombolysis.
- **The posterior-circulation time window is a calibration**: the brainstem leptomeningeal collaterals and the slower brainstem penumbra were set to match the trends of the basilar thrombectomy trials (ATTENTION, BAOCHE); their pathways and parameters are model assumptions, not measurements. The calibration was made for an occlusion of one basilar segment: when the lower basilar artery is blocked together with another segment (a long clot that also covers the origins of the AICAs), moderate or poor collaterals leave the paramedian pons below the core threshold, so in the model reopening even at 30 minutes saves the cerebellum but almost nothing of the pons (the same locked-in syndrome or disorder of consciousness). The ESO/ESMINT guideline reports from the BASILAR registry that thrombectomy was associated with better outcomes in every BATMAN stratum (a score that includes the thrombus burden) and advises reperfusion irrespective of the collateral score: such a long clot is a disadvantage, not futility, and this is a limitation of the model. Likewise, an occluded P2 is taken to cover its terminal division (so that the collaterals of one cortical branch do not refill the others through it), so that an untreated P2 occlusion gives the usual hemianopia; and the left–right PICA anastomosis over the vermis is set weak, so that a medial PICA branch occlusion with the default collaterals gives the isolated vertigo that mimics vestibular neuritis, while the PICA's hemispheric anastomoses with the AICA and the SCA are set a little stronger, so that a whole-PICA occlusion still depends on the collaterals and on early reopening. Weakness on the same side as a lateral medullary infarct (the Opalski variant) is not reproduced: the model has no region for the lowest medulla, where the pyramidal tract has already crossed.
- **The undrawn chest-wall and neck collaterals of the subclavian arteries are a calibration**: they were set so that in subclavian steal the basilar artery stays antegrade at rest, and they carry next to nothing at baseline. The same links are also the collateral supply when the common carotid or the brachiocephalic trunk is blocked (thyrocervical trunk / superior thyroid artery → external carotid artery → carotid bifurcation, as seen on angiography after common carotid occlusion; around a brachiocephalic occlusion also from the aorta through the internal thoracic artery into the reversed subclavian artery), so these occlusions are much better compensated than without them. Their strength is not measured.
- **The non-motor symptoms rest on evidence of uneven strength**: where sweating changes, taste loss and pathological crying come from rests mostly on case series and small studies, and their severities are illustrative; the evidence on REM sleep behaviour disorder conflicts, so it is only listed as a possible late problem after any pontine or medullary infarct, not as a symptom of one site. The hypothalamus is not in the model, so its own temperature set-point, circadian rhythm, appetite and hormones are not simulated. Central fever is not a symptom (early fever after an ischaemic stroke is mostly infection, and central hyperthermia in the literature is mostly after haemorrhage); it is shown only as a "risk of central hyperthermia" warning after extensive infarction of the upper pontine (or paramedian midbrain–thalamic) tegmentum on both sides with coma. The population prevalences on the *Outcome* tab are not predictions for the case.
- **Lacunes come in a few typical sites**: every lacune is about 0.8 mL and gives a typical lacunar syndrome (mostly mild to moderate); the small infarct in the lowest part of the internal capsule that still causes a dense hemiplegia, and differences in lacune size, are not modelled. Post-stroke movement disorders are mostly listed only as a population figure, not as symptoms of the case; only two delayed forms tied to one small territory are listed as possible symptoms: the Holmes tremor after a paramedian midbrain infarct and the jerky, dystonic, unsteady hand after a posterior choroidal infarct.
- **The spinal cord is its top only**: the model has the upper cervical cord (C1–C3) that the anterior spinal artery feeds from its origin at the two vertebral arteries; the radiculomedullary arteries that join it lower down (seen on MR angiography in 24 of 50 people: Sheehy 2005) are not modelled, so an occlusion of both vertebral arteries beyond their spinal roots infarcts all of C1–C3, which may overstate how often the cord is lost then. The cord's weakness and sensory loss barely recover in the model, whose recovery curves are the brain's, while after a spinal cord infarct many improve over months to years (Robertson 2012).
- **Recovery and compensation are illustrative**: population-average curves by function and by one- or two-sided damage, with no rehabilitation intensity, age or comorbidity; they cannot estimate anyone's recovery. How much less a limb recovers when its corticospinal tract is lost where it converges is an estimate, as are the range and the shares by which the recovery of an aphasia and a neglect falls with the MCA cortex lost, the share of Wernicke's area (half to three-fifths) over which the recovery of a Wernicke aphasia falls, the brainstem's lower limit of 15 %, the range of the bottleneck (from the symptom threshold to 40 % of both sides), the share of the lateral midbrain (35 %) from which its sympathetic fibres are reached, and the 50 mL from which a saved volume counts as a benefit. The model sets no separate cap on recovery after long ischaemia: after thrombolysis of a basilar occlusion without extensive early ischaemia, half had a good outcome independent of the time to treatment up to 48 h (Strbian 2013), so a late reopening is graded by the brainstem infarct it leaves. The return of function after a reopening has one shape, its pace set by how long the ischaemia lasted, and all of the rescued function returns in the end; in reality rescued tissue can lose neurons in proportion to how deep its hypoperfusion was, and recovery can be delayed for other reasons (the "stunned brain"). Coma and drowsiness caused by a brain region are relabelled at a fixed two weeks after that region became ischaemic as what follows them (persistent hypersomnia; after extensive damage to the tegmentum on both sides, a disorder of consciousness or a locked-in state), whereas in reality people wake after days to weeks. The brainstem consciousness events follow these labels, on the clock of the lesion that causes them: the basilar-coma event runs while the coma is listed (until the tegmentum, rescued by a reopening before it infarcted, works again, or until that relabelling), and a locked-in (classical or incomplete) or disorder-of-consciousness event takes over when the labels do.
- **Recanalisation details are illustrative**: partial reperfusion is approximated as that share of the territory regaining flow, with no microvascular model; a lasting reocclusion ends at the untreated final infarct (only later); the evidence on no-reflow is limited; the published figures are for reference and do not drive the simulation. The thrombolytic drug (alteplase or tenecteplase) does not change the simulation; the time chosen is when flow returns, not when the drug is started; a lacunar (single-branch) occlusion is not reopened by treatment; the eTICI grade shown beside a distal embolus comes from the share of the territory's normal blood flow the blocked branch supplies, not from an angiogram.
- **The model never represents death**: herniation without decompression is usually fatal, and the course and the *Outcome* tab flag "death likely" (with both hemispheres, or both MCA territories, destroyed the survival figures of one do not apply, and the note says that a survivor stays in a disorder of consciousness; two hemispheres herniating downward together are not given the outcome of the survivors of one); coma from a swollen cerebellum without surgery is flagged "life-threatening", as there is no reliable figure for mortality without surgery (the studies had no untreated comatose controls); a basilar occlusion that is not reopened, with a coma the basilar lesion itself causes (from the brainstem or the thalamus), is flagged "often fatal" (90-day mortality 55% and 42% in the medical arms of the thrombectomy trials), from when that artery closes: the coma of a swollen hemisphere stacked with it is the herniation's own risk. Locked-in syndrome and bilateral medial medullary infarction are not "usually fatal" but carry a substantial mortality (about 60% and 24%), which the *Outcome* tab notes. In these cases the rest of the course and the 3- and 6-month NIHSS assume the patient survives.
- **The *Outcome* tab runs the same model twice**: "untreated" is the same occlusion without reopening, not a real-world control group (the NIHSS of a column whose course is usually fatal says "if the patient survives"); 3 and 6 months are the timeline's two last stops (counted from the first event), while the final infarct is evaluated 6 months after the last change of the vessels: a later change moves that evaluation past the 6-month stop, which *Outcome* states with the exact offset, and the course is flagged as "not settled at 6 months" only when the infarct or the deficits listed (with their severity and group) still change in between — at 6 months the share of a deficit taken over by other pathways still creeps up by a point or so a month, which counts only when it moves the deficit to another group; the late events and final regions are not re-evaluated later. The thresholds that group deficits into "still marked / partly compensated / largely compensated" (25 %, 60 %) are chosen for readability. The final infarct counts the upper cervical cord with the brain and names the cord's part (the neuron estimate counts the brain only); the region list shows the regions with 5 % or more of their volume infarcted, or holding a tenth of the final infarct, two thresholds also chosen for readability.
- **Each leptomeningeal anastomosis has a hand-set strength**: its capacity grows with the collateral grade and with the blood flow of the two arteries it joins. Over the convexity the ACA–MCA anastomoses give each MCA branch about the same capacity per mL/min of the territory it feeds (the one over the motor strip used to give it about 1.7 times as much, so that a precentral-branch occlusion with moderate collaterals caused no deficit at all). The PCA–MCA anastomoses give the posterior parietal and temporo-occipital branches more, so with moderate collaterals an occlusion of either alone causes no deficit in the model; the anterior and posterior temporal arteries have none, so an occlusion of either gives its full deficit whatever the collateral grade.
- **Left and right are mirror images for the cerebral pial arteries, not everywhere**: the template brain and its territory atlas are asymmetric, and the flow model used to take each artery's traced length and the tissue it feeds from them as they are, so the same occlusion ended differently on the two sides (with good collaterals a right calcarine occlusion left no lasting field defect and a left one a hemianopia: the left temporo-occipital artery is traced 115 mm long against 98 mm on the right and feeds a quarter more tissue, so less collateral blood came through it). The pial arteries of the hemispheres (A2, M2 and P2 with their cortical branches) and the leptomeningeal anastomoses between them now use the mean of the two sides' lengths and baseline flows in the flow model, so mirrored occlusions get the same perfusion pressures (to within about 1.5 mmHg); the measured tissue volumes (and so infarct volumes) still follow the atlas. The circle of Willis, the perforators and the vertebrobasilar and cerebellar arteries keep their traced lengths, because the posterior-circulation calibration was made on them, and the atlas also splits some regions differently between the territories on the two sides (the right superior parietal lobule, for example, lies more in the ACA territory). So a deficit close to its threshold can still appear on one side only, or settle later on one side: cortical sensory loss after an ACA occlusion, for example, or a central scotoma after a calcarine occlusion with good collaterals.
- **One hemisphere's occlusion can feed the other's collaterals**: the circle of Willis and the large arteries are resistances in one network, so an occlusion of one side (most of all of the ACA or PCA, at A2, P1 or P2, but also of a cerebellar artery or an MCA branch) slightly raises the pressure in the arteries that still flow (the circle, the basilar tip) and with it the flow of the other side's leptomeningeal collaterals; adding it then makes an infarct of the other side (mostly an MCA infarct) smaller: by up to about a fifth of a large infarct (with good collaterals a right inferior-division infarct of 58 mL is 46 mL beside a left P2 occlusion, a right superior-division infarct of 68 mL is 59 mL beside a left A2 occlusion, a right M1 infarct of 163 mL is 155 mL beside either), and by more of a small one (with moderate collaterals an angular-branch infarct of 7 mL is about 4.5 mL beside a P2 occlusion of the other side). It happened in about a fifth of the 512 pairs of single occlusions of the two hemispheres with good or moderate collaterals that were checked (in none with poor ones), and in 12 of them the pair's total infarct is smaller than the larger infarct alone (a right P1 occlusion beside a left inferior-division infarct: 59 mL alone, 51 mL together). In reality the large arteries lose little pressure, so the circle stays close to the systemic pressure whatever one branch does, and the effect should be negligible. Removing it means changing the flow model itself (keeping what an occlusion adds to the other branches out of the collaterals, or letting the arteries autoregulate), which moves the volumes, and with them the swelling and herniation, of every combined case it touches, so it is left as a limitation.
- **Deficits are graded in whole steps**: a limb is plegic or moves a little, NIHSS item 5 scores 4 or 3, so a sliver of tissue at the edge between two grades can tip one. A mid-basilar occlusion with poor collaterals has infarcted the ventral pons by 12 h; a thrombectomy then saves 0.2 mL (63 % of the caudal basis infarcted untreated, 59 % treated), and at 3 months the four limbs move a little instead of not at all (NIHSS 20 against 24). The model cannot remove such thresholds; the texts quote the saving and do not credit the reopening with the difference (see the recanalisation event above), but the *Outcome* tab still shows the two NIHSS values.
- **Not for judging real cases in hindsight** (e.g. "would thrombectomy have changed things?"): the model is a standard brain with average parameters, so the answer reflects only its assumptions.
- The medical content was compiled by the developer from textbooks and papers and **has not been formally reviewed by clinicians**. Please open an issue for any error.

## Development

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # engine, component (jsdom), documentation and output-invariant tests: every rule can fire, treatment never enlarges the infarct, symptoms don't flicker, the numbers in the docs match the data…
npm run lint && npm run typecheck
npm run build      # outputs dist/ with relative paths, deployable in any sub-directory
```

### Regenerating the anatomy assets

`public/data/brain.{json,bin}` and `src/anatomy/generated/*.json` are committed; normal development does not rebuild them.
After changing `src/anatomy/` (vessels, regions):

```bash
python3 -m pip install -r tools/requirements.txt
npm run assets:build    # = vite-node tools/export-anatomy.ts && python3 tools/build_assets.py
```

The first run downloads about 80 MB of public atlases into `tools/.cache/` (git-ignored); it takes about a minute.

## Deploying to GitHub Pages

1. In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** (once).
2. Merge into `main` (or run *Deploy to GitHub Pages* manually from the Actions tab).
3. `.github/workflows/deploy.yml` runs the tests, builds and publishes `dist/` at `https://<user>.github.io/<repo>/`.

Vite's `base` is `'./'`, so every asset path is relative: renaming the repository or using a custom domain needs no change,
and the state lives after the `#`, so no server routing is needed.
