在真实的 MNI 标准脑上看大脑、小脑与脑干的动脉，塞住一条或多条血管（或放出一颗栓子），看
**几分钟到几个月内**会怎么影响「其他」脑区：缺血半影区变成梗死、脑水肿与肿胀挤压、脑疝、脑积水、远端退化……
以及每个时间点**哪些脑区、哪些功能**正在受损、还救得回来、或已经恢复，病程结束时又留下什么。

**线上版：** <https://lzong-tw.github.io/brain-vessel-map/> （需先启用 GitHub Pages，见下方〈部署〉）

![3D 视图：左 M1 栓塞 24 小时；左侧「病例」、右侧「此刻」](docs/screenshot-3d.jpg)

<a id="怎麼用"></a>
## 怎么用

1. **选一个起点**：左侧「范本」载入教学病例（例如左 M1 栓塞、闭锁综合征）；或到「血管」按任一条血管的「＋ 阻塞」。范本旁的「叠加」和血管的「＋ 阻塞」都会**加到**目前的病例上，所以可以组合多条血管（例如基底动脉中段 + 右 PICA）。
2. **调整病例**：左侧「病例」有三张卡片——发病前条件（侧支循环、血压、Willis 环变异）、阻塞事件（每条血管的程度与时程，例如先 TIA、三天后才完全阻塞）、治疗（再通时间、方式与结果、减压手术）。收合时每张卡片仍显示一行摘要；时间轴上方也有整个病例的一行摘要。
3. **拖动时间轴**：从发生时到 6 个月。右侧「此刻」显示那个时间点的组织状态、症状、NIHSS 与事件；「最终」显示病程结束时的结果（有设治疗时，会和「同样阻塞但没有再通」对照）；「详细」显示点选的血管或脑区。「此刻」只在模型仍提供再通治疗时（阻塞开始后一天内、尚未再通）说半影区「可救」，之后改说「仍可能坏死」；引用的量是现在的血流仍会杀死的那部分半影区，其余即使血管不通也会靠侧支存活，另外说明；再通只让部分区域恢复血流时（eTICI 低于 3、无再流、远端栓塞），会说血流没有回来的地方组织仍在坏死（或之后仍坏死了），而不说半影区停止恶化；小梗死（例如脑干）扩大达自身的十分之一（或 0.5 mL）就算正在扩大。
4. **分享**：整个病例都存在网址 `#` 后面，复制网址即可。

<a id="功能"></a>
## 功能

| | |
|---|---|
| **真实解剖几何** | 大脑半球、小脑、脑干、丘脑、基底核、内囊、胼胝体、齿状核、脑室——由 MNI ICBM152 2009c 模板产生的 3D 表面，不是手捏的形状。 |
| **180 段动脉** | 主动脉弓 → 颈动脉／椎动脉 → Willis 环 → 皮质分支、豆纹动脉、脉络丛动脉、脑干穿通支、PICA／AICA／SCA，其中 38 段是软脑膜／颅外侧支；主干位置校正到多中心 MRA 统计图谱。125 个功能脑区、268 个「脑区 × 供应区」单位。 |
| **血流模拟** | 以 Poiseuille 阻力网络解每条血管的流量与方向：Willis 环逆流代偿、锁骨下动脉盗血、自动调节、低血压时的分水岭缺血，以及 21 种解剖变异（胚胎型 PCA、缺 AComm／PComm、永存三叉动脉、Percheron 动脉含或不含中脑与丘脑前部……；默认的完整 Willis 环在成人只占少数）。脑干另有图上没画出的软脑膜侧支，其导通度随血压改变；锁骨下动脉也有没画出的胸壁与颈部侧支。 |
| **病例 → 此刻 → 最终** | 左侧「病例」集中一个病例的所有设定，「范本」可载入或叠加；右侧「此刻」看显示时间当下，「最终」看病程结束时：最终梗死、3／6 个月的 NIHSS、留下的缺损与代偿程度、晚期并发症。 |
| **时间轴** | 发生时 → 15、30 分 → 1、2、3、4.5、6、12 小时 → 1、2、3、5 天 → 1、2 周 → 1、3、6 个月。「此刻」与「详细」都跟著时间轴变：组织状态、还剩多久会失去半影区、哪些功能受损／濒危／已恢复，以及整段病程的「功能受影响时间轴」热图（点任一格可看那个时间点的症状、来源脑区与变化）。 |
| **分段病程** | 每条血管可设定开始与自行再通的时间，也可「之后变成完全阻塞」：模拟短暂性脑缺血（TIA）、狭窄后才完全阻塞（例如前驱 TIA → 数天后基底动脉闭塞），以及在任一时间点治疗。 |
| **再通细节** | 治疗方式（取栓／静脉溶栓／桥接）、再灌注程度（eTICI 0–3）、再阻塞、取栓时碎片栓到远端分支或新区域（同侧 ACA）、无再流（证据有限）。模拟的是你选的结果；旁边附上依阻塞位置整理的已发表数据（再通率、有症状出血——中型／远端血管与大核心取栓各有自己的数字、tenecteplase、超过 4.5 小时经影像筛选的溶栓、再阻塞、远端与新区域栓塞、无再流），每个数字都有出处，并依部位提醒溶栓／取栓时间窗（选的时间是血流恢复的时间，比溶栓用药晚 1–3 小时，所以要到药物多半是在 4.5 小时后才开始时——约血流在 6.5 小时后恢复——才说单用溶栓太晚；基底动脉溶栓超过 4.5 小时只有专家共识、没有试验验证的取栓部位、中型血管取栓的阴性试验）。病程中的「治疗时间窗」也依阻塞部位说明：前循环大血管（含大核心试验）、基底动脉（试验死亡率）、单纯颈部 ICA、V4、中型／远端血管与腔隙性卒中。「已救回」只算「不治疗会死、治疗后活下来」的组织，包括不治疗时肿胀造成脑疝而梗死的区域。 |
| **恢复** | 早期的缺损比梗死大（水肿与远端功能抑制让活著的组织暂时停摆），之后依备援路径部分代偿：单侧病灶、有双侧支配或平行路径的功能代偿较多；脑神经核这类「最终共同通路」没有备援；脑桥腹侧或中脑大脑脚两侧大部分受损时主路径与备援一起中断，恢复很有限（会说出是哪一处）；再通后两侧只留下小梗死时不算这种瓶颈。失语与忽略能被代偿多少，要看同一半球的大脑中动脉皮质还剩多少：几乎整个语言皮质都梗死时，3 个月后仍是严重或全面性失语；理解力还要看韦尼克区剩下多少：韦尼克区梗死超过约五分之三时，3 个月与 6 个月后仍是中重度的韦尼克型失语。脑干由致密的神经束与神经核组成，缺损依梗死或仍未恢复的比例逐渐减轻，不会在门槛上一起出现或消失。有些部位还看左右侧：右侧丘脑旁正中梗死的认知障碍多半会恢复，左侧或双侧的常持续。只是示意的群体平均，不是预后。 |
| **水肿与肿胀** | 细胞毒性水肿（DWI，几分钟内）→ 离子性水肿（CT 低密度，数小时）→ 血管性水肿（第 3–5 天最肿）→ 消退 → 萎缩（数月后）；3D 脑会依各区肿胀量变形（可放大 1×／3×／5× 以便看清楚），另有「水肿／影像」著色模式（ADC 恢复正常后 DWI 仍亮数周，T2／FLAIR 因胶质疤痕一直是亮的）；中线偏移、脑室受压或扩大随时间计算，意识程度跟著中线偏移变化（两侧半球都肿胀时，跟著两侧合计的肿胀）。 |
| **连锁反应（对其他部位的影响）** | 恶性 MCA 水肿 → 半球本身的肿胀把中线推到昏迷范围时（不论另一侧如何）大脑镰下脑疝（压 ACA）与钩脑疝（压中脑、PCA；被脑疝压到梗死的大脑脚，会留下穿过它的动眼神经纤维的麻痺）；两侧肿得差不多时，是脑向下的中央型天幕切迹脑疝，单独就会脑疝的那一侧保留它本身肿胀造成的续发梗死（只有两侧合计的肿胀才达昏迷范围时则不加），未减压时标示「很可能死亡」；占位性小脑梗死分级（20 mL 起要观察、38 mL 起可能恶性肿胀）→ 脑干受压与阻塞性脑积水，意识随肿胀变化，未手术而昏迷时标示「危及生命」；出血转化风险；交叉性小脑失联（CCD）；锥体径 Wallerian 退化；可能的下橄榄核肥大退化与软颚颤抖；丘脑萎缩；两侧脑干被盖大范围梗死又昏迷时的中枢性高热风险；延髓外侧梗死（单侧也可能）前 10 天的呼吸衰竭风险；只有内耳梗死时当成卒中警讯、而不是 TIA；吸入性肺炎（在病例列出吞咽困难或意识变差的期间出现，标题依当时列出的是哪一项；梗死很大时，在两者列出之前先提醒做吞咽筛检）、卒中后的心脏并发症（任何梗死都可能；从 NIHSS 达 16 分或列出昏睡、昏迷时起注明是严重卒中——依临床严重度，不是梗死体积——再通让缺损消失后改说发作时很严重，岛叶受累时另外说明）、深部静脉血栓（第 2 到第 30 天、患者无法自己活动的期间：腿抬不起来、昏睡或昏迷、意识障碍、无动性缄默）；叠加多次阻塞时，每个留下梗死的病灶都从自己的发作时间起算这些警示与中枢性高热的风险、早发与晚发癫痫（附晚发性发作的比率）、可能出现的中枢性疼痛与痉挛（和症状同时出现）、脑干梗死后可能出现的 REM 睡眠行为障碍、抑郁…… |
| **临床输出** | 预期症状（依系统分组、左右侧）、具名综合征（Wallenberg、Weber／Benedikt、Foville、闭锁综合征（典型、不完全，以及昏迷时的基底动脉昏迷）、脑桥前内侧综合征、Percheron（含或不含中脑）、丘脑四个供应区、Gerstmann、腔隙性、内囊警讯综合征、桶中人、双侧延髓内侧梗死、前脊髓动脉综合征……共 55 条规则）、NIHSS 估计（缺血在椎基底动脉系统、又有症状时提醒后循环常被低估——只是梗死延伸到枕叶的大脑中动脉或颈动脉卒中不算；分数为 0 但有量表不计的症状时会注明）。单一穿通支（腔隙）阻塞可以选落点：同一条小分支落在内囊后肢、辐射冠、内囊膝部或脑桥，分别呈现纯运动性、运动失调性偏瘫、构音障碍—笨拙手或内囊膝部的意识混乱与失忆。腔隙性的标签是临床综合征：同样的表现几分钟内消失、没有留下梗死时就是腔隙性 TIA；同一支小动脉一天内有两次这样的 TIA，才算内囊警讯综合征。 |
| **非运动功能** | 依受损部位出现、跟著时间轴变化：睡眠（中枢性睡眠呼吸中止、长期嗜睡）、情感表达（病理性哭笑）、体温调节与出汗（同侧无汗、对侧半身多汗、瘫痪侧肢体偏冷）、味觉丧失、尿滞留；功能热图各有一列。晚期的后果各有自己的开始时间（痉挛与中枢性疼痛约 2 周、病理性哭笑约 3 周、肢体发冷约 1 个月、中脑梗死后的霍姆斯颤抖约 2 个月）；中枢性疼痛与病理性哭笑标成「可能出现」，不算进 6 个月时的缺损数；痉挛只有在早期无力严重或半身感觉减退时才较严重。「最终」页另列出卒中后常见、但与病灶部位关联有限的问题（抑郁、焦虑、冷漠、病理性哭笑、疲劳、失眠、睡眠呼吸中止、失智）、最常见的并发症（跌倒、肩膀痛、尿失禁、感染、再次卒中），以及少见（约 1%）的卒中后不自主运动，附族群盛行率与出处——模型算不出个人风险，也不计入症状或 NIHSS。 |
| **三种视图** | 3D（可切面、调透明度、只看单侧）、Willis 环示意图（即时流量与方向，可直接点击阻塞）、脑干四个层面的血管分区切面。 |
| **栓子模拟** | 选来源（心脏、左右颈动脉斑块、左右椎动脉）与大小，依各分支流量随机漂流，卡在比它窄的血管——大栓子多卡在 ICA 末端或 M1，小栓子进到皮质分支。 |

<a id="這個模型怎麼算的"></a>
## 这个模型怎么算的

1. **几何**：`tools/build_assets.py` 从 TemplateFlow 下载 MNI152NLin2009cAsym 的分割与概率图，用 marching cubes 产生网格；每个表面点被标上「功能脑区 × 动脉供应区」（床，bed），供应区来自 Liu 等人的动脉分区图谱，重叠处即分水岭。
2. **血流**：每条血管是一个 Poiseuille 阻力；每个床由一条或多条供应动脉分摊；侧支依等级（好／中／差）有不同导通度；小动脉在灌注压下降时扩张（自动调节，上限 1.8 倍）。脑干另有图上没画出的软脑膜侧支，血压高于正常时会随之收缩；锁骨下动脉另有图上没画出的胸壁与颈部侧支，近端阻塞时和倒流的椎动脉一起供应手臂。只有部分人才有的血管（永存三叉动脉）只在选了该变异时存在，被变异移除的血管不会画出。大脑半球表面的软脑膜动脉（A2、M2、P2 及其皮质分支）与它们之间的软脑膜侧支，长度与基础流量取左右两侧的平均，让同一条动脉在两侧阻塞时的血流一样（见「限制」）。解线性方程得到各点压力与流量。
3. **病程分段**：阻塞可以在不同时间开始、自行再通、之后恶化，治疗也可能再阻塞或把碎片冲到远端；每一段「阻塞不变」的时间各解一次血流，组织沿著这条血流历史演变。时间以第一个事件为 0；连锁反应与恢复则从造成大部分梗死的那次阻塞起算（每个病灶的肿胀依它自己的时钟，见下；没有梗死时，从最近一次造成缺血的阻塞起算，之前的每次发作各自当作一次发作来说明），而各脑区的晚期症状、代偿与昏迷改列，则从该脑区本身开始缺血时起算；脑疝造成的续发梗死，从脑疝的那个肿胀病灶（它自己那一侧的半球）开始时起算：右侧 M1 恶性梗死的脑疝梗死，不会在一个月后的左侧 M1 阻塞成为主要事件时重新起算，它造成的腿部无力也保有已经得到的代偿。每个时间点显示的是当时的病情：之后才开始的阻塞当时还不知道，在它开始之前什么都不改变——不改变肿胀、意识程度、事件，也不改变「此刻」对病程的预估（之后会完全阻塞的狭窄，在那之前就是持续的狭窄）；「最终」页与通往它的最终梗死那一行，显示的是整个排程的结果。后来的阻塞开始之后，每个病灶仍依它自己的时钟肿胀、脑疝，并有它自己的水肿事件（恶性水肿或占位效应、脑疝与它造成的梗死、交叉性小脑功能抑制、小脑肿胀），所以较早的梗死不会在较大的阻塞开始时失去肿胀或脑疝梗死，脑疝已经压坏的组织也不会因为后来的阻塞本来也会让它梗死而又活回来；已经开始的肿胀病程（水肿、脑疝、脑疝后很可能死亡的提示）不会被后来的阻塞拿掉、改标题或提早在它开始之前结束，已经开始的治疗与再通事件（治疗时间窗、血管再通与之后的再阻塞或远端栓塞、血管自行再通、Willis 环侧支代偿、纹状体内囊梗死的皮质征象）也一样：因为后来的病灶而改变的说法（例如中度占位效应变成恶性病程），从后来那个病灶的第一天起才这样说。每个半球（以及小脑）的肿胀依它自己的病灶分类（病灶在一天之内开始的那些床；小脑另外算进肿胀期和它重叠的每个小脑梗死，不论较早或较晚，因为后颅窝的病程只依梗死大小决定：病程从当时已开始的梗死合计达到该等级时起算，所以相隔几天的两个小脑梗死不论谁先开始，肿胀都一样，较晚的那个开始前已经说过的病程照原样保留），每个病灶的肿胀依和它同时在肿的病灶大小而定，后来的病灶要等它自己开始肿胀才算进来（所以较早的肿胀不会在后来的阻塞开始时突然变大）；两侧半球只有在两侧病灶相差一天之内开始时，才合起来和单侧恶性梗死的大小标准比较（肿胀在时间上重叠时仍会合计）；其他事件（超急性期机转、影像、出血转化、癫痫、晚期退化）依造成大部分梗死的那次阻塞的时钟进行，这是叠加多次卒中时的简化。文字中的「发病后」从这个主要发作起算；肿胀的文字从它自己的病灶起算，不是主要发作时会注明（右侧 M1 阻塞后约 279 小时缓解的右半球脑疝就这样说明，即使一个月后的左侧 M1 成为主要事件也一样）。没有留下梗死的脑缺血，在缺损还在时，当作还分不出是不是 TIA 的急性卒中来说明：列出它那些阻塞的治疗时间窗，不等著看它会不会消失，抗血小板药物要等影像排除出血后才给；从症状清单不再有缺损时起，才说 TIA 的部分（「症状消失不代表没事」与抗血小板药物的建议，打过溶栓剂时要等 24 小时的追踪影像）（Powers 2019；Easton 2009）。上段颈髓（前脊髓动脉的供应区）缺血时有它自己的病程（脊髓梗死、脊椎 MRI、之后的恢复），脑也缺血时与脑的病程并列；只有手臂或脸部缺血时，不说脑的病程。
4. **组织命运**：相对血流 < 30% 为核心梗死，30–55% 为缺血半影区，55–85% 为轻度低灌注。组织死得多快，取决于血流剩多少、缺血多久。终末动脉完全没有血流的地方（深部穿通支供应的灰质，例如纹状体与丘脑）约 6 分钟后开始坏死、十几分钟内大部分死亡。同一群穿通支供应的白质（内囊与辐射冠）撑得比较久：约 2.5 小时内不会坏死，之后约 4 小时死一半、6 小时死大部分，依取栓时不同再灌注时间下内囊被保住的比例校正。腔隙（一束穿通支中的一条分支）依它所在组织的时程坏死，一条分支后面和整束穿通支后面一样，占的范围也不超过那束穿通支在该构造供应的部分：内囊的一条分支阻塞 1 小时，留下的内囊梗死不会比整群豆纹动脉阻塞 1 小时多，也就是没有，功能也和整群阻塞时的内囊一样，在之后几小时内恢复；所以 M1 阻塞在 1–2 小时内打通，纹状体仍会梗死，手臂通常保得住，6 小时才打通就很少保得住。腔隙在最终脑区清单与脑区细节里以它自己的体积与所占比例显示（约 0.8 mL：辐射冠的 6%、内囊后肢的 38%），和上方的最终梗死相符；它让这个构造失去的功能（大部分）则显示为该脑区的失能，脑区细节也会说明为什么这么小却影响这么大。落点沿用构造本身缺损的腔隙（尾状核头、脑桥下部、延髓外侧），让构造失去的功能也不超过整束穿通支阻塞时：Heubner 动脉的一条分支不再留下整条 Heubner 动脉都不会留下的持续构音障碍，脑桥下旁正中的一条分支造成的偏瘫也不比整群分支重（有自己综合征的落点，例如纯运动性或运动失调性偏瘫的腔隙，仍失去所在纤维束大部分的功能）。侧支还送得到血的组织（皮质、白质、小脑）前 20 分钟不会坏死，之后完全没有血流时约 2.5 小时死一半，刚好低于核心门槛时约 6 小时死一半，半影区更慢（血流越低越快死；从未再通时最多 85% 能靠侧支存活，存活的部分在约 12 小时内逐渐恢复功能）。缺血开始两天后，除非还在坏死，组织就不再算半影区：到那时半影区不是已经坏死，就是会存活（用标示缺氧但仍存活组织的 PET，这种组织在前两天越来越少、越来越小：Read 2000；Markus 2004），所以从第 2 天起显示的半影区大约就是病程还会失去的组织，其余是会存活、仍暂时不运作的组织，照以前一样逐渐恢复功能（「此刻」与脑区的详细数据都这样标示，和再通后救回的组织一样，不当作已坏死的组织）。侧支差的 M1 阻塞，梗死在 1 小时约 60 mL，前几个小时每小时增加 35–55 mL，约 12 小时填满整个供应区（大血管阻塞实测最快的速度约每小时 74 mL）；侧支中等时每小时约 20–30 mL。不治疗时低于核心门槛的组织终究都会死，所以最终梗死和以前一样，只是时间进程变慢，侧支差时及早再通也救得回组织。再通救回的组织要几小时到几天才恢复功能，不是立刻恢复：缺血 1 小时后约四分之一立刻恢复，缺血 1 小时约 2 小时、缺血 6 小时约一天内恢复一半，其余在数周内恢复（几分钟的 TIA 立刻恢复）。视网膜在完全阻塞约 12 分钟后才开始坏死（人类估计值；猴子实验长得多），所以几分钟的一过性黑蒙不留梗死。脑干的半影区死得较慢、未治疗时存活较少，这是为了符合基底动脉取栓试验（ATTENTION、BAOCHE）而校正的。单一穿通支（腔隙）阻塞不改变模型看得到的血流，它的组织从阻塞当下就停止运作，在组织开始坏死之前再通（几分钟内；在内囊与辐射冠约 2.5 小时内）就不留下梗死（内囊 TIA）。穿通动脉是终末动脉，不论只阻塞一条分支或整束，后面的白质都没有侧支血流能到达：「此刻」说它还活著是因为白质在完全没有血流时要几个小时才会坏死，而不是靠侧支撑著。最终梗死在最后一次血管变化后 6 个月评估。
5. **治疗**：在选定时间打通「当时存在的完全阻塞」。再灌注程度（eTICI）决定供血区有多少比例走「再通后」的路线，其余照未治疗的路线；无再流、再阻塞与远端栓塞各自修改这条路线。「已救回」＝未治疗会梗死、治疗后存活的组织，包括不治疗时肿胀造成脑疝、压迫而梗死的区域（即不治疗与治疗的最终梗死之差）。治疗打通血管后，「治疗时间窗」就结束（血管自行再通而留下梗死时也一样），打通的血管在发作第一天内又塞住（再阻塞）时，时间窗在当天剩下的时间再度出现，仍从发作时起算；eTICI 0 的尝试在病例摘要写成「尝试、未再通」，找不到可打通阻塞的治疗（模型不会打通的腔隙性阻塞用静脉溶栓，或当时没有完全阻塞）则写成在那时给予，没有 eTICI 分级、没有治疗与不治疗的比较，也没有「已救回」。eTICI 是依最后血管摄影上整个下游区域恢复灌注的比例分级（3 = 100%、2c = 90–99%、2b67 = 67–89%、2b50 = 50–66%：Liebeskind 2019），所以被血栓碎片塞住的下游分支会依它供应的正常血流比例降低显示的分级（M1 取栓时下分支栓塞，选的 3 会变成 2b50）：选的分级是其余区域的结果；栓到新区域则另外报告，不改变所选分级。血管自行再通而留下梗死时，有自己的事件与「此刻」说明，并列出和血管一直阻塞相比救回了多少（一项 53 个研究的统合分析中约四分之一的阻塞会自行再通：Rha 与 Saver 2007）；在任何组织坏死之前就再通的，当作 TIA。自行再通和治疗打通一样判断：肿胀造成脑疝时压迫到哪些仍活著的组织，依血管一直阻塞时的病程而定，所以结果和同一时间完全取栓相同，不会比血管一直阻塞更大。较晚的阻塞，其治疗时间窗引用的核心是决定治疗时它自己的病灶坏死的量，不是较早的梗死；较早的梗死在 3 个月内（且至少早一天开始；模型的选择）时，说明静脉溶栓不是标准治疗：指引建议不要使用，这是主要依据专家共识的相对禁忌，一个登录研究中只有前一次卒中在 14 天内时症状性脑出血较多（Shah 2020；Scala 2026）。「血管再通」事件会列出有无治疗时 3 个月的 NIHSS，并在避免了缺损（至少 2 分）、避免了常会致命的病程（脑疝、脑干受压、基底动脉没打通又昏迷），或保住至少 50 mL 脑组织时标示为有益：避免闭锁综合征只救回几 mL 的脑桥；反过来，不治疗时致命的病程，模型给的是假如患者存活时的 NIHSS，NIHSS 对右半球梗死的计分也比同样大小的左半球低，最终梗死体积本身就预测日后的功能。两边 NIHSS 一样时不会写成「约 X 分（不治疗约 X 分）」，而会说明 NIHSS 看不出、但治疗保住了多少组织；不治疗时致命的那一栏在事件与「最终」页都注明「假如患者存活」。再通只救回极少量的组织（不到 0.5 mL，也不到不治疗时梗死的十分之一）时，这点组织刚好在严重度等级交界处造成的 NIHSS 差距不算在再通身上（见限制）：事件会说明，也不因此标示为有益，不完全闭锁的事件也不说再通救回部分脑桥；没有这次再通、四肢也会在同一时间（一天之内）恢复部分动作时，也不这样说，例如侧支良好的中段基底动脉阻塞在 2 天时再通，不论有没有再通，四肢都在第 9 天恢复部分动作；0.05 到 0.5 mL 的量写到小数一位，不写成「约 0 mL」；算不算极少量，看再通本身救回多少，不扣掉它送出的血栓碎片在别处造成的梗死。脑干的小梗死不算极少量：下段基底动脉阻塞、侧支差、6 小时打通时救回 1.5 mL 中的 0.4 mL，仍算有益。
6. **水肿**：依各床的核心、半影区与再灌注状态，分别累积细胞毒性、离子性、血管性水肿与后期萎缩；肿胀体积换算成中线偏移（减压手术后大部分往颅外扩张），意识程度依中线偏移的大约范围下降（Ropper：约 4 mm 嗜睡、6 mm 昏睡、8 mm 昏迷）。两侧半球都肿胀时，会把脑往下挤而不是推向对侧，中线移动较少：模型这时把两侧的肿胀加在一起，视同单侧半球的肿胀，来决定意识程度。一侧半球会不会脑疝、何时脑疝，依它本身的肿胀（单独肿胀时会造成的中线偏移）：从第 3 天起、在这个肿胀仍达昏迷范围时脑疝，所以另一侧较小的肿胀（会往回推）不会让它的脑疝与续发梗死消失；另一侧的肿胀小到没有自己的水肿事件时，两侧合计、从这一侧推过去的肿胀仍达昏迷范围，也让它脑疝，和昏迷一致。脑疝开始时，若中线被它推过去 4 mm 以上，就向它自己那一侧脑疝（钩与大脑镰下脑疝）；否则两侧一起被往下压（中央型脑疝：没有大脑镰下脑疝、没有单侧的动眼神经麻痺），单独就会脑疝的那一侧保留它本身肿胀造成的续发梗死——大脑后动脉区压在天幕边缘，和单侧或两侧占位造成天幕切迹脑疝后的情形一样（Keane 1980），以及大脑前动脉区压在大脑镰上（这是模型的选择：两侧一起肿胀时扣带回不会滑到大脑镰下方）；两侧都不会单独脑疝、只有合计的肿胀才达昏迷范围时，中央型脑疝不加上续发梗死（无法判断是哪一侧、多大；这是模型的选择）。两侧都有至少三分之二的大脑中动脉区失去功能时，不论肿胀多少，前两周至少列为嗜睡。以梗死大小来看，两侧合计只在两侧都有会肿胀的大脑中动脉区梗死时，才走恶性水肿与脑疝的病程（恶性梗死的证据来自大脑中动脉区梗死）：两侧前或大脑后动脉区的梗死（或一侧大脑中动脉、另一侧大脑前动脉）是两侧各自的中度占位效应，肿胀仍合计来决定意识；只有和另一侧合计才达标准的那一侧，文字会说明是两侧合计，不会在较小的单侧体积旁写「> 145 mL 为高风险」。不论大小，肿胀达昏迷范围（8 mm，单侧或两侧合计）就是恶性脑水肿，从第 3 天起、仍在这个范围时脑疝：两侧颈动脉区（中与大脑前动脉区）都梗死、各自都未达恶性的大小时，两侧一起肿到昏迷并向下脑疝，附致命风险，而不是昏迷一周后醒来；单侧约 245 mL、本身的中线偏移达 9 mm 的半球也一样。模型里肿胀造成的昏迷一定伴随这个病程；昏睡（6–8 mm）则不会。两侧大脑半球最后都有三分之二以上梗死（包括脑疝造成的续发梗死），或两侧的大脑中动脉区都有三分之二以上梗死（皮质和丘脑之间很大一部分的白质连结经过这里），不论有没有脑疝，存活者在较晚那次病灶的两周后列为意识障碍（植物人或最小意识状态，NIHSS 1a 计 3 分），不会醒成清醒的患者（Adams 2000；Multi-Society Task Force 1994），「最终」页也换成两侧的说明，不用单侧的存活数字。
7. **连锁反应**：用文献中的简化门槛（例如 14 小时内梗死 > 145 mL → 恶性水肿；小脑梗死 ≥ 20 mL 要观察肿胀、≥ 38 mL 恶性肿胀可能），把后果投射到**没有被阻塞**的脑区。只有在 Willis 环把血送进阻塞或狭窄之后的区域时，才说它的侧支代偿启动：静止时供应某个交会点的动脉全都阻塞、狭窄，或来自这样的交会点，而前交通、后交通动脉或眼动脉流进这个交会点的血流增加超过每分钟 5 mL（模型的选择）。所以它能接上阻塞的颈动脉、A1、P1 或基底动脉，以及内颈动脉 T 型血栓之后的大脑前动脉，但到不了在 Willis 环之后阻塞的 MCA、A2 或 P2；事件只列出真正有送血的通道（两条交通动脉都缺如时只有眼动脉），仍有梗死时会说它补不足，并列出那个区域的梗死量。只有那个区域在动脉阻塞时也维持运作，才说它足以避免梗死（绿色）：内颈动脉 T 型或基底动脉只塞住几分钟、因为发作短暂而没有梗死时，会说它不足以让那个区域在阻塞时维持运作（症状就来自那里），直到动脉再通。（单看交通动脉血流反转说明不了什么：在对称的网络里前交通动脉静止时的流向是任意的，所以它在一侧的 M1、M2、A2 阻塞时「反转」，另一侧从不反转。）纹状体内囊梗死的皮质征象（Donnan 1991）：阻塞从未到达皮质时（只有豆纹动脉）从发作起出现；M1 阻塞在皮质坏死前再通时，从再通起出现，并说明皮质正逐渐恢复功能；文字只列出真正坏死的深部构造（不列早期再通保住的内囊）。

阻塞，也可能是侧支补不上的内颈动脉阻塞），而且只在它描述的无力或感觉丧失（脸、手臂或腿的无力，或脸与手臂、整个半身的感觉丧失，列出的或目前无法检查的）旁边，或内囊梗死时才显示：M1 取栓时血栓碎片塞住下分支，留下纹状体与那条分支的皮质（含脑岛）梗死，占这个供应区四个皮质区，旁边是韦尼克失语与偏盲、完全没有无力，这时以下分支综合征的标签命名；血流动力学背景下的边界区表现，改以分水岭标签命名：整个半球的受损有 35% mL），只看整个半球的比例时，同样的大脑中动脉区表现在左侧称为分水岭，右侧却称为完全性大脑中动脉综合征。前脊髓动脉综合征的标签标示上段颈髓的梗死。各脑区的语言成分依流畅度、理解与复诵合成同一时间只有一种的失语类型（全面性、布洛卡、韦尼克、传导性、经皮质、混合型经皮质），成分被代偿后类型也会跟著改变，但只往较轻的类型变、说话流畅的失语不会再变回不流畅（哥本哈根失语研究）：变轻的全面性失语改列布洛卡型，理解比说话受损更重时改列韦尼克型；再通救回的组织逐渐恢复功能时，由留下来的部分决定类型（言语失用或坏死组织造成的缺损让它维持不流畅），第 项）照样列出，到昏迷时才不列（此时这些项目依完全没有反应的患者计分）；意识障碍以不能说话的患者计分，也不列言语的项目。这些缺损并没有消失：「此刻」（摘要与症状清单）、功能热图（点状格子与点开的格子）、脑区细节与「最终」页（含缺损项数）会另外标成「目前无法检查」并注明原因（意识下降、看不见、无动性缄默、听不懂话、肢体瘫痪），不算改善或消失，能检查时再列出，NIHSS 也不会因此降低。NIHSS 分）；脑干病灶造成双侧感觉丧失计 2 分；完全不能说话的全面性失语（第 9 项 3 分）也不能遵从指令（1c 计 2 分），构音项以「无法说话」计 2 分（第 10 项）；意识障碍也照这样不能说话、不能遵从指令的患者计分，这是床边检查看到的样子——若发现患者能用眼球动作回答，那就是闭锁综合征，应以清醒的患者计分，模型无法模拟这个发现；无动性缄默以清醒但不能说话（第 9 项 3 分、第 10 项 2 分）、不做任何指令（1c 计 2 分）、因失语以外的原因无法回答（1b 计 1 分）的患者计分）。两侧额叶眼动区都受损时，不会同时列出偏向左右两边，而是两侧自主水平注视都困难；上段颈髓造成的两侧缺损和延髓造成的同一侧缺损，每一侧只列一次；同一侧较广的缺损所包含的一部分，严重程度不超过它时，就以那个较广的缺损列出，如同象限盲是偏盲的一部分（瘫痪的手臂不会另外列出较轻的肩膀无力；全部感觉都丧失的半侧感觉丧失，包含这一侧的痛温觉、位置感与脸、手、脚的感觉丧失；整侧脸的周边型麻痺包含下半脸的无力），比整体更严重的那一部分则列在旁边，表示那里更严重（脸与手的感觉丧失比这一侧其他地方更多）。早期另加水肿与远端抑制造成的暂时失能（它会让缺损延续、加重，但动脉再通后，不会让血流恢复时已经消失的缺损再回来：及早救回的基底动脉阻塞不会在第 3 天变成闭锁综合征），之后依该功能的备援程度逐步代偿。没有备援的功能，「此刻」要等缺损完全来自坏死组织时才说它不会再改善：梗死周围的水肿仍在加重它、肿胀的邻近组织压迫它的路径，或组织还活著只是暂时不运作时都不说，刚改善的那一个时间点也不说。失语与（右半球的）忽略主要靠同一半球剩下的皮质重组，对侧同源区接手得较差：同一半球的大脑中动脉皮质梗死超过六成后，能被代偿的比例逐渐下降，几乎全部梗死时只剩一成左右，所以整个大脑中动脉区梗死的存活者 3 个月后仍是全面性失语或严重的布洛卡／韦尼克型失语、严重忽略；大脑中动脉分支（M2）的梗死与及早再通的患者恢复照旧（大多数失语患者恢复得不错，持续中重度缺损主要见于整个大脑中动脉区或大范围颞顶叶受损：Wilson 2023）。理解力靠韦尼克区本身剩下的部分接手，与整个梗死多大无关：韦尼克区梗死超过一半后能被代偿的比例下降，超过约五分之三时，3 个月与 6 个月后仍是中重度的韦尼克型失语（NIHSS 第 9 项 2 分、两个问题都答不对），一半以下则恢复到轻度（Naeser 1987；持续的韦尼克型失语通常还涉及缘上回与角回：Kertesz 1993）；这种梗死后好转的全面性失语，会变成严重的韦尼克型失语。眼球偏向不受病灶大小影响：它靠对侧额叶眼动区在数天内接手（Steiner & Melamed 1984）。脑干由致密的神经束与神经核组成，小梗死也会切断相应比例的纤维：缺损在症状门槛以下仍依受损比例分级，降到 15% 时才消失（比这更小的部分在模型里代表相邻动脉供应的边缘，例如 Wallenberg 时的延髓内侧、Percheron 梗死时的中脑），所以恢复中的脑干征象逐渐减轻、不会一起消失，梗死略低于门槛时也会留下相应的缺损；两侧一起才有的征象（构音不能、双侧吞咽困难、呼吸）仍要两侧都达门槛，以下只剩每一侧的征象（口齿不清、各侧无力）。低于门槛的脑干区只决定它自己的缺损，不算这一侧的路径已经失去：大脑后动脉 P2 段阻塞造成的大脑脚五分之一梗死、椎动脉阻塞波及的延髓内侧边缘，都不会拖慢对侧半球造成的无力的恢复；两侧都只有门槛以下的小梗死时，各侧的缺损照单侧病灶代偿。丘脑梗死（因旁边的内囊）造成的短暂无力也不算失去路径；延髓外侧梗死造成的同侧脸部无力，只切断对侧半球往这一侧脸部、交叉后先下行到延髓再折返的那一部分纤维（有些人才有：Urban 2001），大部分纤维在脑桥交叉；它造成的中枢性脸部无力在有这个症状的患者都很轻微，出院时都已消失（Kanbayashi 2021）。所以它完全不算失去一条路径：同侧或对侧也有运动皮质梗死时，皮质造成的脸部无力和延髓造成的脸部无力都恢复得和单独发生时一样（右侧 M2 梗死旁的延髓脸部无力，和没有 M2 梗死时一样在 3 个月时消失），只有两个半球自己的径路都被切断时才照两侧受损恢复。脑干本身组织低于门槛时，水肿造成的短暂抑制不会把它推过门槛而在第 2 天出现新的偏瘫（也不会推过某个缺损自己较高的门槛：不会只出现几天的霍纳氏综合征或嗜睡）；侧支撑住的半影区中还会死去的那一部分仍算失能。皮质脊髓径汇集处（内囊后肢、大脑脚、脑桥基底部）有一半以上梗死、一开始就瘫痪的手或脚，能被代偿的少很多：手臂会留下中度无力（NIHSS 3 分），不会恢复到只剩漂移，脚恢复得较好（这类患者 28 位中只有 1 位恢复手臂的独立动作，单纯皮质卒中则 4 位中有 3 位：Shelton & Reding 2001）；那里的小腔隙只切断部分纤维，代偿比例照常。两侧都在瓶颈处（大脑脚或脑桥腹侧）被切断时，两侧失去得越多，能代偿的越少：在症状门槛时不再额外减少，到模型称为典型闭锁综合征的程度（两侧脑桥腹侧各 40%）时作用完全，两侧都约有三分之一以上梗死时才标为瓶颈（「此刻」、脑区与「最终」页）。桥接治疗再通后两侧大脑脚各约四分之一梗死（0.8 mL），是两侧的病灶，恢复到轻度无力，不是闭锁综合征（两侧脑桥梗死的结果比单侧差：Kumral 2002；但再通后即使 DWI 上两侧脑桥大范围病灶，也不一定结果不好：Haussen 2016）。有动眼神经麻痺的那一眼不会另外列出霍纳氏综合征：瞳孔的收缩肌与扩张肌都失去神经支配时，瞳孔停在中等大小、对光没有反应，动眼神经麻痺合并霍纳氏综合征看起来可能像瞳孔没受影响（Serdaru 1983）；同一病灶造成的半身流汗减少仍会列出。霍纳氏综合征与这种流汗减少，需要比 P2 段供应的比例更大的中脑外侧梗死：大脑后动脉阻塞通常造成视野缺损、半身感觉丧失与神经心理缺损，合并霍纳氏综合征只见于近端阻塞、中脑前外侧也梗死的个案（Bassetti 1995），后循环登录研究中霍纳氏综合征与近端（延髓）的供应区相关（Searls 2012）。

## 老实说：限制

- **血流是 0 维的集总模型**，没有脉动、没有血液黏滞度变化、没有真实的 3D 流体力学。数字（mL/分）只在「数量级」与「方向」上有意义。
- **阈值与时间常数是从文献简化、再手动校正**，目的是呈现正确的「趋势」（侧支越差梗死越大、越早再通救越多、后循环 NIHSS 偏低……），不是预测某个患者会有几 mL 梗死。组织坏死的速度依大血管阻塞实测的梗死核心扩大速度校正（中位数每小时约 3–5 mL，每小时 10 mL 以上算快速扩大，最快约 74 mL）；侧支中等与良好时，模型前几小时的扩大速度（每小时约 20–30 与 10–20 mL）仍高于中位数，因为终末动脉的穿通支供应区与模型里没有血流的前颞叶皮质很早就坏死。两条交通动脉都没有、侧支又差的半球几乎完全没有血流，第一小时就损失约 100 mL，超出实测范围。猴子实验的门槛（血流低于每 100 克每分钟 10–12 mL 时 2–3 小时内梗死）比模型依循的人类数据快。深部白质的时程依「各再灌注时间下内囊梗死的患者比例」校正，并把这个比例当作内囊坏死的比例（模型只有一个典型的患者，不是一群人的分布）；腔隙依它所在组织的时程坏死。缺血开始两天后半影区就不再算「有风险」，这是模型的选择，依据的是 PET 上缺氧但仍存活的组织在这段时间越来越少，不是实测的界限。小脑与延髓中没有穿通支供应的部分沿用侧支供应组织的一般时程，没有自己的校正，所以同样的血流下，它们现在比脑桥撑得久；脑桥的基底动脉校正则维持当初校正的样子。
- **水肿的幅度与时程是教学用的近似**：每个床用同一组曲线，实际上个体差异极大；3D 变形只沿表面法线推出，不是真正的组织力学，放大倍率只为了看得见。Ropper 的分级是单侧占位造成的侧向偏移与意识的关系；两侧半球都肿胀时，模型把两侧的肿胀加在一起、视同单侧半球的肿胀，两侧都有三分之二的大脑中动脉区失去功能时至少列为嗜睡，两侧大脑半球或两侧大脑中动脉区都有三分之二以上梗死时，存活者两周后列为意识障碍：三者都是模型的选择，没有数据依大小给出两侧半球梗死的意识程度。
- 小血管（皮质穿通支、脑干小分支）的位置是**示意**，只有主干有统计图谱校正。表面的动脉与侧支画在「把脑沟填平」的表面上方，避免一路潜进皮质下；这只影响画面，血流模型用的仍是原本的血管长度。
- **脑部网格之间有几处小缝**：两半球之间的中线与脑干、小脑之间留有几毫米的缝，第三、第四脑室在少数角度会露出一小段（最多约 4 mm）。大脑半球与小脑之间刻意留了约 3 mm（小脑天幕的位置），小脑上动脉（SCA）的分支走在这条缝里；为此画面上枕叶与颞叶的下缘在交界处削薄了约 2 mm（最多约 6 mm），脑区体积与血流模型不受影响。和真实大脑一样，小脑上面大多被枕叶盖住，要看完整的 SCA 可在「显示」隐藏该侧半球或调低皮质透明度。
- 症状、综合征、NIHSS 都是「由受损脑区推估」，实际临床表现差异很大；出血性卒中、静脉窦血栓、血管炎等**都没有**模拟。
- **血压的效果是模型假设**：模型里血压越高，侧支血流越多、梗死越小（在默认的 93 mmHg 附近特别敏感），高血压本身没有坏处；实际上急性卒中时血压过高与过低都与较差的预后相关，用药物升压只有小型试验支持。平均动脉压 ≥ 120 mmHg 时，连锁反应会提醒这些证据与溶栓前的血压上限。
- **后循环的时间窗是校正出来的**：脑干软脑膜侧支与较慢的脑干半影区，是为了符合基底动脉取栓试验（ATTENTION、BAOCHE）的趋势而设定，吻合路径与参数是模型假设，不是测量值。这个校正是针对单一段基底动脉阻塞：下段基底动脉连同另一段一起阻塞时（长血栓，连 AICA 的开口一起盖住），中等或差的侧支会让旁正中脑桥低于梗死核心的门槛，模型里即使 30 分钟就再通，也只救得回小脑，几乎救不回脑桥（一样是闭锁综合征或意识障碍）。ESO/ESMINT 指引引述 BASILAR 登录研究：取栓在各个 BATMAN 分层（这个分数也计入血栓负担）都与较好的结果相关，并建议不论侧支分数都进行再灌注；这种长血栓是不利因素、不是无效，这是模型的限制。同样地，P2 阻塞被假设为连同末端分叉一起堵住（某一皮质分支的侧支血流不会经过分叉再灌回其他分支），让未治疗的 P2 阻塞出现常见的偏盲；左右 PICA 之间跨中线的吻合也设得很弱，让默认侧支下 PICA 内侧分支阻塞就出现像前庭神经炎的孤立性眩晕；PICA 与 AICA、SCA 在小脑半球的吻合则设得稍强，让整条 PICA 阻塞仍取决于侧支与及早再通。延髓外侧梗死合并病灶同侧偏瘫（Opalski 变异型）没有重现：模型没有延髓最下段（锥体径已交叉处）这个区域。
- **锁骨下动脉没画出的胸壁与颈部侧支是校正出来的**：设定的目标是锁骨下盗血时基底动脉在休息时仍维持顺向，平时它们几乎没有血流。同一组吻合在颈总动脉或头臂动脉干阻塞时也是侧支来源（甲状颈干／甲状腺上动脉 → 外颈动脉 → 颈动脉分叉，颈总动脉阻塞后的血管摄影可见；头臂动脉干阻塞时还有主动脉经胸廓内动脉流入倒流的锁骨下动脉），所以这两种阻塞比没有它们时代偿得好很多。吻合强度不是测量值。
- **非运动症状的证据等级不一**：出汗异常、味觉与病理性哭笑的定位多来自病例系列与小型研究，严重度是示意；REM 睡眠行为障碍的证据互相矛盾，所以只在任何脑桥或延髓梗死后列为可能的晚期问题，不是某个部位的症状。模型没有下丘脑，所以下丘脑本身的体温设定、昼夜节律、食欲与内分泌都没有模拟。中枢性发烧不是症状（缺血性卒中后早期发烧多半是感染，文献中的中枢性高热大多见于出血），只在两侧上脑桥（或中脑—丘脑旁正中）被盖大范围梗死又昏迷时，以「中枢性高热的风险」警示显示。「最终」页的族群盛行率不是这个病例的预测。
- **腔隙只有几种典型落点**：每个腔隙固定约 0.8 mL，表现取自典型的腔隙综合征（多为轻到中度）；落在内囊最下方、小却造成严重偏瘫的情况，以及腔隙大小不同造成的差异，都没有模拟。卒中后不自主运动大多只以族群比率列出，不会出现在病例的症状里；只有两种和一小块供应区相关的晚发型列为可能的症状：中脑旁正中梗死后的霍姆斯颤抖，以及脉络丛后动脉区梗死后抽动、扭转、不稳的手。
- **脊髓只有最上段**：模型只有前脊髓动脉从两侧椎动脉起始处供应的上段颈髓（C1–C3）；下方汇入的根髓动脉（50 人的磁振血管摄影中有 24 人看得到：Sheehy 2005）没有模拟，所以两侧椎动脉在脊髓分支之后阻塞时，C1–C3 会整段梗死，可能高估了这时脊髓受损的机会。脊髓造成的无力与感觉丧失在模型里几乎不会恢复（恢复曲线是脑的），实际上脊髓梗死后许多人在数月到数年间仍会进步（Robertson 2012）。
- **恢复与代偿是示意**：只依「哪种功能、单侧或双侧」给群体平均的曲线，没有康复强度、年龄、共病等因素，不能拿来推估任何人的恢复。皮质脊髓径在汇集处被切断时，肢体能恢复的少多少，是估计值；失语与忽略的代偿随大脑中动脉皮质剩下多少而下降的范围与比例、韦尼克型失语的代偿随韦尼克区梗死比例下降的范围（一半到五分之三）、脑干分级到 15% 的下限、瓶颈作用的范围（从症状门槛到两侧 40%）、中脑外侧从多少比例起会切断交感纤维（35%），以及「保住 50 mL」算有益的门槛，也都是估计值。模型没有对「缺血多久」另设恢复上限：基底动脉阻塞没有大范围早期缺血时，再通到 48 小时仍有一半结果良好、与时间无关（Strbian 2013），所以晚再通的结果由它留下的脑干梗死决定。再通后功能恢复只用一种曲线，速度由缺血多久决定，救回的功能最后全部回来；实际上救回的组织仍可能依当初灌注不足的程度损失部分神经元，恢复也可能因其他原因延迟（「休克脑」）。脑区造成的昏迷与嗜睡一律在该脑区开始缺血两周时改列为接下来的状态（长期嗜睡；两侧被盖大范围梗死后则是意识障碍或闭锁），实际上醒来的时间从数天到数周不等。脑干意识状态的事件跟著这些标签，依造成它的病灶自己的时钟走：基底动脉昏迷的事件只在列出昏迷时进行（两侧被盖在梗死前因再通而救回时，到它恢复功能为止，否则到改列那时），标签改变时再由闭锁（典型或不完全）或意识障碍的事件接续。
- **再通细节是示意**：部分再灌注以「该比例的供血区恢复血流」近似，没有真正的微血管模型；永久的再阻塞最终梗死会回到不治疗的结果（只是延后），无再流的比例证据有限；已发表数据只供参考，不会决定模拟结果。溶栓药物（alteplase 或 tenecteplase）不影响模拟；选的时间是血流恢复的时间，不是开始用药的时间；腔隙性（单一分支）阻塞不会被治疗打通；有远端栓塞时显示的 eTICI 分级，是由被塞住分支供应的正常血流比例算出，不是来自血管摄影。
- **模型不模拟死亡**：未减压的脑疝通常致命，病程与「最终」页会标示「很可能死亡」（两侧大脑半球或两侧大脑中动脉区都被破坏时，单侧的存活数字不适用，改说明存活者会停留在意识障碍；两侧一起向下脑疝时，也不引用单侧存活者的预后）；小脑肿胀昏迷而未手术则标示「危及生命」，不手术的死亡率没有可靠的数字（研究没有未手术的昏迷对照组）；基底动脉没有打通、又因基底动脉病灶本身（脑干或丘脑）而昏迷时标示「常会死亡」（取栓试验内科对照组 90 天死亡率 55% 与 42%），从那条动脉阻塞之后才算：叠加的半球肿胀造成的昏迷是脑疝自己的风险。闭锁综合征与双侧延髓内侧梗死不是「通常致命」，但死亡率不低（约 60% 与 24%），「最终」页另外提醒。这些情况下，之后的病程、3 个月与 6 个月的 NIHSS 都是假设患者存活的结果。
- **「最终」页是同一个模型的两次计算**：「未治疗」是同样的阻塞但没有再通，不是真实世界的对照组（病程常会致命的那一栏，NIHSS 注明「假如存活」）；3／6 个月取时间轴上那两站（从第一个事件起算），最终梗死则在最后一次血管变化后 6 个月评估：较晚的变化让这个评估落在时间轴的 6 个月之后，「最终」页会写出晚了多久，只有梗死或列出的缺损（连同严重度与分组）在这段期间还会改变时，才标示「6 个月时尚未稳定」——6 个月时缺损被其他路径接手的比例每个月仍会多一个百分点左右，只有让缺损换到另一组时才算；晚期事件与最终脑区不会另外延后重算。缺损分「仍明显／部分代偿／大致代偿」的门槛（25%、60%）是为了阅读方便而定的。最终梗死把上段颈髓与脑一起算进去，并标出其中脊髓的部分（神经元损失的估计只算脑）；脑区清单列出梗死达该区 5% 以上、或占最终梗死十分之一以上的脑区，这两个门槛也是为了阅读方便。
- **每一条软脑膜侧支的强度是手动设定的**：吻合的容量随侧支等级、也随两端动脉的血流量增加。大脑凸面上，大脑前动脉与大脑中动脉之间的吻合，让每一条大脑中动脉分支依它供应的组织量得到大致相同的侧支容量（运动区那条原本给到约 1.7 倍，侧支中等时中央前动脉阻塞完全没有症状）。大脑后动脉与大脑中动脉之间的吻合给顶后动脉与颞枕动脉较多，所以侧支中等时，单独阻塞其中一条在模型里没有症状；颞前动脉与颞后动脉则完全没有吻合，不论侧支好坏，阻塞都会出现完整的缺损。
- **大脑表面的软脑膜动脉左右对称，其他部分不完全对称**：模板脑与供应区图谱本身左右不对称，流量模型原本直接沿用每条动脉描绘出的长度与它供应的组织量，同一条动脉在两侧阻塞的结局因此不同（侧支良好时，右侧距状动脉阻塞没有留下永久视野缺损，左侧却留下偏盲：左侧颞枕动脉描绘出来长 115 mm、右侧 98 mm，供应的组织也多四分之一，经它来的侧支血流较少）。现在大脑半球的软脑膜动脉（A2、M2、P2 及其皮质分支）和它们之间的软脑膜侧支，在流量模型里用左右两侧长度与基础流量的平均，左右对应的阻塞得到相同的灌注压（相差约 1.5 mmHg 以内）；量出来的组织体积（梗死体积）仍照图谱。Willis 环、穿通支、椎基底动脉与小脑动脉仍用描绘出的长度，因为后循环的校正是以它们为准；图谱也在两侧把某些区域分给各供应区的比例不同（例如右侧顶上小叶较多属于大脑前动脉）。所以接近门槛的缺损仍可能只出现在一侧，或在一侧较晚才稳定下来：例如大脑前动脉阻塞后的皮质感觉丧失、侧支良好时距状动脉阻塞后的中心暗点。
- **一侧的阻塞可能让另一侧的侧支变多**：Willis 环与大动脉在同一个阻力网络里，一侧的阻塞（最主要是大脑前、后动脉的 A2、P1 或 P2，也包括小脑的动脉或大脑中动脉的分支）会让仍有血流的动脉（Willis 环、基底动脉顶端）压力稍微升高，另一侧软脑膜侧支的血流也跟著增加；加上这条阻塞后，另一侧的梗死（多半是大脑中动脉区）反而变小：大梗死最多小约五分之一（侧支良好时，右侧下分支梗死 58 mL 在左侧 P2 阻塞旁变成 46 mL，右侧上分支梗死 68 mL 在左侧 A2 阻塞旁变成 59 mL，右侧 M1 梗死 163 mL 在两者旁都约 155 mL），小梗死小得更多（侧支中等时，角回分支梗死 7 mL 在另一侧 P2 阻塞旁约 4.5 mL）。检查过的 512 组侧支良好或中等的两侧单一阻塞中约五分之一如此（侧支差时没有），其中 12 组两个阻塞合计的梗死反而比较大的那一个单独时小（右侧 P1 阻塞加上左侧下分支梗死：单独 59 mL，合计 51 mL）。实际上大动脉损失的压力很小，不论一条分支如何，Willis 环的压力都接近全身血压，这个效果应该可以忽略。要消除它得改血流模型本身（让阻塞给其他分支增加的压力不再喂给侧支，或让动脉自动调节），会改变所有受影响的合并病例的体积，以及随之而来的肿胀与脑疝，所以列为限制。
- **缺损是一级一级分的**：肢体不是完全瘫痪就是稍微能动，NIHSS 第 5 项是 4 分或 3 分，所以刚好落在两级交界的极少量组织就可能让它跳一级。中段基底动脉阻塞、侧支差时，12 小时已经梗死了脑桥腹侧；这时取栓只救回 0.2 mL（尾侧脑桥基底部不治疗时 63% 梗死，治疗后 59%），3 个月时四肢却从完全不能动变成稍微能动（NIHSS 20 分，不治疗 24 分）。模型无法消除这类门槛；文字会写出救回的量，也不把差距算在再通身上（见上面的「血管再通」事件），但「最终」页仍会显示两个 NIHSS。
- **不适合拿来回头评断真实病例**：例如「如果当时取栓会不会不同」——模型是标准脑加平均参数，答案只反映模型假设。

<a id="開發"></a>
## 开发

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 引擎、界面元件（jsdom）、文件与输出不变量的测试：每条规则都能被触发、治疗不会让梗死变大、症状不会闪烁、文件里的数字与数据一致……
npm run lint && npm run typecheck
npm run build      # 输出到 dist/，相对路径，可放在任何子目录
```

<a id="重新產生解剖資產"></a>
### 重新产生解剖资源

`public/data/brain.{json,bin}` 与 `src/anatomy/generated/*.json` 已放在 repo 里，一般开发不需重建。
若修改了 `src/anatomy/`（血管、脑区）想重建：

```bash
python3 -m pip install -r tools/requirements.txt
npm run assets:build    # = vite-node tools/export-anatomy.ts && python3 tools/build_assets.py
```

第一次会下载约 80 MB 的公开图谱到 `tools/.cache/`（已 gitignore），全程约 1 分钟。

<a id="部署到-github-pages"></a>
## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**（只需做一次）。
2. 合并到 `main`（或在 Actions 分页手动执行 *Deploy to GitHub Pages*）。
3. `.github/workflows/deploy.yml` 会跑测试、建置并发布 `dist/`。网址为 `https://<帐号>.github.io/<repo>/`。

Vite 的 `base` 设为 `'./'`，所有资源都是相对路径，repo 改名或使用自订域名都不需要改设定；
状态存在网址 `#` 后面，不需要伺服器路由。

```
src/
  anatomy/     血管、脑区、症状、综合征、变异、范本、时间轴、再通证据、数据来源（sources.ts）

  engine/      solver → hemodynamics → schedule／treatment → tissue → edema／cascade → recovery → clinical → simulate；embolus

  i18n/        界面字符串（繁体中文／简体中文／英文／德文／日文），依功能分档
```
