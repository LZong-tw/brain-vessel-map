<a id="experimental-public-data-calibration"></a>
# 公開資料的實驗校正

「詳細資訊」校正工作台嘗試以發表的彙總梗塞擴大觀測，進行示意的前循環擬合。**這次校正被否決：**擬合因子顛倒了預期的側枝品質順序，一個擴大目標無法達到，且所有基準體積與獨立參考明顯不符。工作台是實驗診斷，不是新的有效側枝設定；候選因子與預設模擬分開。

<a id="published-observations"></a>
## 發表的觀測

[MacLellan et al.，2021 年線上發表、2022 年期刊卷期](https://doi.org/10.1016/j.jstrokecerebrovasdis.2021.106208)分析 DEFUSE 3 兩治療組中未再灌流的 84 位參與者。梗塞擴大從基準影像測量至隨機分派後 24 小時影像。發表的增加中位數為：

| 基準灌流概況 | 擴大中位數，mL |
| --- | ---: |
| HIR 與 CBV index 都有利 | 21.7 |
| 一項有利 | 40.9 |
| 兩項都不利 | 108.2 |

分析把 HIR 大於或等於 0.34、CBV index 小於或等於 0.74 分為不利。這些影像量測不是 App 的良好／中等／不良側枝設定。把有序分組對應至 App 三級設定，是明示的建模假設。[原出版者摘要](https://www.strokejournal.org/article/S1052-3057%2821%2900613-3/abstract)提供彙總觀測；不重建個別軌跡或病人層級分布。

<a id="borrowed-clock-and-representative-geometry"></a>
## 借用的時鐘與代表幾何

工作台需要各 MacLellan 分組未報告的經過時間，借用 [Albers et al., 2018](https://doi.org/10.1056/NEJMoa1713973) Table 1 原始 DEFUSE 3 藥物組中位數，見[原論文副本](https://paramedics.org/storage/news/Albers%20et%20al.pdf)。該組有 90 位參與者：發作至資格影像為 9 小時 55 分，發作至隨機分派為 10 小時 44 分。加上指定的 24 小時追蹤，得到發作後 34 小時 44 分的代表終點。模型擴大是終點梗塞體積減去基準影像時的梗塞體積。

這些是原始藥物組中位數，不是 84 人未再灌流分析或其三個灌流分組的時間量測。組合中位數形成假設的代表時鐘，不是觀測到的成對軌跡。不得把終點說成發作後 24 小時。

幾何採專案的單獨右 M1 阻塞（`M1_r`）、MAP 93 mmHg、無解剖變異。把整個模型供應區視為異質試驗族群的代表，是另一項明示假設。藥物組 116.1 mL 的灌流病灶中位數不定義這個模型供應區或最終梗塞邊界。10.1 mL 的基準缺血核心中位數是保留的獨立參考：不參與擬合，與模型基準不符之處必須可見。

<a id="what-is-fitted"></a>
## 擬合項目

對每個有序彙總目標，只改具名側枝導通度因子 G。研究專用 API 覆寫所有 `kind: 'collateral'` 具名血管的原始 `COLL_GRADE` 因子，包括小腦與顱外側枝。隱藏的 `BRAINSTEM_PIAL` 連線保留原始、依分級而定的導通度；既有組織閾值與時間常數固定。此廣泛覆寫不提供後循環校正證據：實驗病灶仍只有右 M1。獨立研究 API 不改一般模擬輸入或預設值。測試重現計算與否決；通過測試不表示已完成臨床校正。

<a id="rejected-fit-result"></a>
## 被否決的擬合結果

在上述幾何與時鐘下得到下列模型輸出。殘差是模型擴大減發表目標；顯示值已四捨五入。

| 發表的灌流組 | 候選 G | 模型基準，mL | 模型擴大，mL | 擴大殘差，mL |
| --- | ---: | ---: | ---: | ---: |
| 兩項有利 | 0.097422832 | 274.995 | 21.7000004 | 約 0 |
| 一項有利 | 0.259092893 | 255.489 | 40.9000072 | 約 0 |
| 兩項都不利 | 0.819373662 | 172.040 | 81.916233 | −26.283767 |

較不利的發表分組反而得到較高候選 G，與預期側枝品質解釋相反。到了假設的晚期基準，模型已發生大量梗塞：降低 G 增加基準傷害，讓量測期間可再擴大的剩餘體積變少。因此兩個吻合的擴大差值掩蓋了極大的基準誤差。所有模型基準都不接近獨立 10.1 mL 參考，108.2 mL 擴大目標也未達到。

這些失敗共同否決所提幾何／時鐘／只調 G 的校正，不證明側枝效益在生理上反轉、不支持強迫調整組織常數來吻合，也不驗證替代預設設定。合理校正需要更多量測與有更充分依據的族群／幾何代表。

擬合點不是唯一可識別的生理導通度。阻塞幾何、血壓、側枝架構與組織動力學都能影響相同體積終點。三個彙總中位數不提供 G 的不確定區間、病人變異、獨立驗證或量測間經校正的梗塞擴大曲線。工作台須報告擬合殘差與基準參考比較，不暗示臨床準確性。這些論文不提供合成病人分布、治療效果估計、功能結局換算或病灶邊界。

<a id="remaining-calibration-scope"></a>
## 其餘校正範圍

此實驗不重新校正後循環或兩段基底動脈阻塞、小腦或延髓傷害動力學、腔隙性傷害動力學、48 小時半影慣例、Willis 環與後顱窩動脈解剖對稱性，或頂後、顳枕與顳部軟腦膜吻合。這些仍未驗證，保留原假設。擴展擬合需要明確新增證據與測試，不能把前循環彙總擬合轉移後就宣稱驗證完成。

<a id="additional-early-growth-attempt-not-adopted"></a>
## 額外早期擴大嘗試：未採用

[Wheeler et al. (2015)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4478123/)把初始擴大定義為基準梗塞體積除以發作至影像時間，不是瞬時導數。M1 分組（33 人）中位數 2.9 mL/h，IQR 1.3–7.6。相較晚期、混合族群 DEFUSE 3 目標，解剖比較更接近，但仍缺少公開成對的 M1 特異時鐘、完整軌跡與區域組織傷害量測。

可重現的 `diagnoseEarlyGrowthCalibration()` 實驗把全世代 3.7 小時時鐘套用於此分組，採單獨右 M1、中等側枝、MAP 93 mmHg、無變異。不把任何代表設定推論為病人層級聯合分布。搜尋延遲與組織時間常數的共同乘數；0.001–10,000 搜尋區間與 80 次迭代是數值選擇，不是臨床參數範圍。

| 實驗 | 結果 | 決定 |
|---|---|---|
| 既有模型 | 假設時鐘下為 24.728457 mL/h | 保留不符之處可見 |
| 所有組織時間乘上共同因子 | 10.284395× 得到 2.9 mL/h，3.7 h 時為 10.73 mL | 否決跨組織類別轉移 |
| 只無限減慢預設組織 | 未改的深部／穿通支傷害留下 3.779299 mL/h | 目標無法達到 |

數值吻合會把內囊延遲從 2.5 移到約 25.7 小時，時間常數從 1.75 移到約 18.0 小時。這些改變沒有區域量測支持，且與 `tissueParams.ts` 討論的較早內囊傷害相衝突；彙總體積吻合不驗證這些改變。既有區域曲線本身仍保留已記錄的機率至組織比例假設。

ICA 與代表上分支 M2 比較得到 4.433152 及 0.097242 mL/h，發表彙總中位數則為 6.2 及 0.4。來源亞型不完全等於模型阻塞，時鐘也不是獨立配對；這些比較不是驗證。不向模型套用任何時間乘數。測試重現兩項否決，確認一般模擬結果及區域參數不變。只有解剖與時間成對資料能支持合理、實際套用的擬合後，才能勾選校正完成。
