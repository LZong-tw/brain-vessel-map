<a id="experimental-public-data-calibration"></a>
# 実験的な公開データ校正

詳細の校正ワークベンチは、公表された集計梗塞増大観測へ前循環の説明用フィットを試みます。**試みた校正は棄却します：** フィット係数は想定された側副血行の良さの順序を逆転し、一つの増大目標へ到達できず、全基準体積は独立参照と大きく異なります。これは実験診断であり、新しい妥当な側副プロファイルではありません。候補係数は既定シミュレーションと分離します。

<a id="published-observations"></a>
## 公表観測

[MacLellan et al.、2021年オンライン公開、2022年誌面](https://doi.org/10.1016/j.jstrokecerebrovasdis.2021.106208)は、両治療群の非再灌流DEFUSE 3参加者84人を解析しました。梗塞増大は基準画像から無作為化後24時間の画像までで測定しました。公開増加中央値は以下です。

| 基準灌流プロファイル | 増大中央値、mL |
| --- | ---: |
| HIRとCBV indexの両方が良好 | 21.7 |
| 片方が良好 | 40.9 |
| どちらも良好でない | 108.2 |

HIRが0.34以上、CBV indexが0.74以下を不良と分類しました。これらの画像測定はアプリのgood/moderate/poor側副設定とは異なります。順序付き群をアプリの三等級へ関連付けることは明示的なモデル仮定です。[出版社の原抄録](https://www.strokejournal.org/article/S1052-3057%2821%2900613-3/abstract)は集計観測を提供します。個別経過や患者単位の分布を再構成しません。

<a id="borrowed-clock-and-representative-geometry"></a>
## 借用した時計と代表形状

各MacLellanサブグループの経過時間は報告されていないため、ワークベンチは[Albers et al., 2018](https://doi.org/10.1056/NEJMoa1713973)の原DEFUSE 3内科治療群Table 1の中央値を借用します。[原論文コピー](https://paramedics.org/storage/news/Albers%20et%20al.pdf)で確認できます。群は90人で、発症から適格画像まで9時間55分、無作為化まで10時間44分でした。指定24時間追跡を加えると代表終点は発症後34時間44分です。モデル増大は終点梗塞体積から基準画像時の梗塞体積を引いた値です。

これは原内科治療群の中央値であり、84人の非再灌流解析や三灌流群の時間測定ではありません。中央値を組み合わせた時計は仮定した代表時計で、観測された対応経過ではありません。終点を発症後24時間と記述してはいけません。

形状は本プロジェクトの単独右M1閉塞（`M1_r`）、MAP 93 mmHg、解剖学的変異なしです。全モデル領域を不均一な試験集団の代表とすることも明示的仮定です。内科群の116.1 mL灌流病変中央値はモデル領域や最終梗塞境界を定義しません。10.1 mL基準虚血コア中央値はフィットしない独立参照です。モデル基準との不一致は表示し続けます。

<a id="what-is-fitted"></a>
## フィット対象

順序付き集計目標ごとに変えるのは具名側副血管コンダクタンス係数Gだけです。研究専用APIは、小脳・頭蓋外側副血管を含め、`kind: 'collateral'`の全具名血管の元`COLL_GRADE`係数を上書きします。非表示`BRAINSTEM_PIAL`接続は元の等級依存コンダクタンスを維持します。既存組織閾値・時定数は固定です。広い係数上書きは後循環校正の根拠を与えず、実験病変は単独右M1のままです。別研究APIは通常入力・既定値を変えません。テストは計算と棄却を再現し、合格しても臨床校正されたことを意味しません。

<a id="rejected-fit-result"></a>
## 棄却したフィット結果

指定形状・時計で以下の出力となります。残差はモデル増大から公開目標を引いた値で、表示値は丸めています。

| 公開灌流群 | 候補G | モデル基準、mL | モデル増大、mL | 増大残差、mL |
| --- | ---: | ---: | ---: | ---: |
| 両方良好 | 0.097422832 | 274.995 | 21.7000004 | 約0 |
| 片方良好 | 0.259092893 | 255.489 | 40.9000072 | 約0 |
| どちらも良好でない | 0.819373662 | 172.040 | 81.916233 | −26.283767 |

不良な公開群ほど高い候補Gになり、想定した側副の良さの解釈と逆です。モデル梗塞の大部分は仮定した遅い基準までに既に生じています。Gを減らすと基準損傷が増え、測定間隔中に増大できる残体積が減ります。二つの一致した増大差は非常に大きな基準誤差を隠します。どのモデル基準も独立10.1 mL参照へ近付かず、108.2 mL増大目標へ到達しません。

これらの失敗は形状・時計・Gのみの校正案全体を棄却します。生理学的に側副利益が逆転する証拠でも、フィットを強制するため組織定数を変更する根拠でも、代替既定プロファイルの検証でもありません。妥当な校正には追加測定と、より裏付けられた集団・形状表現が必要です。

フィット点は一意に同定された生理コンダクタンスではありません。閉塞形状、血圧、側副構築、組織動態は同じ体積終点へ影響できます。三集計中央値はGの不確実区間、患者変動、独立検証、測定間の校正済み増大曲線を与えません。ワークベンチは臨床精度を示唆せず、残差と基準参照比較を報告する必要があります。論文は合成人口分布、治療効果推定、機能転帰換算、病変境界を提供しません。

<a id="remaining-calibration-scope"></a>
## 残る校正範囲

後循環・二区間脳底動脈閉塞、小脳・延髄損傷動態、ラクナ動態、48時間半影慣例、Willis輪と後頭蓋窩動脈の対称性、後頭頂・側頭後頭・側頭の別々の軟膜吻合は再校正しません。これらは未検証で既存仮定を維持します。拡張には追加根拠とテストが必要で、前循環集計フィットをそのまま検証として転用しません。

<a id="additional-early-growth-attempt-not-adopted"></a>
## 追加の早期増大試行：採用せず

[Wheeler et al. (2015)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4478123/)の初期増大は、基準梗塞体積を発症から撮影までの時間で割った値であり、瞬間微分ではありません。M1サブグループ（33人）は中央値2.9 mL/h、IQR 1.3–7.6です。遅い混合集団DEFUSE 3目標より解剖学的に近い比較ですが、公開されたM1固有の対応時計、完全経過、局所組織損傷測定はありません。

再現可能な`diagnoseEarlyGrowthCalibration()`実験はその群に、全コホートの3.7時間時計、単独右M1、中等度側副、MAP 93 mmHg、変異なしを仮定します。代表設定から患者単位の同時分布を推定しません。遅延と組織時定数の共通倍率を探索します。探索範囲0.001–10,000と80反復は数値的選択で、臨床パラメータ範囲ではありません。

| 実験 | 結果 | 判断 |
|---|---|---|
| 既存モデル | 仮定時計で24.728457 mL/h | 不一致を表示 |
| 全組織の時間に乗算 | 10.284395×で2.9 mL/h、3.7 hで10.73 mL | 組織分類を跨ぐ転用を棄却 |
| 既定組織だけ無期限に遅延 | 不変の深部・穿通支損傷が3.779299 mL/h残る | 目標到達不能 |

数値的一致は内包遅延を2.5から約25.7時間、時定数を1.75から約18.0時間へ移します。局所測定の裏付けがなく、`tissueParams.ts`のより早い内包損傷と矛盾します。集計体積一致はそれを検証しません。既存局所曲線自体も、文書化された確率から組織割合への仮定を維持します。

ICAと代表上部M2比較は4.433152、0.097242 mL/hで、公開集計中央値は6.2、0.4です。公開サブタイプは正確なモデル閉塞ではなく、時計も独立に対応していません。これは検証ではありません。時間倍率はモデルへ適用しません。テストは両棄却を再現し、通常結果と局所パラメータの不変を確認します。解剖・時間が対応したデータで妥当な適用フィットを支えられるまで、校正は未完了です。
