<a id="experimental-public-data-calibration"></a>
# 实验性公开数据校准

详情中的校准工作台尝试将示意性前循环模型拟合至已发表的合计梗死增长观察。**此次校准被拒绝：**拟合因子与预期侧支质量排序相反、一个增长目标无法达到，且全部基线体积与独立参考明显不符。工作台是实验诊断，不是新的有效侧支配置。候选因子与默认模拟分开。

<a id="published-observations"></a>
## 已发表观察

[MacLellan et al.，2021 年在线发表、2022 年期刊刊出](https://doi.org/10.1016/j.jstrokecerebrovasdis.2021.106208)，分析 DEFUSE 3 两个治疗组中未再灌注的 84 名参与者。测量从基线影像到随机分组后 24 小时影像的梗死增长。发表的增长中位数为：

| 基线灌注特征 | 增长中位数，mL |
| --- | ---: |
| HIR 和 CBV index 均有利 | 21.7 |
| 一项有利 | 40.9 |
| 均不利 | 108.2 |

分析将 HIR 至少 0.34、CBV index 至多 0.74 分类为不利。这些影像测量不是应用的良好／中等／差侧支设置。将有序组对应应用三种分级，是明确的建模假设。[出版方原始摘要](https://www.strokejournal.org/article/S1052-3057%2821%2900613-3/abstract)提供合计观察；不重建个体轨迹或患者层面的分布。

<a id="borrowed-clock-and-representative-geometry"></a>
## 借用时间及代表性几何

工作台需要各 MacLellan 子组未报告的经过时间。借用原始 DEFUSE 3 药物治疗组中位数，来自 [Albers et al., 2018](https://doi.org/10.1056/NEJMoa1713973)表 1，可见[原始论文副本](https://paramedics.org/storage/news/Albers%20et%20al.pdf)。该组 90 人：起病至符合条件影像为 9 小时 55 分钟，起病至随机分组为 10 小时 44 分钟。加上规定的 24 小时随访，代表性终点为起病后 34 小时 44 分钟。模型增长是终点梗死体积减去基线影像时的梗死体积。

这些是原始药物治疗组中位数，不是 84 人未再灌注分析或三个灌注组的时间测量。组合中位数产生假定代表性时间，不是实测配对轨迹。不能将终点描述为起病后 24 小时。

几何为项目单独右 M1 阻塞（`M1_r`），MAP 93 mmHg，无解剖变异。将这个完整模型供血区域视为异质试验人群的代表，也是明确假设。药物治疗组 116.1 mL 的灌注病灶中位数不定义该模型区域或其最终梗死边界。10.1 mL 的基线缺血核心中位数是保留参考，不参与拟合；与模型基线的任何差异必须保持可见。

<a id="what-is-fitted"></a>
## 拟合内容

仅针对每个有序合计目标改变具名侧支导流因子 G。研究专用 API 覆写每条 `kind: 'collateral'` 具名血管的原始 `COLL_GRADE` 因子，包括小脑及颅外侧支。隐藏的 `BRAINSTEM_PIAL` 连接保留原始随分级变化的导流系数。现有组织阈值和时间常数固定。这种范围广的覆写不提供后循环校准证据：实验病灶仍是单独右 M1。独立研究 API 不改变普通模拟输入或默认值。测试重现计算及拒绝结果；测试通过不代表模型得到临床校准。

<a id="rejected-fit-result"></a>
## 被拒绝的拟合结果

上述几何及时间假设下得到以下输出。残差是模型增长减去发表目标；显示数值经过舍入。

| 已发表灌注组 | 候选 G | 模型基线，mL | 模型增长，mL | 增长残差，mL |
| --- | ---: | ---: | ---: | ---: |
| 均有利 | 0.097422832 | 274.995 | 21.7000004 | 约 0 |
| 一项有利 | 0.259092893 | 255.489 | 40.9000072 | 约 0 |
| 均不利 | 0.819373662 | 172.040 | 81.916233 | −26.283767 |

较不利发表组分配了更高候选 G，与预期侧支质量解释相反。假定基线较晚，此前大量模型组织已梗死：降低 G 增加基线损伤，留给测量期间增长的体积更少。因此，两项吻合的增长差值掩盖了非常大的基线错误。没有模型基线接近独立 10.1 mL 参考，108.2 mL 增长目标也未达到。

这些失败共同否定所提出的几何／时间／仅 G 校准，不证明生理侧支获益逆转、不支持为强行拟合改变组织常数，也不验证替代默认配置。可辩护的校准需要额外测量及更有依据的人群／几何表示。

单个拟合点不是唯一可识别的生理导流系数。阻塞几何、血压、侧支结构和组织动力学可影响同一体积终点。三个合计中位数不提供 G 不确定性区间、患者变异、独立验证或测量间的已校准梗死增长曲线。工作台必须报告拟合残差及基线参考比较，不暗示临床准确性。论文不提供合成患者分布、治疗效应估计、功能结局换算或病灶边界。

<a id="remaining-calibration-scope"></a>
## 剩余校准范围

实验不重新校准后循环或跨两段的基底动脉阻塞；小脑或延髓损伤动力学；腔隙动力学；48 小时半暗带约定；Willis 环及后颅窝动脉解剖对称；或顶后、颞枕和颞动脉的独立软脑膜吻合。这些领域仍未经验证并保留现有假设。扩展拟合需要明确的额外证据和测试，不能将前循环合计拟合转用于其他领域，仿佛它已经验证了那些领域。

<a id="additional-early-growth-attempt-not-adopted"></a>
## 额外早期增长尝试：未采用

[Wheeler et al. (2015)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4478123/)将初始增长报告为基线梗死体积除以起病至影像时间，不是瞬时导数。M1 子组（33 人）中位数为 2.9 mL/h，IQR 1.3–7.6。相比晚期混合人群 DEFUSE 3 目标，解剖比较更接近，但仍缺乏公开配对的 M1 特异时间、完整轨迹及区域组织损伤测量。

可重现的 `diagnoseEarlyGrowthCalibration()` 实验为该子组假设 3.7 小时的全队列时间、单独右 M1、中等侧支、MAP 93 mmHg、无变异。不将这些代表性设置推断为患者层面的联合分布。搜索延迟及组织时间常数的共同乘数；搜索区间 0.001–10,000 及 80 次迭代是数值选择，不是临床参数范围。

| 实验 | 结果 | 决定 |
|---|---|---|
| 现有模型 | 假定时间下 24.728457 mL/h | 保持差异可见 |
| 乘以所有组织时间 | 10.284395× 得到 2.9 mL/h；3.7 h 时 10.73 mL | 拒绝跨组织类别转移 |
| 仅无限减慢默认组织 | 未改变深部／穿通支损伤留下 3.779299 mL/h | 无法达到目标 |

数值吻合会将内囊延迟从 2.5 小时移至约 25.7 小时，时间常数从 1.75 小时移至约 18.0 小时。没有区域测量支持这些变化，而且与 `tissueParams.ts` 所述明显更早的内囊损伤矛盾。合计体积吻合不能验证这些变化。现有区域曲线自身仍保留已记录的概率至组织比例假设。

ICA 及代表性上 M2 比较得到 4.433152 和 0.097242 mL/h，对照发表合计中位数 6.2 和 0.4。发表亚型不等于模型的精确阻塞，时间也未独立配对；这些比较不是验证。未将任何时间乘数应用于模型。测试重现两项拒绝，并确认普通模拟结果及区域参数不变。在解剖和时间配对数据能够支持可辩护的实际拟合前，校准项目保持未勾选。
