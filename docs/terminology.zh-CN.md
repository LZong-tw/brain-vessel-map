<a id="translation-terminology"></a>
# 翻译术语

简体中文、德语和日语翻译涵盖界面文字、解剖名称及现有临床解释。翻译不改变血管几何、模拟参数、临床概率或引用研究结果。MCA、ICA、ACA、PCA、PICA、AICA、SCA、MLF、NIHSS 等惯用标识保留。

<a id="simplified-chinese-zh-cn"></a>
## 简体中文（zh-CN）

参考为全国科学技术名词审定委员会编写的《人体解剖学名词》第二版。委员会的[人体解剖学名词目录](https://www.cnterm.cn/sd/yxjk/zwh/rtjp/)说明该术语项目。由复旦大学提供镜像的[2013 年文本](https://xtjp.fudan.edu.cn/Upload/Files/201804100314393640155.pdf)提供本次翻译所使用的可访问术语条目。其标题页含未完成的出版元数据，包括占位 ISBN；因此将其视为委员会编写的术语稿件，不据此证明正式印刷版本的书目信息。

明确的区域术语调整包括颈内动脉、大脑中动脉、脑桥、丘脑、脉络丛前动脉、辐射冠、内侧丘系、伏隔核、面神经和视辐射。解释使用简体中文及这些解剖名称，是应用现有教学解释的翻译，不是从术语书复制的定义。综合征人名、研究名称及模型假设在适当情况下保留。

临床中文也采用中国大陆的通行用法，例如使用“同向偏盲”对应 homonymous hemianopia，参见[北京市卫生健康委员会卒中信息](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jbzs/201912/t20191217_1250088.html)。该临床用语参考与委员会解剖术语目录不同。

<a id="german-de"></a>
## 德语（de）

解剖命名遵循通行德语神经解剖用法，包括德语医学文本惯用的拉丁血管名称：A. carotis interna、A. cerebri media、A. communicans anterior、A. basilaris 及小脑动脉。已核查来源为 Thieme 的 [*Klinische Neuroanatomie – kranielle MRT und CT* 脑动脉及血管供血区域章节](https://shop.thieme.de/api/media-proxy?url=https%3A%2F%2Fnginx%2Fmedia%2F18%2F19%2F9a%2F1653305463%2F9783131634146_musterseite.pdf%3Fts%3D1653305463)。翻译使用德语叙述及 Dysarthrie、Hemianopsie、Neglect、internukleäre Ophthalmoplegie 等通行临床名称。Putamen、Hippocampus 等共用拉丁解剖名称有意保留与英语条目相同的拼写。

<a id="japanese-ja"></a>
## 日语（ja）

解剖名称遵循日本解剖学会公开的[《解剖学用語 改訂13版》](https://www.anatomy.or.jp/yougo.html)，尤其是[血管术语](https://www.anatomy.or.jp/file/pdf/yougo/kaibo6.pdf)及[神经系统术语](https://www.anatomy.or.jp/file/pdf/yougo/kaibo7.pdf)。例如内頸動脈、中大脳動脈、前交通動脈、脳底動脈、後下小脳動脈、中心前回、内包、視床和内側毛帯。临床解释翻译为日语叙述，惯用缩写和人名保持可识别。

<a id="scope-of-verification"></a>
## 验证范围

完整性测试检查每个编写的本地化键，包括动态文字模板。选定术语断言保护区域解剖名称及未改变的惯用缩写。这些检查证明翻译覆盖和术语一致性，不是对全部教学叙述的独立临床审阅。路线图中的临床审阅仍是单独任务。

<a id="consciousness-terminology"></a>
## 意识术语

神经学英语 *stupor* 在简体中文中译为**昏睡**，依据 [MSD 中文解释](https://www.msdmanuals.cn/home/brain-spinal-cord-and-nerve-disorders/coma-and-impaired-consciousness/stupor-and-coma)：强刺激可短暂唤醒患者；**昏迷**对应 coma。德语使用 **Sopor**，即 [AWMF 022-016 分类表](https://register.awmf.org/assets/guidelines/022-016l_S1_Akute_Bewusstseinsstoerung_jenseits_der_Neugeborenenperiode_2021-01-abgelaufen.pdf)中的量性意识水平。该存档指南仅用于命名参考，不作为治疗建议。日语使用**昏迷**表示 stupor，**昏睡**表示 coma，依据[医学书院神经检查文章](https://www.igaku-shoin.co.jp/misc/medicina/shinkei4601/)中的区分。这些区域语言修正不改变模型意识阈值。
