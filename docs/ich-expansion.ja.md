<a id="intracerebral-hemorrhage-expansion-risk"></a>
# 脳内出血の拡大リスク

この独立した教育用計算器はAl-Shahi Salman et al., *Lancet Neurology* (2018)、[DOI 10.1016/S1474-4422(18)30253-9](https://doi.org/10.1016/S1474-4422(18)30253-9)の四予測因子モデルを再現します。[出版社PDF](https://www.pure.ed.ac.uk/ws/portalfiles/portal/74826881/PIIS1474442218302539.pdf)の3ページに適格条件、7ページに式と検証が記載されています。動脈性梗塞シミュレーションとは独立です。

<a id="published-equation"></a>
## 公開式

```text
PI = -4.426 - 0.230 * t - 0.0776 * V
     + 1.196 * sqrt(V) + 0.310 * A + 1.065 * C
p = 1 / (1 + exp(-PI))
```

`t`は症状発症から基準画像までの時間（時間）、`V`は基準画像の血腫体積（mL）です。`A`と`C`は発症時の抗血小板療法と抗凝固療法を独立に記録し、ありは1、なしは0です。その後の投与や中止は記録しません。不明入力をゼロとは扱わず、臨床的初期値やリスク区分閾値は追加しません。

出典は基準画像と再撮影間の「more than 6 mL」の増加を拡大と定義します。再撮影は発症から六日未満で行われ、80%超は48時間以内でした。したがって固定24時間確率ではありません。

<a id="population-and-input-domain"></a>
## 対象集団と入力範囲

出典は18歳以上、脳小血管病によると考えられる自然発症・非外傷性脳内出血で、画像上の背景構造的原因がない成人を含めました。基準画像は発症後0.5から24時間、基準血腫体積は150 mL未満でした。計算器は150 mL未満の正の実測体積と、端点を含むその時間範囲内の既知の撮影時間を要求します。

血腫体積を減らし得る急性期治療（外科的除去、止血治療、降圧）を受けた患者は除外されました。この式は治療効果を推定できません。類推によって外傷性出血、構造的血管病変、出血性変化、静脈性出血、Duret出血へ適用しません。

薬剤予測因子は公表通りの二値指標です。薬剤別係数やDOAC固有校正は提供しません。

<a id="validation-and-interpretation"></a>
## 検証と解釈

四予測因子モデルは十コホートの2,381患者から開発され、C-indexは0.75（95% CI 0.73–0.78）でした。五コホートの895患者で検証し、C-indexは0.74（0.71–0.78）でした。著者は良好な校正を報告しています。適格メタ解析全体は36コホートの5,435患者で、この大きな数はモデル開発標本ではありません。

これは出典集団の拡大リスク推定です。体積増加量、病変の位置や境界、症状、mRS、治療利益を予測しません。3Dや切片表示に血液や組織損傷を追加しません。式の再現と、臨床意思決定ツールとしてアプリを検証することは別です。

<a id="remaining-source-checks-for-the-roadmap"></a>
## ロードマップに残る出典確認

- **静脈圧・流出：** [Marcotti 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4476203/)は定常Poiseuilleネットワークと公開形状を提供します。旧形状補足は取得済みで、八辺の簡略計算器へ転記しました。流入、深部還流割合、流出口圧は未検証の初期値を割り当てずユーザーが入力します。[静脈・出血圧モデル](venous-hemorrhage.ja.md)に来歴と残る制限を記載しています。静脈病変は生成しません。
- **脊髄回復：** [Robertson 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3466672/)はコホート転帰から長期機能回復を記述しますが、連続C1–C3障害回復曲線は提供しません。転帰から本モデルへの定量的対応は未指定です。
- **校正：** [DEFUSE 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC6628906/)は側副群の梗塞分布、[Wilson 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10169426/)は病変群の言語経過を提供します。選択された集団と実測転帰をモデルのコンダクタンスや病変割合へ対応させることは未検証で、要約統計を直接の置換値とはしません。
- **中心性ヘルニア：** [Ropper 1993](https://pmc.ncbi.nlm.nih.gov/articles/PMC1015157/)と[Wijdicks 1997](https://pubmed.ncbi.nlm.nih.gov/9153493/)は二次損傷を記述しますが、損傷組織割合の変位・時間式はありません。その割合の自動生成は裏付けのない校正を追加します。
- **MRA血管置換：** TopCoW MRA008の原エントリとCC BY-NC 4.0ライセンスを三本の交通血管描画形状について検証しました。配置は未検証、遠位枝は手作成です。[出典固有の来歴と仮定](mra-communicating-shapes.ja.md)が実測形状、手作成接続線、シミュレーション形状を区別します。
