# 静脉流出及实测血肿压力

这些独立研究计算器位于详情中，不改变当前动脉病例、组织损伤、症状、3D 几何或切片视图。所有临床输入起始为空。半径比起始为 1，表示归一化的开放参考配置，不是患者测量。

<a id="reduced-venous-network"></a>
## 缩减静脉网络

来源为 Marcotti et al. (2015)，[DOI 10.1186/s12883-015-0352-y](https://doi.org/10.1186/s12883-015-0352-y)。稳态网络采用 Poiseuille 阻力及已发表血管几何。文章适用 CC BY 4.0；数据除另行声明外为 CC0。已获取旧版几何 DOCX 的 SHA-256 为 `d9254e9f2a4208fad9ab2261f537502d126607997f544c4d8bae0cdbfb172207`。[旧版补充材料](https://static-content.springer.com/esm/art%3A10.1186%2Fs12883-015-0352-y/MediaObjects/12883_2015_352_MOESM1_ESM.docx)提供以下长度和直径，单位 cm：

| 血管 | 长度 | 直径 |
|---|---:|---:|
| 上矢状窦 | 19.22 | 0.45 |
| 直窦 | 3.96 | 0.17 |
| 每侧横窦 | 5.25 | 0.88 |
| 每侧乙状窦 | 12.25 | 0.53 |
| 每侧颈内静脉 | 15 | 1.7 |

来源黏度为 3 cP（0.003 Pa·s）。阻力为 `128 × viscosity × length / (π × diameter⁴)`，内部采用 SI 尺寸。直径除以二得到半径。发表的零出口为表压参考，不是患者中心静脉压。

应用将网络缩减为八条边：上矢状窦及直窦汇入窦汇，再经双侧横窦、乙状窦和颈内静脉通向共同出口。省略来源的额外脊髓及侧支通路。不重现完整发表网络或其验证结果。

用户提供总脑静脉流量、进入直窦的比例及共同出口压力。深部比例位于 [0, 1]，各剩余管腔半径比位于 [0, 1]。几何及黏度固定时，导流系数随该比值的四次方变化。将输入比值解释为血栓效应是一个假设，不是血栓负荷量表。不从论文推断临床流入或出口压力默认值。

计算施加稳态流入，求解压力及双侧引流，假设血管刚性、层流和固定黏度。不将静脉压反馈耦合至脑动脉灌注，也不模拟血管塌陷、顺应性、再通、组织损伤或临床结局。省略的侧支通路可改变对阻塞的响应。

若施加流量不能离开不连通分量，则不存在有限稳态压力解。报告的是模型不连通，不是患者 ICP 无穷大。不连通零流量分量的压力不确定。明确报告数值溢出，不以封顶压力替代。

<a id="observed-hematoma-pressure-effect"></a>
## 实测血肿压力效应

压力–体积关系依据 Marmarou et al. (1978)，[DOI 10.3171/jns.1978.48.3.0332](https://doi.org/10.3171/jns.1978.48.3.0332)：

```text
ICP = baselineICP × 10^(observedAddedHematomaVolume / enteredPVI)
CPP = enteredMAP − ICP
```

PVI 是此关系中使压力增加十倍所需的体积。体积和 PVI 使用 mL；ICP 和 MAP 使用 mmHg。增加体积必须非负；基线 ICP、PVI、MAP 必须为正。输入增加体积是实测值，不是独立 ICH 扩大风险计算器的预测。

原始模型在猫实验中验证。后续成人研究报告七名无占位病灶成人的 PVI 为 25.9 ± 3.7 mL（[Shapiro et al., 1980](https://doi.org/10.1002/ana.410070603)）。这个小而不同的人群提供背景，不提供默认值或允许范围。

将关系立即应用于固定分室中的血肿体积，**在脑内出血中未经验证**。计算器不模拟脑脊液置换或储备、动态代偿血流、水肿、病灶边界、症状、治疗效果或临床结局。负 CPP 表示此标量计算中负压力梯度，不预测负血流。溢出是数值状态，不是临床压力估计。
