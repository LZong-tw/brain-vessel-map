<a id="contralateral-pressure-safeguard"></a>
# 對側壓力的數值保護

這是教育用血流模型中範圍受限的數值保護，不是新的生理自動調節模型，也不表示對側半球阻塞在所有情況下都不能讓另一供應區受益。

<a id="why-use-a-numerical-fallback"></a>
## 為何採用數值替代方案？

Ursino 與 Lodi 的 [1998 年腦血流自動調節模型](https://journals.physiology.org/doi/abs/10.1152/ajpheart.1998.274.5.H1715)描述血流在「CPP range of 50–150 mmHg」內約略穩定。這是腦灌流壓的範圍，不是血流圖中所有血管共同適用的 MAP 截止值。近端軟腦膜調節與遠端血流調節透過血管力學作用。

此模型家族的[已發表實作](https://pmc.ncbi.nlm.nih.gov/articles/PMC2673531/)在 Table 1 列出近端增益「G₁ = 0.02 mmHg⁻¹」。穩態調節器使用動脈壓減顱內壓相對於參考值的偏差。活化會改變平滑肌張力，半徑再由血管壁力學決定，阻力則與半徑的四次方相關。這些數值不等於直接乘上具名 ICA、ACA 或 MCA 阻力的增益。

目前網路缺少這種分室層級的血管壁力學耦合。把文獻增益直接當成阻力乘數，會捏造缺少的校正。因此本次變更採用已授權的數值替代方案，保留既有組織常數與病灶校正。

<a id="scoped-counterfactual-comparison"></a>
## 範圍受限的反事實比較

保護用於兩側各有半球特異性阻塞的組合。對每個接受側半球，參考迴路保留自身阻塞、移除對側半球阻塞。椎動脈、基底動脈等兩側共用血管的阻塞仍保留，不視為可移除的對側病灶。

參考迴路與組合迴路使用相同 MAP、解剖變異及側枝分級。各參考迴路的正向側枝血流形成相互限制：每個半球都可同時是供應側與接受側。必要時降低實際側枝導通度，排除高於參考值、由壓力衍生的增加。沒有正向參考血流的路徑，包括新近反轉的路徑，保留原始導通度。

保護也透過供應各半球的具名動脈導通度，施加接受側壓力的數值上限。上限採相應參考壓力，不是生理自動調節閾值。限制不再需要降低導通度時，導通度可回升至原值，但不能超過原值。不推導或加入生理增益。

調整導通度後重新解整個迴路，不在求解後覆寫壓力或血流，並明確要求守恆。守恆診斷的邊界流入包含既有、隱藏的主動脈弓至上肢供血，以及畫面顯示的血管路徑。

只限制正向、由壓力衍生的增益，保留側枝支持的損失。組合阻塞可移除側枝供應側支持，使新病灶自身的梗塞核心合理地大於單獨阻塞時。真實新增的側枝路徑不會僅因另有病灶就被移除。這是避免壓力重分配造成非預期效益的模型特定保護，不模擬其背後的自動調節機制，也不構成臨床治療規則。

<a id="verification-boundary"></a>
## 驗證範圍

回歸測試應證明所針對的雙側半球行為，保留共用血管阻塞與真實側枝路徑的作用，並確認調整導通度後仍維持血流守恆。既有單一阻塞、再灌流與組織校正回歸測試仍須通過。路線圖項目只能在這些測試通過後標記完成。
