<a id="translation-terminology"></a>
# 翻譯術語

簡體中文、德文與日文翻譯涵蓋介面、解剖名稱與既有臨床說明。翻譯不改血管幾何、模擬參數、臨床機率或引用研究結果。MCA、ICA、ACA、PCA、PICA、AICA、SCA、MLF 與 NIHSS 等慣用識別名稱保留。

<a id="simplified-chinese-zh-cn"></a>
## 簡體中文（zh-CN）

參考為全国科学技术名词审定委员会《人体解剖学名词》第二版。委員會[人體解剖學術語目錄](https://www.cnterm.cn/sd/yxjk/zwh/rtjp/)識別此術語計畫；[復旦大學鏡像的委員會 2013 文本](https://xtjp.fudan.edu.cn/Upload/Files/201804100314393640155.pdf)提供本翻譯使用的可取得條目。標題頁仍有未完成出版中繼資料，包括暫填 ISBN；視為委員會撰寫的術語文稿，不作正式印刷書目細節的證明。

明確區域術語調整包括：颈内动脉、大脑中动脉、脑桥、丘脑、脉络丛前动脉、辐射冠、内侧丘系、伏隔核、面神经、视辐射。說明以簡體中文與這些解剖名稱表達，是 App 既有教育說明的翻譯，不是複製術語書定義。適當保留症候群人名、研究名稱與模型假設。

臨床中文也依中國大陸慣用語，例如 homonymous hemianopia 採「同向偏盲」，參見[北京市衛生健康委員會中風資訊](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jbzs/201912/t20191217_1250088.html)。此臨床用法來源與委員會解剖術語目錄分開。

<a id="german-de"></a>
## 德文（de）

解剖命名依標準德文神經解剖用法，包括德文醫學文本慣用的拉丁血管名稱：A. carotis interna、A. cerebri media、A. communicans anterior、A. basilaris 及小腦動脈。已查核來源為 Thieme 的 [*Klinische Neuroanatomie – kranielle MRT und CT*，腦動脈與血管供應區章節](https://shop.thieme.de/api/media-proxy?url=https%3A%2F%2Fnginx%2Fmedia%2F18%2F19%2F9a%2F1653305463%2F9783131634146_musterseite.pdf%3Fts%3D1653305463)。翻譯採德文與標準臨床名稱，如 Dysarthrie、Hemianopsie、Neglect、internukleäre Ophthalmoplegie。共用拉丁解剖名稱，如 Putamen 或 Hippocampus，刻意保留與英文相同拼寫。

<a id="japanese-ja"></a>
## 日文（ja）

解剖名稱依日本解剖學會[《解剖学用語 改訂13版》公開術語](https://www.anatomy.or.jp/yougo.html)，尤其[血管術語](https://www.anatomy.or.jp/file/pdf/yougo/kaibo6.pdf)與[神經系統術語](https://www.anatomy.or.jp/file/pdf/yougo/kaibo7.pdf)。例子包括内頸動脈、中大脳動脈、前交通動脈、脳底動脈、後下小脳動脈、中心前回、内包、視床、内側毛帯。臨床說明翻譯為日文，慣用縮寫與人名仍可辨識。

<a id="scope-of-verification"></a>
## 驗證範圍

完整性測試涵蓋每個人工編寫的在地化鍵，包括動態文字模板。部分術語斷言防止區域解剖名稱及慣用縮寫改變。這些檢查建立翻譯涵蓋與術語一致性，不是所有教育文字的獨立臨床醫師審查。路線圖的臨床審查仍是另一項工作。

<a id="consciousness-terminology"></a>
## 意識術語

神經科英文 *stupor* 在簡體中文譯為**昏睡**，依 [MSD 中文說明](https://www.msdmanuals.cn/home/brain-spinal-cord-and-nerve-disorders/coma-and-impaired-consciousness/stupor-and-coma)：強刺激可短暫喚醒；**昏迷**表示 coma。

德文採 **Sopor**，為 [AWMF 022-016 分類表](https://register.awmf.org/assets/guidelines/022-016l_S1_Akute_Bewusstseinsstoerung_jenseits_der_Neugeborenenperiode_2021-01-abgelaufen.pdf)的定量意識程度。引用存檔指引僅為命名，不是治療建議。

日文以**昏迷**表示 stupor、**昏睡**表示 coma，依[醫學書院神經檢查文章](https://www.igaku-shoin.co.jp/misc/medicina/shinkei4601/)。這些語系修正不改模型意識閾值。
