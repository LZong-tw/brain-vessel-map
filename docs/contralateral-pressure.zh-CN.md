<a id="contralateral-pressure-safeguard"></a>
# 对侧压力数值保护

这是用于教学血流模型、适用范围明确的数值保护。它不是新的生理性自动调节模型，也不主张对侧半球阻塞在任何情况下都不能使其他区域获益。

<a id="why-use-a-numerical-fallback"></a>
## 为什么采用数值替代方案？

Ursino 和 Lodi 在其 [1998 年脑血流自动调节模型](https://journals.physiology.org/doi/abs/10.1152/ajpheart.1998.274.5.H1715)中描述，在约“CPP 范围 50–150 mmHg”内血流保持稳定。该范围指脑灌注压，不是图中每条血管的直接 MAP 截止值。其近端软脑膜调节和远端血流调节通过血管力学起作用。

该模型系列的一个[已发表实现](https://pmc.ncbi.nlm.nih.gov/articles/PMC2673531/)在表 1 中列出近端增益“G₁ = 0.02 mmHg⁻¹”。稳态调节器使用动脉压减颅内压相对于参考值的偏差。激活改变平滑肌张力，随后由管壁力学确定半径；阻力取决于半径的四次方。这些数值并未定义直接乘以具名 ICA、ACA 或 MCA 阻力的增益。

当前网络缺少这种分室层面的管壁力学耦合。将已发表增益作为直接阻力乘数，会凭空补上缺失的校准。因此，本次修改采用已获授权的数值替代方案，并保留现有组织常数及病灶校准。

<a id="scoped-counterfactual-comparison"></a>
## 限定范围的反事实比较

当两侧各有半球特异性阻塞时，应用此保护。对每个受血半球，参考电路保留本侧半球的阻塞，移除对侧半球的阻塞。椎动脉、基底动脉及其他共有血管的阻塞保留在参考电路中，不将其视为可移除的对侧病灶。

参考电路采用与双侧阻塞电路相同的 MAP、解剖变异和侧支分级。各参考电路中的正向侧支血流提供双向约束：每个半球既可供血，也可受血。必要时降低实际侧支导流系数，以排除超出参考电路、由压力带来的增流。参考电路中没有正向血流的通路，包括新出现的反向通路，保留原始导流系数。

此保护还通过向各半球供血的具名动脉导流系数，对受血侧压力施加数值上限。上限取自对应的参考压力，不是生理性自动调节阈值。当约束不再要求降低导流系数时，可将其恢复至原始值，但不能超过原始值。不推断或添加生理增益。

调整导流系数后重新求解整个电路。求解后不覆写压力或血流，守恒仍是明确要求。守恒诊断的边界流入包括现有隐藏的主动脉弓至上肢供血，以及所显示的血管通路。

只限制由压力带来的正向增益，保留侧支支持减少的影响。尤其是，组合阻塞可使侧支供血来源消失，因此与新病灶单独存在相比，其自身的梗死核心确实可能增大。不会仅因另有病灶就移除真实的新可用侧支通路。此比较是模型特有的保护，用于避免压力重新分布造成非预期获益；它不模拟底层自动调节机制，也不建立临床治疗规则。

<a id="verification-boundary"></a>
## 验证边界

回归测试应证明目标双侧半球行为，保留共有血管阻塞和真实侧支通路的影响，并检查调整导流系数后的血流守恒。现有单一阻塞、再灌注及组织校准回归测试仍须通过。路线图项目仅在这些测试通过后才算完成。
