<a id="contralateral-pressure-safeguard"></a>
# 対側の圧に対する数値的保護

これは教育用血流モデルの限定的な数値的保護です。新しい生理学的自動調節モデルではなく、反対側半球の閉塞が別の領域に利益をもたらすことはないという普遍的な主張でもありません。

<a id="why-use-a-numerical-fallback"></a>
## 数値的代替手法を用いる理由

UrsinoとLodiの[1998年の脳血流自動調節モデル](https://journals.physiology.org/doi/abs/10.1152/ajpheart.1998.274.5.H1715)は、「CPP range of 50–150 mmHg」で血流がほぼ安定すると記述しています。この範囲は脳灌流圧であり、グラフのすべての血管に直接適用するMAP閾値ではありません。近位軟膜血管の調節と遠位血流の調節は血管の力学を介して作用します。

[このモデル系列の公開実装](https://pmc.ncbi.nlm.nih.gov/articles/PMC2673531/)のTable 1には、近位ゲイン「G₁ = 0.02 mmHg⁻¹」が示されています。定常状態の調節器は動脈圧から頭蓋内圧を引いた値の基準値からの偏差を用います。活性化が平滑筋張力を変え、壁の力学によって半径が決まり、抵抗は半径の第四乗に依存します。これらの値は、具名のICA、ACA、MCAの抵抗に直接乗算するゲインを定義しません。

現在のネットワークには、そのコンパートメント単位の壁力学との連成がありません。公開ゲインを抵抗の直接倍率に用いると、欠けている校正を創作することになります。そのため、今回の変更は承認された数値的代替手法を用い、既存の組織定数と病変校正を維持します。

<a id="scoped-counterfactual-comparison"></a>
## 限定した反実仮想比較

半球固有の閉塞が左右に組み合わされた場合に保護を適用します。受血側半球ごとの基準回路は、その半球の閉塞を維持し、反対側半球の閉塞を除きます。椎骨動脈、脳底動脈、その他の共有血管の閉塞は基準回路にも残し、除去可能な対側病変として扱いません。

基準回路のMAP、解剖学的変異、側副血行の等級は組合せ回路と同じです。各基準回路で正方向に流れる側副血流を相互の制限値とします。各半球は供血側にも受血側にもなり得ます。圧の変化によって基準を超える増加を除外するため、必要に応じて実際の側副血管コンダクタンスを減らします。新たに逆転した経路など、基準で正方向血流がない経路は元のコンダクタンスを維持します。

各半球へ供給する具名動脈のコンダクタンスを通じ、受血側の圧にも数値的上限を適用します。これは対応する基準圧を用いた上限であり、生理学的自動調節の閾値ではありません。制限のための減少が不要になれば元の値へ戻せますが、元の値を超えません。生理学的ゲインを推定または追加しません。

調整したコンダクタンスで回路全体を再計算します。解を求めた後に圧や流量を上書きせず、保存則を明示的な要件とします。保存診断の境界流入には、表示された血管経路に加えて既存の非表示の大動脈弓から上肢への供給も含めます。

制限するのは圧による正の増加だけです。側副供給の喪失は維持します。組合せ閉塞が側副供血側の支援を除くと、新しい病変自体の梗塞コアが単独閉塞より増えることがあります。実際に新たに利用可能となった側副経路を、別の病変があるという理由だけで除去しません。これは意図しない圧再分配の利益を防ぐモデル固有の保護であり、背景の自動調節機構をモデル化したり臨床治療規則を確立したりするものではありません。

<a id="verification-boundary"></a>
## 検証範囲

回帰テストは対象の両半球組合せ動作を示し、共有閉塞と実際の側副経路の効果を維持し、調整後コンダクタンスで流量保存を確認する必要があります。既存の単独閉塞、再灌流、組織校正の回帰も必要です。これらが合格した後にのみロードマップ項目を完了とします。
