<a id="continuous-model-deficits-and-ordinal-examination-grades"></a>
# 連続的なモデル障害と診察の序数等級

代償後の障害の大きさを、0から3の`SymptomItem.continuousSeverity`として保持します。これは教育モデル内部の値であり、実測された臨床尺度や確率ではありません。`deadContinuousSeverity`は比較のため、永続的組織損傷に由来する対応した大きさを保持します。既存の組織、代償、気付きやすさ、症状の閾値は変更しません。掲載された症状の従来の`sev`（1、2、3）は既存の症状規則で引き続き利用できます。追加のヒステリシスや時間依存の等級状態はありません。

<a id="nihss-is-an-ordinal-bedside-examination"></a>
## NIHSSはベッドサイド診察の序数尺度

[NINDS NIH Stroke Scale](https://www.ninds.nih.gov/sites/default/files/2025-03/KnowStroke_NIHStrokeScale_March2025_508c.pdf)は診察カテゴリーを定義します。確認した[American Stroke Association版NIHSS指示](https://www.stroke.org/-/media/Data-Import/downloadables/5/2/3/NIH-Stroke-Scale-UCM_490144.pdf?rev=c72312713d574cf494fc406be288c3f6)は、診察中に観察した患者の遂行を採点するよう求めています。運動項目は、下垂せず保持（0）、下垂（1）、限定的な抗重力努力（2）、抗重力努力なし（3）、運動なし（4）へ進みます。感覚項目は正常（0）、部分的障害（1）、重度または完全な障害（2）を区別します。

原典の運動ラベルには「No drift」「Some effort against gravity」「No effort against gravity」「No movement」が含まれます。これらは診察の記述であり、梗塞体積の閾値ではありません。

順序付きカテゴリーは等級間の距離が等しいことを意味しません。一点の差は一定量の筋力や感覚ではありません。算術的補間はモデルの表示上の選択であり、NIHSS指示が与える臨床解釈ではありません。梗塞マップ、組織体積、動脈閉塞だけから患者のNIHSSを算出できません。ベッドサイド所見と規定の診察で得点を決めます。

<a id="motor-presentation-uses-existing-anchors"></a>
## 運動表示は既存の基準点を使用

上肢・下肢の筋力低下では、連続的なモデル重症度を`src/anatomy/symptoms.ts`の既存の`nihss.pts`基準点へ投影します。

| モデルの大きさ | 運動投影の基準点 |
| --- | --- |
| 0 | 0 |
| 1 | 既存の軽度項目点、`pts[0]` |
| 2 | 既存の中等度項目点、`pts[1]` |
| 3 | 既存の重度項目点、`pts[2]` |

隣接基準点間は線形投影です。表示する運動等級は最も近い整数に丸めます。正の値を持つ掲載済み運動障害は、少なくとも既存の軽度基準点`pts[0]`を維持します。一般的な筋力低下の基準点`[1, 3, 4]`では、軽度と中等度の間に中間等級2が現れます。異なる既存基準点の症状はその基準点を維持し、再校正しません。最大等級はモデルの大きさが正確に3へ達することを要求せず、関連する神経路組織がすべて損傷したことも意味しません。

この量子化は既存の病変校正を維持し、一部の組織が残るという理由だけで既知の古典的症候群を再分類しません。予測されたベッドサイド所見としてカテゴリーを検証するものではありません。最高運動等級の表示は説明用のモデル推定であり、特定の患者に随意運動がない証拠ではありません。推定整数等級が変わらなくても連続的な大きさは変化できます。

基準点と投影は経験則です。実証的な病変から筋力への閾値、新しい病変境界、治療効果量、患者校正を追加しません。小さな解剖学的変化が連続値を変えても、それだけで患者のカテゴリー上の利益を確立しません。

<a id="other-examination-items-and-limits"></a>
## その他の診察項目と制限

他の項目は既存のNIHSS序数規則を維持します。公式範囲は感覚0–2、顔面運動0–3、言語0–3、構音0–2、視野0–3、水平注視0–2、四肢協調0–2、消去・不注意0–2です。カタログの既存`pts`配列はこれらのカテゴリーとの教育的関連付けであり、臨床校正された病変閾値ではありません。意識や指示された行動の遂行不能など診察上の依存関係も既存推定器に残ります。

推定NIHSSは整数であり、丸め境界を挟む隣接モデル値などでカテゴリーや総得点が段階的に変わることがあります。ごく小さな両側変化を大きな合計運動得点の利益と扱わない既存の保護を維持します。集約していない連続的な大きさは、序数量子化から独立して回復比較と障害表示を支えます。分数NIHSSとして報告せず別に保持します。どちらもmodified Rankin Scaleへの換算、個人の予後、実測治療利益を与えません。
